## 구현 기준

- 새로운 CSS 파일을 계속 겹치지 않고 editorial.css를 현재 표현 계층으로 사용
- 이번에 바꾸는 기술 구성의 기존 editorial 규칙은 교체
- FHD 기준 h1 52–68px / h2 36–48px / 본문 16–18px / 보조 12–14px
- rem 체계로 QHD·UHD에서도 같은 상대적 위계 유지
- 흰색·차가운 회색·짙은 남색·GeoSR 블루만 사용
- 모션은 400–700ms의 이미지 등장과 링크 피드백에 한정하지 않고 필요에 따라 확장하되 콘텐츠 탐색을 방해하지 않음
- reduced-motion에서 전환·사진 확대 중단
- 한글 문장은 구체적인 수행 활동 중심으로 작성하고 근거 없는 성과·수치를 추가하지 않음
- 새로운 과학 이미지나 영상은 이 디자인 수정에 끼워 넣지 않음 기존 승인된 초안과 검증된 원본만 연결

## 검수 게이트

1. KO 전체 8개 경로와 대표 상세 화면을 실제 브라우저에서 확인
2. 수정 페이지 FHD / QHD / UHD CSS viewport에서 상대 배치·글자·여백 비교
3. 모바일에서 가로 넘침과 탭·양식 재배치 확인
4. EN의 긴 제목과 자료 목록 확인
5. 기술 탭 / 검색 / 문서 확대 / 양식 유효성 / reduced-motion 확인
6. 경로·메타데이터·영상 수명주기 기존 검사 통과 후 커밋과 푸시

브라우저 CSS viewport와 낮은 DPR을 조합해 전체 레이아웃을 검수하며 실제 UHD 모니터 검수로 표현하지 않음
직접 CDP 캡처에서 큰 화면이 잘리는 현상을 발견해 QHD·UHD 최종 증거는 브라우저 screenshot API로 다시 저장함

- 메인 직접 구현 / 검수 기준 코드의 이전 버전은 10cb4d3
- 기술 페이지를 가로 5개 분야와 설명·미디어 2열로 재구성하고 기존 21개 기술 연결을 유지

- 문의 화면과 공통 연락 영역을 재구성하고 입력 양식은 실제 mailto 방식으로 유지

- 개인정보 검토 문서의 비공개 상태와 인증서 확대 동작을 유지
- 홈·기술·연구·소식·회사·AX·장비·문의 8개 경로의 대표 화면과 기술·장비·연구 상세를 실제 브라우저에서 확인
- FHD 1920×1080 / QHD 2560×1440 / UHD 3840×2160 연구 화면 비교에서 제목 크기 67.2 / 89.6 / 134.4px로 같은 상대 위계 확인
- 390×844에서 연구·문의·영문 기술 페이지의 재배치와 가로 넘침 없음 확인
- 영문 연구 검색 erosion 결과 2건 / 기술 탭 방향키 이동 / AX 모니터링 분야 선택 / 인증서 확대와 닫기 확인
- 빈 문의 양식은 이름·이메일·문의 내용 입력 단계에서 차단하며 외부 메일 전송은 실행하지 않음
- prefers-reduced-motion에서 기술 화면 전환 시간 0초와 키보드 조작 유지 확인
- AX 실제 기능 미리보기 영역은 16:9 비율 유지
- JavaScript 구문 검사와 diff 공백 검사 통과
- 경로 검사 16개 KO/EN 요청과 56개 로컬 참조 2xx 확인
- 메타데이터·접근성 계약 검사와 영상 수명주기 검사 통과

증거는 `visual-review-r5/`의 대표 화면 17장과 `viewport-checks.json`에 저장
수정 영역의 브라우저 검수 기록이며 모든 게시글 본문의 이관 또는 모든 실물 디스플레이의 검수를 의미하지 않음
