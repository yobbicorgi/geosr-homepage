# 메인 화면 구성과 검수 · 2026-09-28

## 현재 구성

메인은 대표 기술과 플랫폼을 보여 주고 상세 자료는 세부 페이지에서 탐색한다
Selected Work와 인증 목록 및 기존 홈페이지 원문 보관 안내는 메인에서 제거했다

| 순서 | 구성 | 연결 |
| --- | --- | --- |
| 첫 화면 | 영어 고정 문구 Geo Data Intelligence와 광역 연안 포스터 | 사업 분야와 회사 소개 |
| 01 | 분야별 미디어와 관측·환경·수치모델·원격탐사 선택 | 21개 상세 기술 |
| 02 | AX 화면 가로 탐색과 GeoDAP 실제 메인 화면 | 삽입한 AX 페이지와 GeoDAP 서비스 |
| 03 | 짧은 회사 개요 | 연혁과 인증 갤러리 및 사업장 |
| 04 | 소식 세 건 | 전체 소식 게시판 |

연구개발 719건과 소식 384건 및 장비 80건은 해당 게시판에서 검색한다
인증 명칭 127개는 회사 페이지의 분류형 갤러리에서 확인한다
민감정보 검토 대상인 문서 두 건의 이미지 보호는 유지한다

## 디자인 판단

[Motionsites 12개와 Refero 12개 비교](17-DESIGN-REFERENCES-20260928.md)를 바탕으로 미디어와 설명의 비중을 조정했다
섹션 제목과 본문 및 분야 선택을 같은 정렬선으로 묶었다
큰 화면에서 불필요한 세로 공백을 줄이고 모바일에서는 하나의 미디어와 펼친 설명만 표시한다
메인과 공통 하단의 반복적인 대각선 화살표 및 작업 경위 문구는 제거했다

직접 만든 단순 Three.js 지구·파형은 미채택 처리하고 코드와 전용 자산을 삭제했다
수치모델 영역은 NASA SVS 해양 순환 시각화의 1080p 발췌로 교체했다
이 영상은 외부 모델 설명 자료이며 GeoSR 자체 계산 결과나 회사 본편으로 표시하지 않는다
출처 링크와 영상 정지 버튼을 함께 제공한다
AX 직원 저장소의 곡면형 가로 갤러리는 유지한다

## 미디어 상태

| 영역 | 현재 상태 |
| --- | --- |
| 메인 첫 화면 | 회사소개서 연안 사진을 임시 포스터로 사용 |
| 관측·조사 | 실제 무인선 사진 |
| 환경·생태 | 검토된 실험 콘셉트 정지 이미지 |
| 수치모델 | NASA SVS ECCO2 24초 1080p 영상 |
| AI·원격탐사 | 지구·위성 콘셉트 정지 이미지 |
| AX | 제공 저장소 화면과 곡면형 갤러리 |
| GeoDAP | 실제 공개 메인 캡처 |

회사 60초 본편과 Higgsfield 요소별 영상 제작은 별도로 남아 있다
유료 생성은 이번 변경에서 수행하지 않았다
현재 포스터의 촬영 위치가 확인된 본편 원본이라고 주장하지 않는다

## 실제 검수

- QHD 2560×1440 국문 기술 영역에서 미디어와 설명을 함께 확인
- FHD 1920×1080 영문 제목과 설명 및 분야 선택 확인
- 모바일 390×844에서 가로 넘침 없음
- 분야 선택과 방향키 및 Home·End 이동 확인
- 1920×1080 H264 30fps 24초 무음 영상 확인
- 모션 감소에서는 자동 다운로드와 자동 재생을 하지 않으며 직접 재생 가능
- 최초 메타데이터 수신이 모션 감소 상태의 직접 재생을 취소하던 오류 수정
- 비활성 분야와 화면 밖 영상은 정지하며 사용자의 정지 선택을 유지
- 국·영문 18개 경로와 로컬 참조 및 미디어 수명주기 검사 통과

기능 검수는 최종 디자인 승인이나 전체 영상 완성을 의미하지 않는다
공식 geosr.com 배포 및 실제 기기 Safari 검수는 포함하지 않는다
