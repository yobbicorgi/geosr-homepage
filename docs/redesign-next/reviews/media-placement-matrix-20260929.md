# GeoSR 홈페이지 미디어 배치표

작성일 2026-09-29 · 상태: 콘셉트 이미지와 원문 기술 자료를 페이지별로 대조하는 중

## 배치 원칙

이미지는 위치마다 역할을 먼저 정하고 고른다. 해당 기술의 실제 결과·공개 기록·보유 장비를 보여주는 자리는 원래 GeoSR 자료를 같은 주제의 자리에 둔다. 자료가 없거나 해상도와 구도가 넓은 도입 장면에 맞지 않으면 새로 만든 독립 콘셉트 이미지를 사용하고 `콘셉트 이미지`라고 표시한다. 원본 기록을 보기 좋게 만든다는 이유로 수치·지도·성과를 다시 그리거나 다른 분야의 이미지를 돌려 쓰지 않는다.

화면에 놓을 때도 주변 디자인을 기준으로 삼는다. 전폭 배경은 넓은 현장과 읽을 여백을 함께 확보하고 세부 도입 이미지는 제목과 같은 시선 흐름에 둔다. 실제 도표와 문서는 본래 비율 전체가 보이게 하며 갤러리에서는 콘셉트와 원자료를 구분해 순서대로 확인할 수 있게 한다. 작은 화면에서 이미지의 핵심 대상이 잘리면 비율이나 구도를 다시 정하고 임의 크롭으로 해결하지 않는다.

이미지 슬라이드는 선택 분야에 맞춰 바뀌며 한 분야 안에서 콘셉트 장면과 실제 회사 기술 자료를 구분한다. 실제 원본 지도·그래프·탐지 화면 자체가 설명의 중심인 기술은 원본을 첫 이미지로 유지하고 더 꾸민 이미지로 대체하지 않는다. 공개 자료가 이어지는 기술 상세에서는 첫 장면과 원문 갤러리의 역할을 나눈다. 각 이미지는 해당 화면에 놓일 크기와 크롭·정렬 상태로 확인하고 이웃 섹션과 같은 사진이 불필요하게 반복되지 않는지 점검한다.

수치와 지역명 및 실제 운영 상태를 콘셉트 이미지에 덧씌우지 않는다. 설명용 경계나 분할 상자는 `콘셉트`임을 화면에 보이고 원문 결과와 분리한다.

## 메인 영상과 세부 페이지의 역할 · 2026-09-29 최신 결정

메인 첫 화면은 서로 다른 업무를 다룬 5~10초 장면을 묶은 한 편의 영상으로 구성한다. 넓은 현장과 실제 행동 및 분석으로 넘어가는 시점 변화가 보여야 하며 같은 조사선이나 같은 자연 풍경을 반복해 길이만 늘리지 않는다. `Geo Data Intelligence`는 영상과 독립된 웹 텍스트로 고정한다. 메인에 채택한 장면은 주제와 정확히 맞으면 **해당 세부 페이지에서도 재사용할 수 있다**. 메인에서는 전체 흐름의 한 부분이고 세부에서는 해당 기술의 맥락과 원문 자료를 함께 보여준다.

세부 도입 장면은 그 기술을 한눈에 이해시키는 이미지 또는 승인된 영상으로 시작한다. 바로 아래에서 GeoSR 원문 그림과 사업소개·보유기술·활용분야를 읽게 한다. 연구·사업·논문 게시판은 검색과 목록을 우선하고 인증·면허는 갤러리로 둔다. 한 컷을 무관한 기술에 돌려 쓰지 않는다.

영상 제작은 메인 장면의 서로 다른 주제와 실제 동작 확보 → 검수한 장면의 메인 편집 → 필요한 장면만 해당 세부 페이지로 확장의 순서로 진행한다. 원본 이미지 QA와 시작·중간·끝 콘티 및 예상 크레딧을 고정하고 한 장면을 한 번씩 제작한다. 동작이나 구조가 실패한 장면은 같은 프롬프트로 반복 결제하지 않는다.

## 인공지능 시계열 기술 도입 화면 보완 · 2026-09-29

ID 61 첫 화면의 조위계 사진만으로는 시계열 예측이라는 기술이 드러나지 않아 이미지 위에 자체 SVG 설명 그래픽을 추가했다. 관측 구간과 예측 구간을 서로 다른 선으로 구분하되 축과 수치 및 실제 지역명은 넣지 않았다. 그래픽은 장면을 이해시키기 위한 개념 도식이며 GeoSR 예측 성능이나 실제 계산 결과가 아니다. 영문 페이지에도 같은 선과 크기를 사용하고 대체 설명을 `Concept diagram of AI time-series analysis`로 제공한다.

실제 해수면 유동 AI 예측·조위 관측과 예측 비교·해양환경 변수 공간 예측은 아래 기술 자료 영역에 기존 공개 자료 그대로 남겨 첫 화면 그래픽과 구분한다. 화면 크기가 작아져도 선 그래프를 설명하는 카드와 원본 관측 장면이 함께 보이도록 카드 폭과 위치를 반응형으로 조정했다.

원본 기술 도표가 첫 장면인 페이지는 보기 좋은 신규 사진을 억지로 씌우지 않는다. 필요하면 이후 검수에서 도표 주변 프레임·캡션·배치를 다듬되 원본 픽셀과 수치를 보존한다. 개별 기술 본문은 `dist/business-details-data.js`가 원문에서 분리한 사업소개·보유기술·활용분야를 그대로 제공한다.
