# 세부 페이지 디자인 보완 기준

검토일 2026-09-20

후속 요청에 따른 전체 콘텐츠 표현 기준은 [콘텐츠별 표현 설계 v1](CONTENT-PRESENTATION-PLAN-v1.md)을 따른다
아래는 이 턴에서 확인한 레퍼런스와 초기 세부 페이지 보완 명세의 기록이며 완성 디자인 승인을 의미하지 않는다

## 범위

사용자가 수용한 메인 첫 화면은 유지하고 사업·연구·AX Platform·회사·소식·장비·문의의 구성과 표현을 보완한다
코드 구현 전에 메인이 레퍼런스를 검토하고 아래 방향을 정했으며 서브에이전트는 정해진 명세에 따라 구현한다

MotionSites는 갤러리의 미리보기를 확인했으며 원본 사이트의 전체 동작을 검증한 것은 아니다
레퍼런스의 코드·이미지·문구를 복사하지 않는다

## 공통 시각 설계

- 내부 페이지는 읽기 쉬운 밝은 바탕과 GeoSR의 청색을 중심으로 구성
- AX 소개 첫 구간만 짙은 남색을 사용해 콘텐츠 성격을 구분
- 본문 폭은 최대 1360px이며 제목 52px와 본문 16px를 기준으로 조정
- 모바일 제목은 34px를 기준으로 자연스럽게 줄바꿈
- 전체 화면 높이의 반복적인 빈 소개 구간을 줄이고 첫 화면에서 실제 내용을 확인
- 탭은 밑줄 방식으로 통일하고 설명·날짜·분류의 기준선을 정렬
- 준비 중인 영역은 명확하게 표시하되 작은 안내와 차분한 미디어 자리로 표현
- 긴 문장과 한글 직역투를 줄이고 기능과 사실 중심으로 작성

## 페이지별 구성

| 페이지 | 구조 |
| --- | --- |
| 연구·소식 | 짧은 소개 → 대표 소식 한 줄 → 분류·검색 → 목록 → 상세 본문 |
| 회사 | 회사 개요와 16:9 필름 자리 → 분야 → 연혁·정보 → 자료 3분류 → 오시는 길 — 별도의 반복 소개 구간은 두지 않음 |
| 장비 | 제목 → 분류·검색 → 같은 비율의 검증된 장비 사진과 간결한 설명 |
| 문의 | 연락처·주소와 문의 양식을 한 화면에 배치하고 미전송 안내 유지 |
| 사업 | 기술 분야 탭 → 16:9 이미지와 설명 → 원래 기술 항목에 대한 연결 |
| AX Platform | 별도 콘셉트 필름 자리 → 탐지·예측·모니터링 분류 → 실제 플랫폼 소개 |

## 동작 설계

- 사업·AX 전환은 같은 비율의 미디어 안에서 240ms 교차 전환
- 텍스트는 최대 8px 이동하며 탭 밑줄은 약 250ms 전환
- 인증서 카드 앞면은 항상 유지하고 Y축 회전은 최대 6도
- 카드 hover와 키보드 focus에서는 정면으로 돌아오며 약 320ms 전환
- 모바일에서는 터치 조작과 내용 가독성을 우선
- 움직임 줄이기 설정에서는 장식적인 이동을 제거

## 콘텐츠 유지 조건

내부 페이지의 확정 한글 문구

- 연구 소개 — GeoSR의 연구개발과 주요 수행 실적을 소개합니다
- 회사 소개 — 현장을 관측하고 데이터를 분석해 해양과 환경의 변화를 연구합니다
- 회사 전문 분야 — 현장 조사와 실험 분석부터 수치모델링과 데이터 플랫폼까지
- AX 소개 — 해양·환경 분야의 탐지와 예측을 지원하는 전문 플랫폼
- 장비 소개 — 현장 조사와 실험 분석에 활용하는 주요 장비를 소개합니다
- 문의 — 함께할 일을 이야기해 주세요

GeoDAP과 AX Platform은 별도 소개 항목이다
AX 콘셉트 영상과 개별 플랫폼의 실제 기능 화면은 구분한다
현재 미검증 이미지나 UI는 빈 영역을 채우기 위해 투입하지 않는다
검수된 실험실 콘셉트 이미지는 실제 연구실 사진으로 오인되지 않게 표시한다
보고서 그래프·가짜 장비·네온 흐름선 등은 추가하지 않는다

## 완료 검수

한글·영문 경로를 확인하고 데스크톱과 모바일에서 글자 크기·정렬·오버플로를 검토한다
탭·검색·자료 확대·연락처 링크와 키보드 조작을 확인한다
메인 첫 화면과 기존 원본 자료가 변경되지 않았는지 Git diff로 확인한다
실제 영상 제작과 미검증 플랫폼 화면의 대체는 별도 작업으로 남는다
