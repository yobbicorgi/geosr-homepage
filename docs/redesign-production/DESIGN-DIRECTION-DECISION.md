## 선택: B 기반 하이브리드

B를 기본 정보 구조로 채택한다. 현장 근거와 기술 정보를 편집형 위계로 읽을 수 있고, 섹션 높이와 탐색 밀도를 조절하기 쉽다. 첫 수직 슬라이스에는 A의 전체 화면 hero film 프레임 연출과, C의 키보드로 조작 가능한 연구 흐름 및 AX 미리보기 상호작용을 가져온다.

이번 디자인·QA 범위는 1440, 1920, 2560 CSS px desktop이다. 모바일은 후속 범위로 제외한다. Hero는 정확히 한 viewport 높이로 채우며, header는 미디어 위에 투명하게 겹친다. Hero 내용은 브랜드 헤드라인, 짧은 서브카피, 영상 제작 준비 상태, 작은 scroll cue로 제한한다. 영상이 없는 동안 source-backed 연안 참고 사진을 fullscreen cover poster로 유지하고, 향후 영상은 같은 framing과 cover 동작으로 교체한다. 첫 화면에는 다음 section이 나타나지 않는다. 가져올 요소는 목적이 있는 것만 사용한다. AX의 Discover, Predict, Monitor 화면은 서로 다른 제품 예시로 분리한다. 제품 UI에는 출처 캡처가 보존하는 전체 16:9 비율을 적용하고, 통합된 제품 절차처럼 설명하지 않는다.

## 제외 및 유의점

- 대시보드 과밀도, 한 화면의 불필요한 지표·패널, 검증되지 않은 값이나 지도는 제외한다.
- 콘텐츠 높이에 비해 과도한 빈 화면과 장식 목적의 넓은 여백은 제외한다.
- 기존 공식 4개 분류를 Home에 카드로 반복하지 않는다. Home은 OBSERVE / ANALYZE / MODEL / PREDICT / DELIVER 흐름으로 안내하고, 원래 분류·ID는 기술 디렉터리에서 보존한다.
- 라임·네온, 실제 분석처럼 보이는 가상 레이어, 사람·손 이미지는 사용하지 않는다.
- 회사 정체성 카피는 GeoDAP의 “Earth Data Intelligence” 문구를 반복하지 않는다. GeoDAP은 독립 서비스로 분리한다.

## 구현 확인 범위

`dist/redesign-preview.html`은 새 방향의 Home 수직 슬라이스다. 이는 내부 검토용이며 기존 공개 경로나 배포를 바꾸지 않는다. 사진 위치·촬영일, 캡처 버전, 자료 권리, 자격 문서 현행성, 영문 카피는 계속 미확인 항목이다. 공개 전에 각 출처와 최신 자료를 대조해야 한다.
