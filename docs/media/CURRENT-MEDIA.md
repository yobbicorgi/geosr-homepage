이미지 원본과 재편집용 클립을 웹용 결과와 중복 업로드하지 않는다
프롬프트와 제작 기록은 현재 웹용 파일을 설명하고 재작업할 수 있도록 보존한다
기존 다중 이미지 프롬프트에는 같은 작업에서 생성했지만 현재 쓰지 않는 장면도 언급된다 해당 문장을 선택된 장면의 합격으로 해석하지 않는다
제작 기록에 남은 과거 업로드 URL은 이력이다 다음 작업은 실제 보관 원본을 확인해 다시 업로드한다

## 기술 및 플랫폼

기술 상세의 영상과 정지 대체 이미지는 런타임 manifest와 기술 미디어 데이터에서 확인한다
AX의 현재 소개는 로컬 정적 캡처 갤러리다 현재 사용하지 않는 이전 프리뷰 슬롯과 녹화본은 로컬 보관소로 옮겼다
GeoDAP은 실제 전체 화면 이미지와 외부 서비스 연결을 유지한다
