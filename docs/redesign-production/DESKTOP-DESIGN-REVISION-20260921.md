# 데스크톱 디자인 개선 기준

2026-09-21 · 메인 설계 / 구현 및 검수 기록

## 문제

기존 1360px 최대 폭과 고정 제목·여백은 FHD 이후에도 확장되지 않아 UHD에서 콘텐츠 폭이 화면의 약 35%로 줄었다
기능 검증을 통과한 것을 디자인 완성으로 간주하지 않는다 이번 변경은 사용자 요청에 따른 시각 체계 재설계다

## 확정 설계

- FHD 기준 1920×1080에서 본문 폭 84% 및 좌우 여백 8%
- QHD 2560×1440 및 UHD 3840×2160에서는 같은 정렬선과 열 수 및 상대적인 크기 관계 유지
- 헤더와 메인 첫 화면의 좌우 기준은 4.2%로 더 넓게 사용
- 페이지 전체 zoom이나 transform 확대 대신 요소별 CSS 길이를 동일한 설계 단위로 계산
- 1600px 이상 데스크톱은 비례 체계 적용 기존 소형 데스크톱과 모바일 동작 보존
- 확대·축소와 OS 배율에 따른 CSS viewport 차이를 물리 모니터 해상도와 혼동하지 않음

## 시각 체계

| 항목 | 1920px 기준 |
| --- | --- |
| 본문 | 18px / 행간 1.75 |
| 보조 설명 | 14px |
| 내부 페이지 제목 | 64px / 굵기 650 |
| 섹션 제목 | 48px / 굵기 650 |
| 카드 소제목 | 26–32px |
| 메인 영문 | 82px / 행간 0.97 |
| 메인 한글 | 24px / 자간 -0.02em |
| 헤더 | 높이 88px / 메뉴 15px |
| 섹션 상하 여백 | 104px |

주색은 #1768aa 파랑이며 #071a2b 짙은 남색과 흰색을 큰 면에 사용한다
밝은 배경은 #f5f7fa 본문은 #102536 보조 문자는 #516779 경계선은 #d3dde5를 사용한다
반복되는 청록 회색 면을 줄이고 선택 상태와 연결에 파란색을 사용한다

## 영역별 구성

- 메인: 전체 화면의 지구 영상 자리 보존 하단 왼쪽 제목과 설명 및 과정 표시의 상대 위치 통일
- 전문 분야: 윗줄 분류표시 아래 제목과 링크를 배치하고 4개 탭 아래 60:40 미디어·설명 구성
- 대표 연구: 흰 배경에 주요 사례 한 개와 보조 사례 두 개를 유지하되 제목과 패딩을 같은 체계로 정렬
- 플랫폼: AX와 GeoDAP의 동등한 두 패널 및 16:9 미디어 비율 유지 설명 공간의 과한 높이 축소
- 인증: 분류와 설명을 왼쪽에 문서 갤러리를 오른쪽에 배치해 세로 공간 낭비 축소 앞면을 유지한 회전 보존
- 목록과 상세: 공통 정렬선 적용 상세 본문은 읽기 편한 별도 폭 유지
- AX: 소개 문구 40%와 콘셉트 미디어 60% 이후 세 범주와 플랫폼 선택 22% 및 실제 화면 78%

## 보존 범위

영상 생성 및 새로운 과학 그래픽 생성은 이번 변경에서 수행하지 않는다
기존 탭·필터·모달·키보드·언어·개인정보 보호·준비 상태 표시는 유지한다
미디어 비율을 보존하며 실제 화면에 임의 데이터나 효과를 합성하지 않는다

## 합격 기준

메인이 세 데스크톱 viewport에서 정규화한 콘텐츠 폭과 제목 크기 및 배치를 비교한다
한글과 영문 및 모바일에서 잘림과 가로 넘침을 확인한다
적절한 기능 검사와 실제 렌더링 검수를 모두 통과한 뒤 결과를 기록한다
최종 사용자 디자인 승인은 별개다

## 변경 전 실측

CUA 브라우저에서 CSS viewport를 지정하고 DOM의 실제 치수를 확인했다

| viewport | 홈 본문 폭 | 메인 제목 | 섹션 제목 | 메인 제목 왼쪽 위치 |
| --- | --- | --- | --- | --- |
| 1920×1080 | 1360px | 82px | 52px | 80px |
| 2560×1440 | 1360px | 82px | 52px | 128px |
| 3840×2160 | 1360px | 82px | 52px | 768px |

개선 후에는 본문 폭 비율의 해상도 간 차이가 1%p 미만이어야 한다
메인 및 섹션 제목의 font-size / viewport-width 비율도 1% 이내의 상대 오차로 유지한다
스크롤바 폭에 따른 수 px 차이는 허용하되 제목 줄바꿈이나 열 수 변화로 이어져서는 안 된다

## 적용 및 검수 결과

2026-09-21 신규 desktop-system.css를 9개 HTML의 마지막 스타일시트로 연결했다

- FHD / QHD / UHD 홈 메인 제목 82 / 109.33 / 164px
- 섹션 제목 48 / 64 / 96px
- 헤더 88 / 117.33 / 176px
- 본문 폭 약 84% 유지 및 메인 제목 왼쪽 위치 약 4.2% 유지
- 주요 8개 페이지의 세 데스크톱 해상도에서 문서 가로 넘침 없음
- 영문 8개 페이지 390px 화면에서 문서 및 제목 가로 넘침 없음
- 한글 홈 390px 및 1440 / 1599 / 1600px 경계에서 문서 가로 넘침 없음
- AX 모니터링 탭 전환과 16:9 실제 화면 표시 확인
- 인증 분류 전환 및 실제 자료 이미지 로딩 확인
- CSS 구문 검사 오류 0 및 16개 한영 경로와 43개 로컬 참조 검사 통과
- 16개 경로 metadata/accessibility 정적 검사 통과

검수 캡처와 치수 기록은 review-20260921 폴더에 보관했다
1440 이하 기존 반응형 구성과 1600 이상 데스크톱 구성은 별도 breakpoint를 사용하므로 경계에서 크기 변화가 있으며 FHD 이상 세 목표 해상도에서는 같은 비례를 유지한다
영상은 제작하지 않았으며 기존 준비 중 표시를 유지한다
이번 결과는 디자인 개선 적용 및 위 항목 검증 완료이며 사용자의 최종 미감 승인을 의미하지 않는다
