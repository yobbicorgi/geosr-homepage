- 한국어 메인의 신규 영상 슬롯 8개가 pending으로 로드됨
- 영문 AX 소개의 공통 슬롯 3개와 플랫폼 소개 9개가 표시됨
- 미승인 상태에서 신규 video 요소와 미납품 영상 요청이 없음
- 키보드 좌우 방향키 및 End 키로 AX 탭을 전환하며 포커스·선택 상태·보이는 패널이 일치함
- 1920px 및 390px 폭에서 가로 넘침 없음
- 영문 AX 소개에서 깨진 이미지 없음 — src 없는 문서 확대 대기 이미지는 제외
- AX 소개 영역에서 실제 플랫폼 외부 서비스 접속 링크 없음
- 신규 JS 문법과 Git 공백 검사 통과

## 실제 미디어 연결 시험

기존 satellite-preview.mp4를 임시 로컬 검사 파일로 복사해 사용
실제 새 영상을 생성한 것이 아니며 배포 자산으로 사용하지 않음

- 메인 루프 로드와 재생 확인 · 제어 버튼으로 정지 확인
- 스크롤 영상은 일반 재생을 정지한 상태에서 시간 탐색
- 동일 첫 장면에서 스크롤 진행에 따라 약 3.25초 → 역스크롤 시 약 1.08초로 이동 확인
- 화면 밖 메인 영상 정지 확인
- AX 선택된 영상만 재생 · 예측 장면 종료 후 모니터링 장면 및 다음 장면으로 진행 확인
- prefers-reduced-motion 적용 시 로드된 신규 영상 전부 정지
- 의도적인 잘못된 영상 경로에서 오류 상태와 제작 대기 화면 복귀 확인
- 승인 설정 변경 시 오래된 캐시를 재사용하지 않도록 manifest는 no-store로 요청
- 검사 후 임시 파일 제거 · manifest 전부 src null / pending 복원
- 캐시 없이 다시 열어 승인 영상 0개와 video 요소 0개 확인

## 검수 범위 밖

- 최종 영상과 이미지의 지리·장비·모델 출력 검수는 원본 확보 후 진행
- 저사양 실기기와 Safari의 최종 코덱 및 스크롤 탐색 성능은 미검증
- 현재 원자료와 기존 이미지 전체가 최종 영상 제작 승인 상태라는 뜻이 아님
- 정식 홈페이지 대체 배포와 전체 게시판 이관은 이번 검수 범위가 아님
