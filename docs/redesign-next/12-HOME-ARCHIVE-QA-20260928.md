# 메인 화면·원문 자료실 개선과 남은 범위 · 2026-09-28

## 이번 화면 수정

- 메인 전문 분야·연구 사례의 글자 크기와 높이를 줄여, 제목만 크게 차지하던 화면을 압축했다.
- 중간 AX/GeoDAP 소개를 어두운 전면 배경과 과대한 글자 겹침에서 밝은 편집형 2열 구성으로 바꿨다. 플랫폼 정적 화면을 독립된 16:9 프레임에 `object-fit: contain`으로 표시해 원본 화면이 잘리지 않는다. 모바일은 화면을 먼저, 설명을 뒤에 배치한다.
- 메인·전문 분야·플랫폼·문의 문구 중 직역투와 과장된 문장을 자연스러운 기업 문장으로 수정했다. 전체 국문 카피의 최종 편집 검수는 아직 별도 작업이다.
- 연구 사례와 인증 자료 레일, AX 갤러리에서 마우스 휠로 항목을 넘길 수 있다. 휠 이벤트는 수동(passive)이며 문서의 일반 세로 스크롤을 막지 않는다. 키보드·화살표·터치 조작은 유지한다.
- 분야 전환, 연구 카드와 인증 문서, AX 갤러리의 모션은 실제 탐색 상태 변화에 연결되어 있다. 임의의 관측값이나 분석 결과를 연출하는 그래픽은 추가하지 않았다.
- 모든 HTML 진입 화면의 브라우저 탭 제목을 `GeoSR`로 통일하고, 직원 AX 저장소의 64×64 GeoSR 심벌을 공식 로고와 대조해 파비콘으로 적용했다. 상세 검색 결과에 필요한 페이지별 제목은 Open Graph와 Twitter 메타데이터에 유지한다.
- AX 메인 캡처는 직원 저장소의 1280×720 위성 시설물 탐지 화면 전체를 쓴다. 스크롤 진입 애니메이션이 이미지를 5% 확대해 화면 양옆을 자르던 현상을 없애고, 16:9 프레임과 실제 이미지 경계가 일치하는 것을 브라우저에서 확인했다.
- GeoDAP 공개 사이트의 `THE WORKSPACE` 영역으로 직접 이동해 2026-09-28에 1600×900 브라우저 화면을 캡처했다. 소개 페이지의 지도 작업화면 **미리보기**를 코드상 비율과 위치로 프레이밍해 패널·지도·범례·하단 조작부 전체가 보이게 했다. 로그인한 실제 서비스 화면이 아니므로 페이지와 대체 텍스트에 이를 명시했다. 서비스 접속 시 로그인 화면이 나타나는 것도 확인했다.
- 모바일 플랫폼 선택 탭의 선택 글자가 진한 배경에서 흐려지던 문제를 흰색으로 바로잡았다. GeoDAP 출처 설명표는 가로 전체를 덮지 않는 짧은 캡션으로 줄여 조작부가 보이게 했다.

## 기존 사이트 원문 자료

- `docs/source-migration/pages.jsonl`의 공개 페이지 수집본 8,239개 URL을 원천 자료로 사용한다. URL 순서·페이지 번호 중복과 검색 결과 목록 화면을 정리해 `dist/source-archive.json`에 국문 1,215건과 영문 809건, 합계 2,024건의 본문 텍스트를 로컬에 수록했다. 원문 상세 게시글 2,010건과 회사·채용·정책·대문 등 독립 페이지 14건이다.
- `source-archive.html`에서 회사·사업/기술·사업/연구/학술·장비·공지/보도·채용·정책별 검색, 24건 단위 페이지 이동, 각 원문 상세 보기를 제공한다. 원문 URL·수집일·본문 출처 해시와 이미지·첨부 참조를 유지한다.
- 원래 페이지의 공통 메뉴와 푸터는 상세 본문에서 제외했다. 원천 수집본은 수정하지 않았다. `scripts/verify_public_archive.py`는 중복 ID, 빈 본문, 깨진 문자, 본문과 원천 자료의 일치를 검사한다.
- 이 이관은 **가시 텍스트** 보존이다. 원래 ASP 게시판의 화면 구조·댓글·첨부 파일과 이미지 자체를 복원한 결과는 아니다. 국문 자료의 이미지 URL 고유 참조는 520개이고 인증·면허 페이지에 이미지 참조 131개가 있다. 현재 검수된 로컬 인증 미리보기는 7장이다. 수집 시 `/upload/`와 `/site/`는 robots 제한으로 받지 않았다. 모든 원본 매체를 그대로 삽입하려면 원본 CMS 내보내기 또는 사용 가능한 파일 묶음이 필요하다.
- 이 자료실은 2026-09-20 공개 사이트의 스냅샷이다. 이후 추가·수정 게시글의 자동 동기화는 없다. 개인 연락처, 인증 문서 유효성·공개 범위, 이미지 권리/민감 정보의 공개 전 검토가 남아 있다.

## 영상 상태

- 회사 메인·전문 분야·회사 소개의 새 영상은 아직 승인된 파일이 없다. 메인은 실제 위치가 아닌 광역 연안 콘셉트 스틸을 쓰고 영상 준비 중임을 표시한다.
- `09-20260928-HOME-FILM-REVISION.md`와 `10-HIGGSFIELD-PRODUCTION.md`에 광역 현실 뷰의 회사 영상·컷별 프롬프트·AX 별도 영상 범위를 정리했다. Higgsfield CF01 생성은 요금제 제한으로 거절되어 생성 영상이나 크레딧 차감이 없다. 기존 4개 AX UI 캡처 영상은 승인된 내부 데모 소재이나, 메인 회사 영상이나 완성된 AX 홍보 영상으로 표시하지 않는다.
- 이전 Google Flow 제작 파일을 페이지와 활성 영상 매니페스트에 연결하지 않았다. 과거 파일의 삭제는 보존/삭제 판정과 자동 검토 범위를 확인한 뒤 별도로 처리해야 한다.

## 확인한 것과 확인하지 못한 것

- 내부 미리보기 `http://127.0.0.1:18102/`에서 FHD 1920×1080 메인 AX·GeoDAP 패널과 AX 전체 화면 대화상자, 모바일 390×844 메인·연구·플랫폼 배치를 눈으로 확인했다. 모바일 가로 넘침 없음. QHD 2560×1440, UHD 3840×2160에서는 플랫폼 프레임 폭과 제목 글자 크기 비율 및 가로 넘침을 확인했다. CSS 뷰포트 기준이며 실제 물리 모니터 검수는 아니다.
- 연구 카드는 모바일 화면에서 휠 이동 후 `03 / 03` 상태가 표시됐다. AX 갤러리는 휠로 `01 / 09`에서 `02 / 09`로 이동했다.
- KO/EN 18개 경로와 57개 로컬 참조의 HTTP 2xx, 9개 정적 메타데이터, 영상 라이프사이클, 자료실 2,024건 원문 일치 검사가 통과했다.
- Safari, 물리 모바일 기기와 물리 FHD/QHD/UHD 모니터, 재생 성능과 사용자 디자인 승인, 공식 도메인 배포는 확인하지 않았다. 현재의 시각 개선을 최종 디자인 합격으로 기록하지 않는다.
