사용 여부는 HTML·CSS·JavaScript·JSON과 동적 경로 및 유지보수 도구의 입력까지 확인한다
`docs/handoff/site-files.sha256`은 이번 정리 후 보존한 웹 파일의 기준 해시 목록이다
텍스트는 LF와 CRLF 차이를 정규화하고 이미지·영상·폰트 등 바이너리는 원본 바이트를 그대로 대조한다
사이트를 변경하면 검토한 파일의 해시만 갱신하며 검사 통과를 위해 무조건 다시 생성하지 않는다

## Git에서 제외하는 파일

원본 다운로드와 생성 중간본 및 미채택 결과물·실패 영상·과거 캡처·대량 수집 로그·중복 PDF는 로컬 별도 보관소에 둔다
세션 로그와 실행 PID 및 터널 상태·임시 검수 결과는 `.openai/local/` 또는 `tmp/`에 둔다
과거 문서 전체와 소스 폴더를 편의상 다시 `git add`하지 않는다
새 파일은 현재 실행 또는 설명·인계에 필요한 이유가 있을 때만 커밋한다


GitHub에서 현재 버전을 내려받으면 웹 실행과 현재 코드 유지보수가 가능하다
