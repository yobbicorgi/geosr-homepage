## 발견하여 수정한 문제

1. 원문 JSON만 보존하고 인사말·CI·채용·정책·교통 안내의 실제 진입점과 화면이 없던 문제
2. 영어 원문에 `Copyright by 2024` 푸터가 본문으로 포함되던 문제
3. 새 메뉴의 `board` 쿼리를 목록 페이지가 무시하던 문제
4. 공개 CI ZIP과 회사 소개서가 원문 자료 상세의 첨부로 표시되지 않던 문제
5. 크롤러가 일반 이미지 주소를 공백에서 잘라 한글 파일명의 참조가 훼손되던 문제

과거 캡처의 훼손된 참조 문자열은 수정하지 않았으며 300개 상세 HTML을 새로 읽어 정상 참조와 새 해시를 별도 보존

## 미디어 이관 결과와 보존 경계

- 소유자가 공개 자료 전체 이관을 재차 명시하여 기존 크롤러 제외 경로에 있던 직접 공개 링크도 좁은 범위로 보존
- 로그인이나 접근 제한을 우회하지 않았으며 geosr.com과 공개 본문에 직접 삽입된 회사 Mailplug 이미지 7개만 조회
- `download.asp` 첨부 6종을 모두 회수하여 본문 상세에 다운로드 연결
- 신기술 인증 공고 PDF·해양역학 PDF 도서·보도 이미지 4종의 파일 바이트와 해시 및 원문 글 연결을 보존
- 공백이 포함된 파일명의 정상 주소를 재조회하였고 다운로드 실패 및 미처리 파일은 0개
- HWP 본문의 실제 OLE 문서 구조를 읽어 빈 지원서·자기소개서·경력기술서·동의서 양식임을 확인했으며 공개용 다운로드 연결
- 회사 소개서와 CI 및 이미지의 동일 바이트 중복은 정리했고 모든 원본 URL의 증빙은 원장에 유지
- 인증 보호 대상 2건의 원본 주소 또는 이미지 미리보기를 새로 공개하지 않음
- 이전 코드의 `newsletter-1542`를 뒷받침하는 원문은 없어 뉴스레터 메뉴와 가상 샘플 항목을 제거
- 이번 재조회 대상은 캡처에서 미디어 참조가 확인된 300개 페이지이며 2024개 전부를 같은 시점에 다시 조회했다고 주장하지 않음
- 영어 원사이트의 누락 및 한국어 잔존은 별도 locale overlay로 보완 중이며 원문과 번역을 혼합 저장하지 않음
