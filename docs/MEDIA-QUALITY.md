# GeoSR 이미지·영상 제작 및 검수 기준

2026-09-17 사용자 수정 반영

## 기본 방향

실제 국내 환경을 토대로 관측과 분석의 원리가 시각적으로 읽히는 영상을 만든다
바다 위 파란 네온 선으로 모든 분야를 표현하지 않는다
드론과 무인선은 여러 관측 수단 중 일부이며 회사 전체의 주인공으로 고정하지 않는다

모든 장면은 사실적인 기반 화면 → 기술의 작동 → 데이터의 변환 또는 해석이라는 구체적인 흐름을 갖는다
서로 다른 기술을 보여주는 편집 연결을 실제 자동 연동 기능으로 오인시키지 않는다

## 적용 전 필수 체크

| 항목 | 확인할 내용 | 반려 사례 |
|---|---|---|
| 지리 | 한반도·제주·주변 국가의 위치와 해안선 대조 | 제주 중복·가짜 섬·외국형 절벽을 국내 장소로 사용 |
| 항만 | 방파제 연결·개구부·부두·항로·육상 접근 확인 | 육지 관통 항로·닫힌 항 입구·용도를 알 수 없는 부두 |
| 지형 | 육지·수면 마스크와 경사·수위 관계 확인 | 수면이 산을 통과하거나 데이터가 육지 전체를 덮음 |
| 장비 | 형상·설치 방향·관측 원리·대상 확인 | CTD를 소나로 표현·광학 드론이 깊은 수심을 직접 측정 |
| 물리량 | 수온·염분·클로로필·유속·수위·농도를 구분 | 서로 다른 물리량을 같은 파란 흐름으로 표현 |
| 관측과 해석 | 관측·모델·예측·보간·생성 개념을 구분 | AI 복원을 실제 위성 관측으로 표시 |
| 수치 주장 | 날짜·단위·해상도·범례·출처 확인 | 생성 이미지에 근거 없는 수치·정확도·예측 성능 삽입 |
| 영상 연속성 | 시작·중간·끝의 카메라·해안선·장비·광원 유지 | 장면 사이 섬 생성·소멸·부두 이동·장비 변형 |
| 웹 적용 | 문구 여백·모바일 크롭·명암·루프·정지 화면 확인 | 핵심 피사체 잘림·제목과 데이터 겹침 |

검수 상태는 `보류` `연출 가안 검수` `자료 검증` `최종 제작 검수`로 구분한다
연출 가안 검수는 실제 관측값이나 실제 프로젝트 결과의 정확성을 인증하지 않는다
확인할 근거가 없으면 사실로 단정하지 않는다

## 분야별 이미지 → 영상 연속 설계

| 장면 | 시작 | 기술이 드러나는 변화 | 마무리 / 연결 | 검수 핵심 |
|---|---|---|---|---|
| 국내 연안 공간 조사 | 실제 국내 해안의 정사·사선 영상 | 같은 해안의 육상 점군이 국소적으로 드러나고 표면이 형성됨 | 지형면이 모델 장면의 기준 지형으로 연결 | 수심은 별도 수로측량 자료가 있어야 표현 |
| 해양 관측 | 실제 형상의 조사선·부이·CTD 등 적합한 장비 | 측정 위치 또는 수층이 드러나며 자료가 정리됨 | 수온·염분 등 해당 관측량으로 연결 | 장비마다 가능한 측정량 구분 |
| 환경·화학 분석 | 시료 채취 또는 실제 분석 장비 근접 | 시료 식별에서 성분 분석으로 초점 전환 | 실제 분석 대상에 해당하는 정제된 분포 표현 | 임의 화학반응·분자·결과값 금지 |
| 생태·서식환경 | 국내 갯벌·염습지·연안 생태 현장 | 조사 구역 또는 검증된 대상만 분리해 표시 | 서식환경과 공간 변화의 관계 | 실제 대상 종과 생태 조건 검증 |
| 수치모델·연안 변화 | 실제 해안선·방파제·지형 | 파랑 변형 또는 수위·이동 확산 중 하나만 명확히 전개 | 관측과 해석 비교 또는 시간 변화 | 물이 구조물을 통과하지 않음·조건 없는 실제 결과 주장 금지 |
| 위성·원격탐사 | 한반도 주변을 바라보는 지구 관측 장면 | 같은 지역의 수온장 → 표층염분장 → 클로로필장이 차례로 분리 | 정렬된 다층 정보를 함께 해석하는 장면 | 동일 해안선·영역·투영 유지·다중 센서 자료 통합으로 설명 |
| 환경 AI | 관측 자료의 유효 영역과 결측 또는 대상 구분 | 탐지·복원·예측 중 검증된 기능 하나의 처리 과정 | 원자료와 결과를 구분해 제시 | 단순 스캔 효과를 AI 성능으로 주장하지 않음 |
| AX 전체 | 실제 기능별 대표 장면 | 분야별 화면의 짧은 편집 전환 | AX 소개 페이지와 9개 개별 소개 | 실제로 존재하지 않는 시스템 간 자동 연결 금지 |
| AX 개별 | 실제 플랫폼의 대표 화면 | 검수한 기능 화면 3개를 짧게 전환 | 대표 화면으로 루프 | 실제 UI 캡처·현재값으로 오인하지 않는 캡처 시점 표기 |

기업 메인 영상과 AX 전체 영상은 별도다
기업 메인에서 한 분야가 전체 회사를 대변하지 않도록 관측·분석·모델·AI·원격탐사를 균형 있게 편집한다

## 위성 장면 팩트체크 근거

- Sentinel-3는 SLSTR와 OLCI 등 서로 다른 관측 기기를 사용한다
  - https://www.esa.int/Applications/Observing_the_Earth/Copernicus/Sentinel-3/Data_products
- 해수면 염분 자료에는 SMOS·Aquarius·SMAP의 L-band 마이크로파 관측이 사용된다
  - https://climate.esa.int/en/news-events/Sea-Surface-Salinity-Record-Extended/
- 따라서 현재 한 개의 일반 위성 모형은 관측을 상징하는 연출이며 세 장의 분포장을 같은 센서의 단일 촬영 결과로 설명하지 않는다
- 수온·염분·클로로필층의 색은 현재 설명용 가안이며 실제 관측값·특정 날짜·해상도·정확도를 표시하지 않는다
- 최종 영상의 지도층은 검증된 동일 좌표계의 데이터로 합성하고 생성 모델이 해안선을 다시 그리게 하지 않는 방식을 우선한다

현재 웹 동작 검수 결과는 REVIEW-QA.md를 따른다
실제 플랫폼에 표시된 표층염분 제품과 위성 장면의 일반적 자료층은 별도로 검증한다
특정 광학 센서의 처리 제품을 직접적인 염분 관측으로 설명하지 않으며 알고리즘·출처 확인 전에는 제품 원리를 단정하지 않는다

최종 영상 검수는 시작·중간·끝뿐 아니라 전체 프레임에서 지형과 장비가 변형되는지도 확인한다
검수되지 않은 프레임을 연결한 영상은 전달하지 않는다
