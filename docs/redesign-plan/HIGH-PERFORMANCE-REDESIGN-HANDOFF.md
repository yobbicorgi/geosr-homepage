# 고성능 모델 재설계 인계

작성일 2026-09-18
상태: 작업 일시 중단
기준 저장소: `https://github.com/yobbicorgi/geosr-homepage.git`
현재 기준 커밋: 이 문서를 포함한 다음 커밋

## 다음 작업의 출발점

현재 목업을 단순 보정 대상으로 삼지 않는다
홈페이지의 첫 화면부터 정보 구조와 표현 방식을 다시 설계한다
기존 구현은 자료 구조와 실제 장비 자산과 AX 화면 기록을 보존하는 참고본이다
시각 언어와 페이지 조합은 새 방향으로 교체할 수 있다

## 사용자 검토에서 확정된 요구

- 한국 기업의 신뢰감과 해외 기술 기업의 정교한 디지털 경험을 함께 보여준다
- 자연 풍경만 앞세우지 않는다
  - 현장 측량과 해양 관측
  - 실제 조사선과 무인선
  - 실험실 분석 장비
  - 수치모델과 공간정보
  - 위성 원격탐사와 AI 해석
  - AX 제품 경험을 한 흐름 안에 설득력 있게 연결한다
- 첫 화면은 최종적으로 전체 화면 영상이다
  - 영상 전에는 검수된 정지 프레임이나 명확한 영상 제작 슬롯만 둔다
  - 단순한 어두운 그라데이션이나 일반적인 네온 격자로 대체하지 않는다
- 플랫폼 화면은 실제 UI를 16:9 전체 화면으로 사용한다
  - 좌우 빈 공간과 메뉴 일부만 보이는 캡처를 쓰지 않는다
  - 실제 조작 흐름은 짧은 3초 내외 빠른 화면 기록으로 보인다
- AX Platform과 GeoDAP은 독립된 두 서비스다
  - AX는 이 홈페이지 안에서 소개한다
  - GeoDAP은 외부 진입으로 연결한다
- 한글과 영문 모두 자연스럽고 실제 기업 문장처럼 작성한다
- 화살표는 외부 이동과 개별 자료 열기처럼 목적이 분명한 경우만 쓴다
- 인증과 면허와 지식재산권은 한 줄로 과도하게 늘어놓지 않고 분류별로 보여준다
- 생성 이미지와 향후 영상은 한국의 해안과 항만과 하천과 육상 환경을 사실적으로 다뤄야 한다
- 사람과 손은 생성 이미지에 넣지 않는다
- 회사 장비를 표현할 때는 실제 GeoSR 장비 원본을 기준으로 한다

## 현재 시안에서 버릴 방향

- 큰 제목만 있고 영상 대기 상태가 넓게 비어 보이는 메인
- 자연 경관 중심의 인상으로 기술과 연구가 약해지는 구성
- 카드 하나의 이미지가 바뀌는 수준의 단순 전환
- 파란 네온 선과 가상 격자를 반복하는 해양 AI 이미지
- 긴 가로 레일과 과도한 여백으로 자료가 작아 보이는 인증 영역
- 일반적인 한국 엔지니어링 회사 홈페이지의 메뉴와 배너 구성

## 새 디자인 단계

### 1. 디자인 언어 먼저 확정

코드를 바로 수정하지 말고 데스크톱 기준 메인 화면의 3개 서로 다른 방향을 만든다
각 방향은 첫 화면과 기술 소개와 AX 소개와 신뢰 자료와 문의 마무리까지 한 화면 흐름으로 설명한다
선정 기준은 최신성만이 아니라 GeoSR의 관측과 분석 장비와 연구 성과가 첫 인상에서 읽히는가다

권장 방향은 기술 장비의 촬영과 데이터가 연결되는 편집형 시네마틱 경험이다
화면마다 거대한 카드나 경관 사진을 반복하지 말고 실제 장비 프레임과 지도와 분석 장면과 제품 화면이 교차하는 리듬을 설계한다

### 2. 메인 영상 프리비주얼을 먼저 설계

최종 약 60초의 루프 구조를 확정한 뒤 그 첫 프레임을 홈페이지에 쓴다

| 구간 | 내용 | 근거 |
| --- | --- | --- |
| 00–10초 | 한반도 주변 위성 기반 환경 레이어가 순서대로 올라오는 시작 | 검수된 위성 콘셉트 또는 실제 위성 원본 |
| 10–20초 | 실제 GeoSR 무인선이 측량 동선으로 이동 | `assets/usv-source.jpg`, `assets/usv.png` |
| 20–30초 | ICP 등 실험 분석 장비의 샘플 분석 | `assets/equipment-icp.png` |
| 30–40초 | 수치모델과 공간정보의 해석 장면 | 검증 가능한 모델·지도 화면 |
| 40–50초 | AX의 탐지와 예측과 모니터링 제품 흐름 | 실제 AX UI 녹화 |
| 50–60초 | 다음 위성 프레임으로 매끄럽게 회귀 | 앞 장면과 지형·조명 연속성 검수 |

각 장면은 정지 이미지부터 먼저 검수하고 이후 Flow 저화질 초안과 Higgsfield 고해상도 제작으로 이어간다

### 3. 페이지 구조를 다시 설계

1. 메인 영상과 한 줄의 기업 관점
2. 현장 장비와 조사에서 출발하는 기술 증거
3. 관측과 분석과 예측을 잇는 연구 방식
4. AX Platform의 실제 제품 경험
5. GeoDAP의 독립된 Earth Data Intelligence 진입
6. 인증과 면허와 지식재산권의 밀도 있는 신뢰 증거
7. 대표 연구·사업·학술 기록
8. 문의와 회사 정보

새 구조에서는 기술 분야 이름을 기존 사이트의 네 개 큰 메뉴처럼 나열하지 않는다
각 분야를 조사 과정과 실제 장비와 결과물로 연결해 읽히게 한다

### 4. 인터랙션 원칙

- GSAP과 ScrollTrigger는 장면 전환과 스크롤 고정 구간에만 쓴다
- Three.js는 위성·공간 레이어 같은 실제 개념을 보조할 때만 쓴다
- Lenis는 페이지 전체 움직임을 과장하지 않는 범위에서만 쓴다
- 제품 화면은 CSS 확대와 마스킹과 실제 짧은 화면 녹화로 깊이를 만든다
- 인증 자료는 현재의 3개 분류 방식을 유지하되 새 디자인 시스템 안에서 다시 배치한다
- 반응형과 `prefers-reduced-motion`을 각 장면 설계 단계부터 포함한다

## 반드시 다시 검수할 항목

- 한글 카피의 자연스러움과 임원진이 선호한 굵은 강조 방식
- 첫 화면이 환경 풍경 사이트처럼 보이지 않고 기술 회사로 읽히는지
- 각 이미지가 실제 업무와 이어지는지
- 한반도와 한국 연안과 항만과 하천의 지리적 형태가 맞는지
- 위성 레이어가 수온과 염분과 클로로필 등 실제 물리량처럼 오인되지 않는지
- 실제 결과가 아닌 가안에는 명확한 표기가 있는지
- 16:9 영상과 제품 녹화에 잘림과 여백이 없는지
- AX와 GeoDAP의 역할이 혼동되지 않는지
- 외부 링크 외에는 화살표가 남발되지 않는지

## 현재 작업 상태

- 마지막 사용자 승인 범위의 구현은 `27fd4e6 Refine credential transitions and link cues`까지다
- 그 이후 시작했던 메인 히어로 포스터 변경은 사용자 중단 요청에 따라 되돌렸다
- 영상 생성과 유료 Higgsfield 작업은 이 인계 시점에 실행하지 않았다
- 다음 세션은 이 문서를 읽고 디자인 보드와 메인 프리비주얼부터 새로 시작한다
