# 세부 페이지 로컬 화면 캡처

내부 미리보기 `http://127.0.0.1:18102/`의 2026-09-29 캡처다. `*-qhd.png`는 2560×1440, `*-1280.png`는 1280×800, `*-mobile.png`는 390×844 CSS viewport에서 촬영했다. 국문 8개 경로의 첫 화면과 일부 영문 회사·채용·개인정보 첫 화면을 담았다.

국문 첫 화면은 마지막 문구 정리 전의 배치 점검 캡처다. 회사·채용 제목과 문의 안내 문구는 이후 코드에서 수정했으므로 이 파일을 최종 카피 확인 자료로 사용하지 않는다. 최종 스크롤 중간·하단의 시각 검수와 실제 기기 검수는 별도로 남아 있다.
