# GeoSR 이미지 후보 검수 v2

## 결과와 한계

메인 검수용 concept keyframe을 만들고 최종 화면에 사용할 수 있는지 다시 검수했다. 최종 통과본은 `flow-lab-ecology-v1.png` 한 장뿐이다. 탈락한 생성 이미지는 공개본과 작업 폴더에서 제거했다.

이 이미지는 GeoSR의 실제 위성 관측, 조사 장비, 실험실, 측정값 또는 연구 결과를 증명하지 않는다. 지리·장비의 외형 검수는 명백한 오류를 거르는 concept 검수이며, 실제 데이터나 현장 자료로 사용하려면 별도 출처 확인이 필요하다. HTML/CSS/JS 연결은 하지 않았다.

## 후보별 검수

### A — `dist/assets/generated/candidates-v2/home-hero-orbit-v1.png`

- **용도 / 웹 슬롯:** 홈페이지 첫 화면의 궤도 hero keyframe 후보. 왼쪽 아래 제목 공간을 전제로 한다.
- **프롬프트 핵심:** 실제 지구 관측 사진 같은 궤도 촬영, 화면 중앙의 동아시아와 한반도, 화면 왼쪽 위의 작은 지구관측 위성, 왼쪽 아래 어두운 여백. 지도·데이터층·궤도선·텍스트 없이 생성했다.
- **사실성 검수:** 중국 동부가 서쪽, 한반도가 중앙, 러시아 극동이 북쪽, 일본 열도가 동쪽으로 보이며 위치가 뒤바뀐 명백한 오류는 없다. 위성은 대륙보다 훨씬 작고 양쪽 태양전지판이 단순하게 보인다. 지구 곡률·구름·대기광은 자연스럽고 오버레이는 없다. 왼쪽 아래는 어두운 지표와 희소한 도시 불빛이라 제목 여백으로 사용할 수 있지만 완전히 비어 있지는 않다.
- **실패 가능성:** 지리와 위성 센서의 세부 형상은 생성 concept 수준이며 정밀 지리 자료나 특정 위성 모델과 대조한 결과가 아니다. 도시 불빛과 지표 질감이 제목 가독성에 영향을 줄 수 있다.
- **최종 결론:** 탈락. 생성 이미지의 지형과 해안선을 공식 지리 자료처럼 신뢰할 수 없고 홈페이지의 대표 지구 화면으로 사용하기에 근거가 부족하다. 기존의 검증 가능한 Earth plate를 유지한다. 파일은 작업 폴더에서 제거했다.

### B — `dist/assets/generated/candidates-v2/flow-observation-ocean-v1.png`

- **용도 / 웹 슬롯:** 해양 관측 소개/flow 영역의 중앙 미디어 keyframe 후보.
- **프롬프트 핵심:** 흐린 한국 연안, 연구선 측면 A-frame에서 해수면으로 내려가는 CTD rosette, 팽팽한 케이블, 먼 배경의 작은 관측 부이 한 개. 원형 프레임 안에 세로 Niskin bottle과 중앙 센서가 있는 구조를 지정했다.
- **사실성 재검수:** 케이블과 인양점의 실제 하중 경로가 명확하지 않고 rosette가 선측과 지나치게 가까워 충돌 위험이 있다. A-frame과 장비 중심선도 자연스럽지 않으며 tag line이나 회전 제어가 보이지 않는다.
- **최종 결론:** 두 생성본 모두 탈락. 물리적으로 신뢰할 수 있는 관측 장면으로 사용할 수 없어 코드에 연결하지 않았고 파일도 작업 폴더에서 제거했다.

### C — `dist/assets/generated/candidates-v2/flow-lab-ecology-v1.png`

- **용도 / 웹 슬롯:** 해양환경·생태 분석 소개/flow 영역의 중앙 미디어 keyframe 후보.
- **프롬프트 핵심:** 사람 없는 현실적인 실험대, 갈색 유리 시료병과 투명 채수병, 플랑크톤 슬라이드와 현미경, 여과 장치와 플라스크·튜브, 분광광도계를 서로 구분해 배치했다. 해수 시료는 맑거나 약한 탁도 범위로 제한했다.
- **사실성 검수:** 병, 현미경, 슬라이드/샬레, 여과 장치, 분광광도계가 각각 식별되고 서로 융합되지 않았다. 시료는 형광 청색이 아니고 읽을 수 있는 라벨·수치·결과가 없다. 사람, 손, 장갑도 없다.
- **실패 가능성:** 생성된 장비 조합은 실제 GeoSR 보유 장비나 확정된 절차를 나타내지 않는다. 이미지의 물리적 구성이 그럴듯해 보여도 특정 분석 결과·시료 종류를 주장할 수 없다.
- **검수 결론:** 최초본의 배경 원형 도식/사진이 가짜 차트로 오인될 수 있어 제거했다. 작업대 장비는 유지한 수정본을 통과 후보로 선택했다.
