# 영상 제작 시 인계 기준

갱신 2026-09-30

현재 배치 파일과 기존 생성 파라미터는 [사용 미디어 인계](../media/CURRENT-MEDIA.md)를 확인한다
현재 상태의 근거는 `dist/film-manifest.json`이며 과거 생성 완료나 선택 판정만으로 새 영상의 합격을 주장하지 않는다
전체 제작 이력과 원본 영상 및 이전 프롬프트 카드는 [별도 보관소](../handoff/REPOSITORY-POLICY.md)에 있다

## 다음 제작 절차

1. 사용자의 최신 요청과 [장면 설계](reviews/20260929-company-film-scene-system.md)를 확인한다
2. 제작할 위치와 대상 및 입력 원본을 고르고 실제 파일을 열어 검토한다
3. 시작 상태와 핵심 동작 및 종료 상태와 카메라 경로를 정확히 설계한다
4. 탐지 박스·분할 마스크·모델 격자·분석 패널은 생성 단계에서 대상과 함께 만들며 뒤에서 임의로 덧그리지 않는다
5. 사용자의 기존 모델 지정은 Seedance 2.0이며 실제 지원 조건과 현재 비용 및 승인된 예산을 다시 확인한다
6. 한 장면씩 생성하고 전체 재생과 연속 프레임으로 구조·물리·지형·주석 추적을 검수한다
7. 검수한 파일만 고유 슬롯에 연결하고 대체 이미지와 조작 및 모션 감소·화면 밖 재생 정지를 확인한다
8. 프롬프트와 입력 hash 및 작업 ID와 실제 비용 및 판정 근거를 현재 사용 미디어 기록에 남긴다

기본 홈페이지 영상은 16:9 무음 1080p다 새 크레딧 소비나 모델 조건은 과거 영수증에서 추정하지 않는다
과거 공개 업로드 URL은 현재 입력 주소가 아니다 원본 확보와 지형·장비 검수 후 다시 업로드한다
사진의 pan·zoom과 잔물결만으로 업무가 보이는 장면이라고 합격시키지 않는다
영상을 검수한 뒤 연결과 전환만 편집하며 잘못된 구조를 후반 그래픽으로 감추지 않는다
현재 웹 실행 버전과 미래 장면 확장 계획 및 유료 생성 승인을 구분한다
