# 영상 과학적 검수와 품질 판정

2026-09-22 메인 직접 검수

## 판정 범위

현재 결과는 720p 콘셉트 편집 초안이다 학술적 검증 완료나 실제 관측 기록으로 표시하지 않는다
회사 60초 영상과 AX 30초 콘셉트 영상을 분리해 시험 편집했으나 연결 품질 미달로 두 편 모두 홈페이지 연결을 해제했다 회사 영상에는 AX UI 및 AX 콘셉트가 없다
현재 메인은 8초 오프닝 초안만 재생하며 회사 소개 본편과 AX 메인은 준비 중으로 표시한다
실제 UI 영상은 하단 개별 플랫폼 소개에만 사용한다

## 확인한 원리와 표현 한계

- 다중빔 음향측심은 음향 신호로 수심을 측정한다 부채꼴은 선박 항적에 수직인 횡방향 관측 폭을 표현한다 실제 바닷속에 흰 빛이 보인다는 의미가 아니다
- C05 첫 이미지의 방향이 모호해 폐기하고 선미를 보는 방향으로 다시 생성했다 최종 후보에서도 트랜스듀서 설치 위치와 빔 원점의 연결을 단정할 정도로 장비가 선명하지 않다 실제 장비 설치도나 성능 설명에는 사용하지 않는다
- 소나 화면의 해저 점군과 해저 지형은 설명용 가상 표현이다 실제 측량 결과가 아니다
- 일반 지형 라이다로 깊은 해저를 투시하는 연출을 금지한다 수심측량 라이다도 파장과 수질 및 수심 조건에 제약이 있다
- NASA 자료의 수온과 염분은 월 자료이며 클로로필은 일별 궤도 관측 자료다 같은 요청 날짜가 동시 관측을 뜻하지 않는다 결측을 생성형 이미지로 채우지 않는다
- 위성은 특정 실제 임무나 기종을 재현했다고 주장하지 않는다 한 위성이 수온·염분·클로로필을 모두 직접 측정한다는 설명을 넣지 않는다
- 실험실은 사람 없는 개념 장면이다 실제 GeoSR 연구실 촬영이나 특정 분석 장비 모델로 소개하지 않는다
- 수중 C06은 연결 컷일 뿐 ROV나 수중 센서 관측이 구현된 장면이 아니다

## 다음 제작의 합격 조건

장면별로 무엇을 측정하고 무엇을 산출하는지 먼저 정한다
장비의 고정점과 케이블 장력 및 광학·음향의 관측 방향을 참조 자료와 비교한다
지도는 해안선과 투영 및 자료 범위를 대조한다 실제 데이터와 설명용 그래픽을 구별한다
시작·중간·끝 프레임뿐 아니라 전체 재생으로 물체 증식과 연결 파손 및 전환 핸들을 확인한다
멋진 조명이나 카메라 움직임만으로 기술적 내용이 충족됐다고 판정하지 않는다
크레딧이 남았다는 이유만으로 불합격 장면의 유사 프롬프트를 반복하지 않는다 먼저 참조 이미지와 연출을 수정한다
