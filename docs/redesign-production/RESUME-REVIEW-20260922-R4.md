# 홈페이지 재개 작업 R4 기록

2026-09-22 · 메인 직접 설계와 구현 및 검수

## 반영한 구성

- 회사 소개 첫 화면을 사람 없는 실험실 콘셉트와 겹쳐 배치한 문구로 재구성했다
- 전문 분야는 고정되는 제목과 여섯 분야의 간결한 탐색 목록으로 구성했다
- 연혁은 읽는 위치에 따라 연도를 강조하는 세로 흐름으로 변경했다
- 회사 소개 탐색 메뉴는 현재 위치를 표시하며 스크롤을 가로채지 않는다
- AX 첫 화면은 시설물 탐지 장면에 제목을 겹쳐 배치하고 화면 높이를 채운다
- 홈페이지의 AX 소개는 전폭 16:9 장면을 사용한다
- AX와 GeoDAP의 독립된 소개 및 GeoDAP 외부 연결을 유지했다
- 영상의 제작 단계는 명시하며 실제 플랫폼 미리보기와 생성 콘셉트를 분리했다

## 검수 조건과 결과

대상은 `http://127.0.0.1:18102/`이며 공식 도메인 배포가 아니다

UHD DPR 1 캡처는 브라우저 캡처 도구에서 화면 타일이 반복되는 오류가 있었다
CSS viewport 3840×2160은 유지하고 캡처 픽셀 밀도만 0.5로 낮춰 올바른 전체 이미지를 확인했다
이는 UHD 물리 모니터의 DPR 1 표시를 직접 검수한 것과 같지 않다
페이지 zoom이나 transform 확대는 사용하지 않았다
증거 이미지는 `visual-review-r4`에 보존했다

전문 분야 및 연혁 탐색과 현재 위치 표시를 실제 클릭으로 확인했다
AX 탐지에서 예측 탭으로 전환한 뒤 동영상 1개와 재생 버튼 1개만 남는 것을 확인했다
실제 UI 표시 영역은 모바일에서도 335×188.4375로 16:9를 유지했다

자동 검증은 한·영 16개 경로와 56개 참조 및 메타데이터·접근성 계약과 영상 생명주기 검사를 통과했다
전체 사이트의 최종 디자인 승인이나 모든 콘텐츠 완성을 뜻하지 않는다

## 영상과 예산

AX 탐지 8초 초안은 연결했고 위성 오프닝 V4는 강체 이동 기준 미달로 보류했다
이번 재개에서 20크레딧을 사용했고 실제 Flow 잔액은 65다
회사 60초와 AX 30초 본편은 미완료다
검수 실패를 크레딧 부족으로 기록하지 않는다

## 남은 핵심 작업

1. 지구 → 위성 → 한반도 연결을 제어 가능한 합성 구조로 확정
2. 실제 지리와 자료 출처를 고정한 관측·분석 연결 장면 제작
3. 해상과 수중 및 실험 분석을 잇는 회사 60초 편집 완성
4. 탐지와 별개인 AX 예측·모니터링 콘셉트 장면 제작
5. 남은 플랫폼의 실제 16:9 기능 녹화와 공개용 자료 검수
6. 나머지 세부 페이지의 구성과 문구 품질을 같은 기준으로 추가 검수

기존 사용자 반려 지형은 재사용하지 않는다
현재 생성·보류·연결 상태는 `../redesign-next/10-HIGGSFIELD-PRODUCTION.md`를 기준으로 이어간다
