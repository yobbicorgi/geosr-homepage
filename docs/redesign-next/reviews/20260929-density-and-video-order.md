2026-09-29 내부 미리보기에서 확인한 값이다 공식 사이트 배포 상태를 뜻하지 않는다

## 동일 CSS viewport 비교

레퍼런스 수치는 한화오션 공개 페이지를 같은 CSS viewport로 열어 실제 계산 스타일에서 읽었다 GeoSR은 로고와 콘텐츠 폭을 그대로 복사하지 않고 여섯 개의 자체 메뉴가 중앙에 모이도록 정렬했다

## 이번 조정

- 메인 제목과 본문 및 버튼에 쓰는 공통 크기 단위에 상한을 두어 QHD에서 과하게 커지지 않도록 했다
- 사업 분야의 휠 스크롤 구간을 280svh에서 240svh로 줄였다 좌우 갤러리와 탭 조작은 유지한다
- GeoDAP 전체 화면은 잘림 없이 최대 1660px 폭으로 표시한다
- 회사 소개 미디어와 파도 장면의 과한 세로 길이를 줄였다
- 공통 메뉴는 같은 너비의 넓은 여섯 칸 대신 콘텐츠 폭에 맞는 중앙 정렬로 바꿨다
- 하단은 상위 메뉴와 세부 링크의 글자 크기를 구분했다
- 수백 건을 탐색하는 소식과 연구 게시판은 필터 24px 및 항목 제목 24px을 QHD 상한으로 두고 행 여백을 32px로 줄였다 원문 제목은 수정하지 않았다

## 검수

- 1288×720에서 회사 소개 메뉴와 도입부를 확인했다
- 390×844에서 회사 소개 도입부와 전체 메뉴 열림 및 가로 넘침 없음을 확인했다
- 2560×1440에서 메인 제목 100px, 섹션 제목 52px, 상단 메뉴 18px, 헤더 108px을 확인했다
- 18개 한영 경로와 201개 로컬 참조 요청 및 메타데이터·접근성 기본 검사가 통과했다
- QHD 소식 목록의 384건 분류와 첫 12개 렌더링 및 가로 넘침 없음을 확인했다
- 전체 페이지 한 장 캡처는 스티키 구간과 지연 이미지가 비어 보일 수 있어 최종 검수 자료로 쓰지 않는다 장면별 실제 스크롤 캡처를 사용한다
