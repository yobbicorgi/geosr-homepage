# 저장소 정리 기록

사용자 요청 · 현재 버전 유지와 인계에 필요한 파일만 GitHub에 보존

## 정리 범위

정리 전 기준 커밋 `d223d6e`
기존 추적 파일 1411개 · 전체 1148768429바이트
666개 파일 · 681133558바이트를 저장소 밖의 [로컬 보관소](REPOSITORY-POLICY.md)로 이동했다
현행 인계 문서와 검증 도구를 포함한 정리 후 추적 파일은 756개이며 약 446.1MiB다
이동 전후 파일별 SHA256을 대조했으며 보관소의 `ARCHIVE-MANIFEST.json`에 원래 경로와 크기 및 해시를 기록했다

제외한 범위는 중복 원본 영상과 미채택 이미지·실패 결과 및 이전 설계·캡처·수집 로그와 중복 PDF 및 미사용 웹 에셋·검수 코드다
현재 게시글 원문과 번역 및 연결된 이미지·첨부자료와 인증 문서 보호 상태는 유지했다
AX 갤러리의 동적 경로 8개와 개발 중 1개 서비스 설명을 보존했다
폰트 라이선스와 AX 이관 출처를 유지했다

## 코드와 문서

현재 AX 페이지에서 덮어써 사용하지 않던 이전 페이지 함수와 7개 이전 영상 슬롯 및 연결 녹화본을 제거했다
플랫폼 설명 데이터 9개는 동일하며 현재 페이지 로딩 순서를 유지했다
메인과 기술 영상·정지 이미지 및 원문 데이터의 보존 파일은 변경 전과 해시가 같다
런타임에서 변경한 파일은 미사용 코드·슬롯을 제거한 `ax-v2.js`와 `film-manifest.json` 두 개다
메인 영상의 review 메타데이터는 현재 미디어 인계문을 가리킨다
현재 웹 및 유지보수 입력 652개 파일의 기준 해시를 `site-files.sha256`에 기록했다

현재 인계 시작점과 코드 안내 및 저장소 관리 기준을 추가했다
사용 이미지 29개의 판정·출처와 관련 프롬프트 및 사용 영상 7개의 해시·제작 파라미터와 메인 편집 구간표를 보존했다
과거 원장의 제작 대기 상태와 현재 연결 상태를 구분했고 누락된 문서·캡처 링크를 수정했다
유지보수 도구는 새 출처 기록을 읽으며 수집 원본이 필요한 검사는 외부 capture 경로를 명시하도록 변경했다
임시 검사 결과가 기존 검토 원장을 덮어쓰지 않도록 출력 경로를 선택하게 했다

## Git 이력

정리 전 파일은 로컬 보관소와 이전 Git 커밋에 남아 있다
현재 브랜치 구성을 정리했으며 Git 이력 재작성과 강제 푸시를 하지 않는다
이전 main이 현재 작업 브랜치의 조상임을 확인했으며 기본 main도 동일한 정리 버전으로 fast-forward 반영한다
과거 큰 파일이 Git 저장 용량에서 사라졌다는 의미는 아니다
