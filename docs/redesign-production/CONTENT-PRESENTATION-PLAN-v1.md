# GeoSR 콘텐츠별 표현 설계 v1

2026-09-20 · 메인 에이전트 설계안 · 다음 구현의 기준을 정리하는 문서

## 이번 결정

현재 사용자는 메인 첫인상을 수용했으며 세부 페이지의 구성과 표현은 더 발전시키기를 요청했다
후속 요청은 효과를 먼저 늘리기보다 각 콘텐츠를 목록·게시판·카드·영상·인터랙션 중 무엇으로 보여줄지 먼저 설계하자는 것이다
따라서 신규 모션 구현은 중단했다
이번 턴의 결과는 아래 표현 설계안이며 이 문서의 미구현 항목을 완료한 것으로 취급하지 않는다

메인이 정보 구조·화면 구성·문구·동작을 결정하고 구현 에이전트에는 화면별 명세를 넘긴다
기존 문서의 모바일 제외 지침은 이후 사용자의 모바일 제작 요청으로 대체되었다
데스크톱을 먼저 완성한 뒤 모바일에는 같은 정보 위계에 맞는 별도 배치를 적용한다

## 1 디자인의 중심

Geo Data Intelligence라는 브랜드에 맞춰 실제 관측·분석·예측·데이터 활용 역량이 드러나는 기술 기업의 웹사이트를 만든다
브랜드와 대표 기술을 보여주는 곳에는 큰 미디어와 강한 타이포그래피를 쓴다
찾아보고 비교하고 읽는 곳에는 안정적인 정렬과 명확한 탐색 수단을 쓴다
한 페이지의 모든 구간을 같은 카드나 같은 전환으로 만들지 않는다

색은 GeoSR 블루와 검정·딥 네이비·블루그레이·밝은 중성색을 사용한다
메인과 AX 콘셉트는 어두운 미디어 무대가 중심이며 긴 설명·자료·목록은 밝은 바탕을 중심으로 구성한다
최종 색값과 대비는 실제 영상과 이미지가 들어간 화면에서 함께 검수한다

## 3 메인 페이지의 화면 순서

1. **회사 필름** — 첫 화면 전체를 차지하는 60초 회사 필름 자리와 브랜드 문구
2. **핵심 역량 탐색** — 분야를 고르면 큰 장면과 설명이 바뀌고 관련 기술이 드러나는 영역
3. **대표 연구·수행 사례** — 실제 과제와 수행 내용을 보여주는 편집형 영역
4. **AX Platform · GeoDAP** — 독립된 두 플랫폼 소개와 각각의 다음 행동
5. **기술의 근거** — 인증·면허·지식재산권 갤러리와 전체 자료 연결
6. **GeoSR 소식** — 최근 항목 3개 정도를 간결한 목록으로 표시
7. **문의와 회사 정보** — 연락처와 필수 정보

각 구간은 브랜드 인상 → 사업 이해 → 수행 근거 → 서비스 → 자격 → 최신 소식 순서로 이어진다
해당 자료가 부족한 대표 사례를 가상의 프로젝트나 수치로 채우지 않는다
기존 메인 전체를 즉시 다시 덮어쓰는 지시가 아니라 현재 구간과 대조해 통합할 설계안이다

## 4 AX 페이지는 제품 시연을 중심으로

### 첫 구간

회사 메인과 구분된 약 30초 AX 콘셉트 필름을 배치한다
관측 자료와 영상이 탐지·예측·모니터링 작업으로 이어지는 개념을 보여주되 실제로 통합되지 않은 플랫폼을 하나의 운영 시스템으로 묘사하지 않는다
가상의 연출 장면과 실제 UI 장면을 구분하며 실제 플랫폼 화면은 생성형 도구로 만들지 않는다

### 개별 플랫폼 탐색

상단에 탐지·예측·모니터링 분류를 두고 그 아래 해당 플랫폼을 선택한다
선택된 플랫폼 하나를 큰 16:9 화면과 설명으로 보여준다
화면 옆에는 해결하는 문제와 주요 기능 세 가지를 배치한다
대표 장면을 짧게 이어서 보여주되 텍스트가 읽혀야 하는 순간은 충분히 유지한다
전체 화면 → 같은 16:9 비율의 기능 확대 → 결과 확인의 흐름을 사용한다
탭을 눌러도 문서 전체가 갑자기 스크롤되지 않게 한다

| 분류 | 현재 확인된 소개 대상 |
| --- | --- |
| 탐지 | Satellite Facility Detection · Natural Phenomena News |
| 예측 | Flood 3D · Storm Surge · Extreme Sea Level · Integrated Flood XAI |
| 모니터링 | Rip Current · Ocean Buoy · Ocean Environment |

Natural Phenomena News는 뉴스 탐색·분류 기능의 성격을 별도 설명한다
Integrated Flood XAI는 개발 중으로 표시하며 실제 화면과 구현 기능을 보유한 것으로 표현하지 않는다
외부 AX 서비스 접속 버튼은 만들지 않는다
GeoDAP은 완성된 별도 서비스로서 자체 소개와 외부 연결을 유지한다

## 5 어떤 움직임을 어디에 적용할지

| 방식 | 적용 위치 | 구체 동작 | 완료 기준 |
| --- | --- | --- | --- |
| 장면 전환 | 기술 분야와 AX 플랫폼 선택 | 미디어가 수평으로 짧게 이동하며 교차 전환 · 제목과 설명은 뒤따라 정돈 | 어느 항목을 선택했는지 명확하고 연속 클릭 시 마지막 선택이 유지됨 |
| 깊이감 있는 갤러리 | 인증·면허·특허 | 중앙 문서는 정면 · 주변 문서는 작은 Y축 각도와 크기 차이 · 스크롤 방향에 반응 | 뒷면 노출과 원문 왜곡 없이 확대 가능 · 문서 잘림 없음 |
| 미디어의 공간감 | 기술 대표 장면과 선택된 장비 | 낮은 각도의 원근과 그림자 · 포인터 이동 또는 페이지 진입에 반응 | 글자는 정지 · 실제 장비 사진의 내용과 비율 보존 |
| 편집형 진입 | 대표 수행 사례 | 큰 사진과 짧은 설명이 약간의 시차로 등장 | 계속 움직이지 않고 읽을 시점에 정지 |
| 위치 안내 | 긴 회사 소개와 연혁 | 현재 구간·연도를 따라가는 밑줄 또는 진행 표시 | 사용자가 전체 위치를 알 수 있고 직접 이동도 가능 |
| 기능 피드백 | 게시판·검색·문의 | 짧은 상태 전환과 선택 강조 | 기능이 즉시 이해되고 키보드 조작 가능 |

구현 방식은 CSS·Web Animations·GSAP 중 필요한 수단을 선택한다
문서 갤러리와 미디어의 제한적인 깊이는 CSS 3D로 구현할 수 있다
실제 3D 장면이 필요한 경우에만 Three.js 도입을 검토한다
라이브러리 개수나 효과 개수를 완성도의 기준으로 삼지 않는다

회전·패럴랙스는 주인공 콘텐츠를 부각하는 곳에 한정한다
게시글 본문·연락처·양식·장비 제원에는 계속 움직이는 효과를 주지 않는다
스크롤을 가로채거나 커서를 바꾸거나 중요한 정보를 호버에만 숨기지 않는다
모바일·터치에서는 원근 효과를 줄이고 스와이프와 명확한 선택 상태를 사용한다
움직임 줄이기 설정에서는 모든 내용이 정적으로 표시되고 기능은 그대로 동작해야 한다

## 6 비주얼·내용 검수

- 브랜드용 연출과 실제 장비·제품·수행 실적의 증거를 명확히 구분
- 실제 플랫폼 화면은 전체 16:9와 같은 비율의 기능 확대 사용
- GeoDAP 이미지의 비율 보존과 전체 화면 가독성 확인
- 생성형 장면의 사람·손·얼굴과 부정확한 장비 형상은 사용하지 않음
- 실제 지형·해안선·측량·계류·케이블·수중 장비의 물리적 관계 확인
- 자연 경관만으로 조사·분석·예측 역량을 대체하지 않음
- 보고서용 그래프와 과도한 네온 선을 장식용 대표 이미지로 사용하지 않음
- 현재 검수된 실험실 콘셉트의 공개용 표기를 유지
- 미확정 영상·자료는 준비 중으로 표시하고 실제 실적처럼 제시하지 않음
- 한글은 영문의 직역보다 업무와 상황에 맞는 표현을 우선

## 7 다음 구현 순서와 검수 기준

### 구성 단계

이 문서의 콘텐츠 표현 표를 바탕으로 메인·기술·AX·회사·자료 목록의 화면 구성을 먼저 구체화한다
실제 제목 길이와 샘플 데이터 수를 넣은 데스크톱 정적 화면으로 비율을 검토한다
대표 페이지마다 어디가 시각적 중심인지 한눈에 확인되어야 한다
완료 기준은 이미지와 문구가 들어간 정적 구성만으로도 위계가 읽히는 것이다

### 상호작용 단계

정적 구성이 정해진 영역에만 위 표의 모션을 추가한다
이벤트·시작 상태·끝 상태·지속 시간·빠른 연속 조작·키보드 동작을 명세한다
완료 기준은 시선을 돕는 움직임과 안정적인 정보 탐색이 함께 성립하는 것이다

### 실제 콘텐츠 단계

분야별 승인 이미지와 플랫폼 기능 녹화를 연결한다
목업 자료와 실제 자료의 표기를 확인한다
실제 콘텐츠 때문에 비율·높이·전환이 무너지면 레이아웃과 동작을 조정한다

### 모바일·영상 인계 단계

데스크톱 구성을 확정한 후 모바일 배치와 터치 조작을 검수한다
회사 필름과 AX 필름은 기존 콘티와 연결된 슬롯·비율·포스터·재생 정책을 명시한다
최종 고품질 영상이 승인되면 해당 슬롯의 소스만 교체할 수 있게 구성한다

## 참조와 구현 상태

[레퍼런스 검토 메모](INNER-PAGE-REFERENCE-DECISIONS.md)에 Refero와 MotionSites에서 실제 확인한 범위를 기록했다
공개 미리보기의 정보 구조와 움직임을 참고하며 유료 상세 페이지를 열람한 것으로 취급하지 않는다

현재 코드에는 내부 페이지 정돈 작업이 진행된 상태가 남아 있다
그 작업을 위 전체 표현 설계가 구현된 완성본으로 취급하지 않는다
신규 inner-motion 파일과 HTML 연결은 아직 만들지 않았다
현재 브랜치의 실제 상태는 Git과 실행 화면으로 확인하며 과거 인계 문서의 완료 표현에 의존하지 않는다

### 중간 코드 검수 기록

- 16개 한글·영문 경로 응답과 34개 로컬 참조가 정상 응답
- 정적 메타데이터 8개와 공용 언어별 메타데이터 계약 검사 통과
- 메인 HTML과 기존 메인 디자인 CSS는 변경하지 않음
- 브라우저에서 연구 분류·상세 연결과 소식 빈 검색 결과 및 문의 미리보기 동작 확인
- AX 소개 구간과 하단 기능·플랫폼 목록이 독립된 섹션으로 렌더링되도록 닫는 태그 오류 수정
- 기술 페이지 배경 대비와 21개 기술 링크 로딩 확인
- 장비 소개의 과도한 여백과 인증서 이미지 잘림 수정 확인
- 전 페이지 모바일·영문 시각 검수와 최종 모션 검수는 아직 완료하지 않음
- 기존 소형 자료와 영상 준비 영역을 포함한 중간 구현이므로 출시 완료 상태가 아님
