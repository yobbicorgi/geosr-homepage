# 올포랜드 참조와 GeoSR 스크롤 설계 · 2026-09-28

## 직접 확인한 화면

2026-09-28 [올포랜드 메인](https://www.all4land.com/main.do)을 브라우저에서 직접 확인했다. 첫 화면의 재생 중인 영상은 1920×1080 약 53초다. 화면에는 실제 도로·저수지·도시 해안과 광역 항공 뷰가 이어지고 일부 구간에 얇은 공간정보 그래픽이 합성된다. 아래로 스크롤하면 첫 장면이 한동안 고정되며 문구가 전환되고 영상 화면이 점차 작아져 검은 배경의 사업 분야 미디어 군으로 이어진다. 사업 영역은 여러 이미지가 서로 다른 크기와 위치로 이동한다. 다음에는 청색 배경의 솔루션 영역이 나오고 마지막에 밝은 기업 개요와 실제 사옥 이미지가 연결된다.

이 기록은 **영상의 분위기·화면 규모·시점 변화·스크롤 리듬**을 분석한 것이다. 올포랜드의 영상 프레임·문구·그래픽·배치 코드를 복제하지 않는다.

## GeoSR에서 가져갈 원리

1. 도시나 해안을 설명만으로 생성하지 않는다. 실제 촬영이나 위치·출처가 확인된 이미지를 우선한다. 소스가 모자라면 그 컷은 미완성으로 두고 다른 실제 자료를 찾는다.
2. 첫 장면에 바다만 크게 두지 않는다. 해안선·하구·도시·조사 해역의 관계가 보이는 큰 시야를 사용한다. 원본 영상의 지리와 다르게 생성된 프레임은 쓰지 않는다.
3. 시점은 상공 직하·완만한 전진·측면 이동·수면에 가까운 장면으로 변주한다. 한 컷 안의 카메라 움직임은 하나만 둔다.
4. 기술 그래픽은 과장된 가짜 측정값이 아니라 절제된 라인·마스크·영역 전환으로 보여준다. 실제 자료 레이어는 출처를 기록하고 시각 장식은 측정 결과처럼 읽히지 않게 한다.
5. 스크롤은 내용을 읽는 행위가 화면 전환을 이끈다. 휠 입력을 가로 갤러리 조작에만 가두거나 화살표 클릭만 요구하지 않는다. 움직임을 끈 사용자에게도 모든 정보가 같은 순서로 나타난다.
