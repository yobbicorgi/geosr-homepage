## 근거와 한계

기록은 `docs/source-migration/`의 수집 결과에서 옮겼습니다. 공개 글의 제목과 텍스트가 조회되며 기존 ID 형태의 링크도 현재 목록의 개별 글로 연결됩니다. 원본 이미지와 첨부파일의 완전한 이관, 인증·등록의 현재 유효 상태, 연구 성과의 독립 검증은 확인되지 않았습니다.

현재 서비스의 정적 이미지와 생성 콘셉트는 실제 관측·실험·수치 결과로 표시하지 않습니다. 원본 기록은 페이지에서 유지하되 방문자에게 과거 홈페이지를 따로 찾아보라고 안내하지 않습니다.
