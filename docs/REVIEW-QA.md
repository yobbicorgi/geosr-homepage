## 검수 중 수정한 항목

- 모바일 필터가 상단 메뉴의 절대 위치 스타일을 상속하던 충돌 수정
- 비동기 문서 목록 이후 직접 링크 위치 복원
- 작은 화면에서 위성과 지도층이 잘리지 않도록 기술 이미지의 16:9 비율 유지
- 문서 확대를 닫은 뒤 선택했던 검색 결과로 초점 복귀
- 생성 무인선의 세부 부품 차이를 확인하고 실제 공개 원본 사진으로 교체
- 구형 스크립트와 이전 미디어를 배포 폴더 밖에 보관
- 스타일과 스크립트에 갱신 식별자를 붙여 이전 브라우저 캐시 회피

## 이미지 판정과 다음 단계

`MEDIA-QUALITY.md`가 이미지·영상의 지리·공학·물리량·연속성 검수 기준이다

- 국내 해안 원본과 무인선 원본은 실제 공개 자료로 구분
- 수치모델 장면의 파랑과 망은 연출 가안이며 실제 해석 결과가 아님
- 위성의 다층 지도는 사용자 승인 방향을 반영한 개념 장면
- 위성 장면의 최종 지도와 해안선은 동일 좌표계의 검증된 자료로 합성해야 함
- 미량분석 장면은 시료 전처리의 일반적인 개념 화면이며 특정 시험 결과를 나타내지 않음
- AX 미리보기는 실제 UI 정지 화면을 편집한 짧은 영상이며 실제 동작 녹화나 실시간 데이터가 아님
- Flood XAI는 개발 중인 소개 목업으로 표시

현재 단계의 완성 범위는 검토용 웹 목업이다
Higgsfield 최종 영상과 전체 게시물 이관 및 회사 자료의 유효기간 확인은 다음 제작 단계다
구 geosr.com 주소의 리디렉션과 문의 처리 및 검색 노출 설정은 공식 전환 시 원본 URL 목록과 운영 환경을 기준으로 확정한다
