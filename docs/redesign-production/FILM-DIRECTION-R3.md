## 현재 판정

기존 회사 60초 및 AX 30초 자동 연결 편집본은 사용자 품질 기준 미달이다
장면 수나 길이 충족을 완료로 보고하지 않는다 기존 파일은 비교용 편집 자료로 보존한다
이 문서는 제작 지시서이며 완성·검수 합격 증명이 아니다

## 연출 원칙

현실을 촬영한 듯한 장면을 바탕으로 관측 대상과 데이터 표현을 같은 공간에 둔다
한 장면 안에서 현실 → 자료가 되는 변화를 보여준다 장비 사진 다음에 무관한 데이터 화면을 붙이지 않는다
색은 자연광·짙은 해양색·백색 계측선이 중심이다 수온·클로로필 같은 자료 색은 변수 의미에 맞게 제한적으로 사용한다
장면마다 장식 네온을 반복하지 않는다 인물 없는 실험실 원칙을 유지한다
모든 장면 사이에 연결 대상·화면 위치·움직임 방향·빛의 방향·앞뒤 12프레임 여유를 지정한다
자료의 실제 지리와 결측 영역은 생성형 도구가 바꾸지 못하게 별도 합성한다
실제 연구 성과로 보이는 값·정확도·논문 그래프는 근거 없이 생성하지 않는다

| 23–30초 | 수중 측량 또는 영상 조사 → 해저 지형 및 영상 자료 | 횡방향 측량 띠가 연안 지형의 윤곽으로 이어짐 | 음향은 설명용 효과임을 구별·불가능한 투시 금지 |
| 30–36초 | 연안·하구 조사 → 사진측량/지형 점군 | 점군의 평면이 분석할 공간 격자로 정렬됨 | 일반 항공 라이다로 깊은 해저를 보는 표현 금지 |
| 36–43초 | 관측 영상·공간 자료 → AI 처리 → 분류 및 변화 탐지 | 처리된 자료 중 환경 시료의 맥락으로 매치 컷 | 떠다니는 가짜 신경망 대신 입력과 출력의 차이를 보여줌 |

60초 안에 모든 역량을 각각 이름 붙여 나열하지 않는다 주 장면과 1–2초 보조 삽입을 구분한다
장비의 종류보다 측정 → 자료 → 분석 → 활용의 관계가 우선이다

## AX 메인 30초 목표 콘티

0–8초 관측 영상과 공간 레이어가 서로 다른 자료로 들어와 정렬됨
8–16초 탐지할 객체와 예측할 상태가 각자 다른 처리 경로로 분리됨
16–24초 탐지·예측·모니터링 결과가 독립된 공간 장면에서 드러남
24–30초 서로 독립된 플랫폼의 역할이 하나의 브랜드 소개로 정리됨

회사 우주·선박 영상의 짧은 재탕이나 실제 UI 화면 나열로 만들지 않는다
하단 플랫폼별 영상만 실제 16:9 녹화를 사용한다 원본 화면 → 기능 선택 → 결과 확인을 약 3–5초로 편집한다
실제 기능을 생성형 UI로 재현하지 않는다

## 제작 순서와 통과 기준

1. 회사 분야와 장면의 역할 확인
2. 시작·중간·종료 keyframe을 한 세트로 설계
3. 앞뒤 장면 keyframe의 공통 대상과 방향을 확인
4. imagegen 결과를 메인이 검수하고 오류가 있으면 수정
5. 대표 전환 한 구간만 Flow 720p로 시험
6. 지리·장비·동작과 연결 합격 후 같은 방식으로 나머지 제작
7. 전체 속도·색감·변수 설명·루프를 검수하고 웹 슬롯에 반영

기존 R3 오프닝 시험은 결과를 확보했으나 끝 프레임의 위성 방향과 축소가 의도와 달라 다음 컷과의 연결 후보로만 보존한다 자동으로 메인에 연결하지 않는다
