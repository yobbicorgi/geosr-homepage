# 한화오션 실시간 페이지 시각 검토 · 2026-09-29

검토 주소는 `https://www.hanwhaocean.com/`이다. 2026년 9월 29일 브라우저에서 메인과 회사 안내, 연혁, 상선, 혁신, R&D 설비, 뉴스 페이지를 열어 스크롤과 사이트맵을 확인했다. 현재 검토 창은 1264×709였으므로 다른 해상도에서의 줄바꿈이나 애니메이션 품질까지 승인한 기록은 아니다.

## 관찰한 페이지 구성

|---|---|---|

## 적용 결정

- 상단 메뉴, 본문 제목, 시각 무대, 상세 자료의 역할을 분리한다.
- 현재 GeoSR 메인에는 해안과 바다, 내륙 수역, 현장 관측, AI 분석의 네 가지 콘셉트 슬라이드가 있다. 각 이미지의 캡션과 해당 기술 주제가 일치하는지 확인하고 원본 연구·사업 자료와 섞지 않는다.
- 기술 상세 21개 페이지는 주제별로 원문 첫 자료 또는 개별 콘셉트 도입 장면을 선택한다. 원문 도표와 지도는 원래 비율·범례·값을 보존하고 콘셉트 장면에는 콘셉트 표기를 둔다.
- 이미지가 정보 탐색을 늦추는 목록 페이지에는 장식 슬라이드를 추가하지 않는다. 소식 페이지에서는 뉴스와 무관한 소개 슬라이드를 제거해 검색과 384건 게시물 목록을 앞당긴다.
- 한화오션의 페이지 구조를 참고하되 문구·이미지·로고·코드·고유 그래픽은 가져오지 않는다. GeoSR 회사 자료와 자체 생성한 콘셉트 이미지만 사용한다.

## 확인 범위와 남은 검증

메인과 지정한 주요 페이지의 스크롤 화면, R&D 시설 선택 구조, 제품 상세 팝업, 사이트맵 오버레이를 확인했다. 모든 한화오션 하위 메뉴를 화면별로 모두 열어 본 것은 아니며 이 기록을 전체 페이지 승인을 뜻하는 것으로 쓰지 않는다. 이후 검수에서는 KO·EN 페이지, 모바일 폭, 실제 스크롤·키보드 조작과 섹션 전환을 계속 비교한다.

## GeoSR 메인 반영 · 구간 이동

한화오션 메인 오른쪽에 현재 구간과 다음 이동 지점을 보여주는 진행 안내가 있다. GeoSR 메인에는 이에 대응해 첫 화면·회사 소개·사업 분야·AX Platform·GeoDAP·수환경 연구·소식의 일곱 위치를 연결했다. 현재 위치는 화면 중앙 구간을 기준으로 바뀌고 숫자와 짧은 항목명은 키보드 포커스나 마우스 오버 때 함께 확인할 수 있다. 앵커 이동은 브라우저 기본 스크롤을 사용하며 일반 휠 입력을 가로채지 않는다. 모바일에서는 고정 요소가 콘텐츠를 가리지 않도록 숨기고 기존 메뉴와 가로 갤러리를 유지한다.

구현 파일은 `dist/home.js`, `dist/home-motion.js`, `dist/home.css`다. 한국어·영어 메인 DOM에서 일곱 목적지와 앵커 ID를 확인했고 JS 문법 및 18개 한영 경로 테스트는 통과했다. 이번 작업 뒤의 QHD·모바일 실제 화면 캡처와 고정 레일의 픽셀 배치는 아직 확인하지 않았다.
