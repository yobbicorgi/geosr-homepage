# GeoSR 60초 기업 필름 · AX Platform 30초 필름 연출 콘티 v2

**상태:** 편집·카메라 방향 승인용 설계 문서. 새 영상·이미지·UI를 생성하거나 제작 완료를 뜻하지 않는다. 화면비는 16:9 데스크톱 기준이다. 장비·현장 이미지는 모두 `SHOT ASSET` 게이트이며, 실제 사용권과 출처가 확인된 자료만 넣는다.

## 우선순위와 연출 의도

이 문서는 60초 기업 메인 필름과 별도 30초 AX Platform 필름의 최신 연출 기준이다. 이전 C01–C10/A01–A06 표와 타이밍·숏 분할이 다르면 **이 v2 타임라인이 우선**한다. 다만 실제 자료의 출처·권리·지리·측정 한계, 사람·가짜 UI 금지 등 기존 사실 검수 기준은 계속 적용한다. `hero-earth-00s-v4.png`는 현재 홈 구현에서 승인된 임시 Earth poster로 쓰지만 완성 영상이나 지리·관측 결과의 증거는 아니다. 그 밖의 생성 키프레임도 개별 승인 범위를 벗어나 확정된 영상 프레임이나 웹 자산으로 간주하지 않는다.

### 현재 작업 우선순위

1. **회사·AX 콘티:** 60초 회사 메인 필름과 별도 30초 AX 필름의 이야기, 장면 목적, 시간, 전환을 먼저 확정한다. 두 필름을 섞지 않는다.
2. **데스크톱 전체 화면 영상 중심 웹디자인:** 영상 또는 교체 가능한 승인 poster가 첫 화면의 100svh 무대를 채우도록 구성한다. 제목과 pending 상태는 HTML overlay로 둔다.
3. **스크롤·전환 리듬:** 한 화면에 하나의 메시지가 읽히도록 섹션 진입, 장면 전환, 스크롤 속도와 여백을 다듬는다.
4. **장비 사실성 확인:** 장비는 이미 정해진 장면의 형태·모델·운용 관계를 검수하는 보조 요소다. 장비 카탈로그를 만들거나 장비별 장면을 추가·확장하지 않는다. 확인되지 않은 부분은 `SHOT ASSET: PENDING`으로 둔다.
5. **ImageGen 키프레임과 향후 Higgsfield 연결:** 앞선 콘티와 웹 구성이 검토된 뒤 기존 shot의 start/end frame을 준비한다. ImageGen은 허용된 배경·공간 콘셉트에만 쓰고, 유료 Higgsfield 생성은 사용자 결제 및 검토 후 진행한다.

이 순서는 제작 우선순위이며 완료 선언이 아니다. 기존 장비 출처·정확성 문서는 4번의 검수 근거로만 사용하며, 그 문서를 이유로 장면·분류·페이지를 늘리지 않는다.

기업 필름은 한 카메라 여정으로 우주에서 동아시아 해역으로 접근하고, 검증된 자료와 현장 관측을 거쳐 분석·예측의 실제 화면을 짧게 보여준 뒤 첫 지구 프레임으로 돌아온다. 자연 풍경을 길게 나열하는 홍보 영상이 아니라 **관측 → 자료 해석 → 현장 조사 → 분석 → 실제 제품 증거**의 기술 서사다. AX 필름은 회사 필름과 분리해 추상적인 자료 흐름에서 출발하고, Discover·Predict·Monitor의 실제 화면을 각각 보여준 뒤 실제 AX UI 진입으로 끝낸다.

두 영상 모두 사람·얼굴·손·인체·인물의 반사나 실루엣을 화면에 넣지 않는다. 생성 글자·로고·수치·측정 결과·가짜 지명·가짜 데이터 시각화·가짜 UI도 금지한다. 필름 자산은 별도 권리·출처 검토 전까지 웹이나 대외 공개에 연결하지 않는다.

**SHOT ASSET 게이트:** 특정 선박·USV·드론·센서·ROV·실험실 모델을 이 콘티에서 확정하지 않는다. 각 컷은 기능과 장면의 목적만 정의한다. 소스가 확보되면 장비명·구성·운용 관계·촬영 위치·사용권을 확인해 교체한다. 자료가 없으면 해당 실제 장비 컷은 보류하고 가짜 장비로 채우지 않는다. 생성형 이미지는 배경·분위기·추상 전환의 내부 가안에만 쓰며 실제 지형, 데이터, UI, 장비 외형의 증거가 아니다.

### 기업 필름 카피와 사운드

화면 문구 후보는 **“관측에서 예측까지”**, 보조 문구는 **“해양·환경 현장의 데이터를 분석과 기술로 연결합니다.”**다. 영상 프레임에 baked text로 넣지 않고 별도 후반 타이포그래피 또는 웹 HTML로 처리한다. 내레이션은 다음 정도의 짧은 문장으로 검토한다.

> 환경의 변화는 여러 관측에서 시작됩니다. 서로 다른 자료를 살피고, 해상과 하천의 현장을 측량합니다. 분석과 실제 플랫폼 화면을 통해 관측에서 예측까지 이어갑니다.

사운드는 저음의 절제된 음악과 검증된 현장 room tone을 사용한다. 00–14초는 넓고 느린 음향, 14–24초 자료 전환마다 과장 없는 미세한 음색 변화, 24–48초는 실제 바람·물결·장비 운용음을 낮게 섞고, 48–55.5초는 실험실·UI 원음이 권리상 허용될 때만 사용한다. 55.5초부터 시작 동기를 되돌려 루프를 닫는다. 가짜 sonar, 레이저음, 알람, 과장된 UI click은 넣지 않는다.

### AX 카피와 사운드

타이틀 후보는 **“AX Platform”**, 설명은 **“Discover · Predict · Monitor — 실제 기능 화면”**이다. 한국어 내레이션은 “해양·환경 정보를 살펴보는 세 가지 기능. 실제 화면으로 Discover, Predict, Monitor를 확인합니다.” 정도로 제한한다. 세 기능의 소개 순서는 영상의 편집 구성이지, 동일 데이터가 한 번에 처리되는 단일 업무 흐름이라는 주장이 아니다.

AX 음악은 회사 필름과 구분되는 짧고 정돈된 전자 리듬을 쓰되, SF·경보·과도한 파란 네온을 연상시키지 않는다. A01의 추상 리듬은 A02에서 낮아지고 실제 UI 화면으로 들어오면 음악만 남긴다. 각 실제 기능 전환에 허구의 click/확정음을 넣지 않는다. 실제 제품 원음은 출처·개인정보를 검수한 뒤 허용될 때만 사용한다.

## 공통 웹·Higgsfield 인계 기준

- 홈페이지 메인 필름은 16:9 edge-to-edge hero의 배경이다. 영상 frame에는 타이틀·로고·CTA를 굽지 않고 HTML overlay가 왼쪽 약 40% title-safe 영역을 쓴다. 우측 주 피사체는 frame 폭의 55–70% 안에 두고, 중요 지형·장비·화면은 바깥쪽 5%에 놓지 않는다. 1440×900에서는 cover 시 좌우가 약간 잘릴 수 있으므로 주요 내용은 중앙 90% 안에 남긴다.
- `hero-earth-00s-v4.png`는 영상이 준비되는 동안 홈의 임시 poster로 사용할 수 있다. 이 로컬 미리보기 사용 승인은 최종 영상 프레임, 외부 공개 권리, 추가 ImageGen 제작의 승인을 뜻하지 않는다. C02/C03 등 다른 v4 frame은 각자 명시된 지리·구도 reference로만 본다.
- 최종 첫 프레임과 마지막 프레임은 같은 지리·카메라·색·crop이다. GeoSR 지형과 해안선은 승인된 source 픽셀로 고정한다.
- AX 및 기업 필름 안의 실제 UI 캡처는 전체 16:9 비율을 유지한다. contain으로 전체가 보이도록 하고 검은 여백을 채우려고 crop하거나 UI 위에 타이포를 겹치지 않는다.
- Higgsfield 입력 묶음은 각 shot의 승인된 start/mid/end frame, source·권리·팩트 기록, 카메라 경로, 이전·다음 shot의 매치 포인트, 금지 요소를 포함한다. 필요한 공백은 출처가 명확한 배경 plate로만 채운다.
- 인접 장면의 지형·카메라 축·색온도·날씨·피사체 규모가 튀지 않는지 contact sheet와 rough cut에서 함께 검수한다. 앞뒤 장면이 시각적으로 이어져도 실제 동일 장소·관측 사건을 주장하지 않는다.
- 각 컷의 실제 장비·현장 자료가 없거나 사용권 확인이 끝나지 않으면 `SHOT ASSET: PENDING`으로 남긴다. 추정 장비나 generated UI로 빈틈을 채우지 않는다.

## 제작 전 승인 체크

- [ ] 두 영상이 각각 정확히 60초와 30초이며 서로 편집·목적·사운드가 분리되어 있다.
- [ ] 회사 영상이 지구→자료→현장→분석→실제 UI→지구의 한 여정이며 자연 풍경 montage에 머물지 않는다.
- [ ] C04 세 자료는 순차 crossfade이고 실제 데이터 픽셀·결측이 보존된다. 월별 SST/염분과 일별 chlorophyll의 비동시성을 문서화했다.
- [ ] 사람·손·얼굴·반사된 인물·가짜 지역·가짜 결과·숫자·UI·제품 상태가 없다.
- [ ] C05–C09의 SHOT ASSET별 실제 모델·구성·운용 관계·사용권이 승인되었거나 명확히 pending이다.
- [ ] 실험실 GENERATED CONCEPT와 실제 GeoSR 시설을 혼동하지 않는다.
- [ ] Discover·Predict·Monitor 원본 화면이 각각 전체 프레임으로 표시되고, 기능 간 동일 사건·실시간 pipeline 주장이 없다.
- [ ] 1440×900, 1920×1080, 2560×1440에서 기업 hero의 제목·주 피사체·지리와 AX 화면의 핵심 내용이 잘리지 않는다.
- [ ] 원본 화면/지리 픽셀, crop-safe 배치, 첫·마지막 프레임 match가 편집 검수에서 확인된다.
