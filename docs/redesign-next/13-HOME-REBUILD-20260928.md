# 메인 페이지 재구성 및 정리 — 2026-09-28

## 변경 범위

이번 변경은 기존 메인의 탭·겹친 카드·선택형 플랫폼 무대를 폐기하고 스크롤로 읽히는 한 페이지를 다시 구성한 것입니다. 국·영문은 같은 정보 구조를 사용하고 문장은 각각 검토합니다.

| 순서 | 현재 화면 | 설계 의도 |
| --- | --- | --- |
| 01 | 광역 연안·하구 히어로 | 해양·환경 회사의 범위를 실제 세계 크기로 보여 줌. 정지 콘셉트와 영상 준비 상태를 명시 |
| 02 | 회사의 조사·분석 흐름 | 현장 자료에서 해석으로 이어지는 역할을 짧은 문장으로 설명 |
| 03 | 관측·환경·모델·AI 분야 장면 4개 | 클릭하지 않아도 모든 분야가 일반 휠 스크롤로 드러남 |
| 04 | 연구·사업 원문 기반 목록 | 출처가 있는 게시글로 바로 이동. 생성 이미지는 실제 결과와 구분 |
| 05 | AX Platform / GeoDAP 독립 소개 | AX는 제공 저장소의 직원 제작 정적 화면, GeoDAP은 공개 소개 페이지의 작업화면 미리보기 사용 |
| 06 | 자격 자료·원문 자료실·소식 | 문서 분류/확대, 기존 공개 글 검색, 날짜가 있는 소식 연결 |

## 코드와 폴더

- `dist/home.js`: 현재 메인 HTML과 회사 페이지가 공유하는 `homeFields`, 자격 갤러리, footer. 사용하지 않는 옛 연구 스택·AX 콘셉트 릴·전문 분야 탭 렌더 코드를 제거했습니다.
- `dist/home.css`: 메인 전용 반응형 레이아웃. `home-refinement.css`의 후행 덮어쓰기 대신 한 파일에서 화면 크기와 색·타입·미디어 비율을 정의합니다.
- `dist/home-motion.js`: 화면에 들어온 제목·목록의 짧은 진입 애니메이션. 핵심 콘텐츠는 애니메이션 실패 시에도 보입니다. 모션 감소 설정에서는 실행하지 않습니다.
- `dist/index.html`: 메인에서 쓰지 않는 AX/회사/옛 시안용 CSS·JS 로딩을 제거했습니다. 공유 CSS와 현재 메인 CSS만 로드합니다.
- `dist/presentation.js`, `dist/interactions.js`: 실제 DOM에서 더는 쓰이지 않는 홈 탭·연구 카드 조작을 제거하고 자격 문서·회사 페이지 기능을 유지했습니다.
- 공개 `dist`에서 미사용 이전 시안 `design-directions.*`, `redesign-preview.*`, `motion-lab.*`, `ax-explorer.*`, `home-refinement.css`를 제거했습니다. Git 이력에서 복구할 수 있습니다. `media-review.*`는 이미지 검수 생성 도구의 출력이라 유지합니다.
- 루트 `README.md`와 `00-START-HERE.md`를 현재 경로·파일 책임·미완료 상태 중심으로 고쳤습니다. 03 실행 계획은 과거 기록임을 명시했습니다.

## 콘텐츠와 출처

- 히어로와 전문 분야 이미지는 검수 대기 중인 콘셉트입니다. 실제 지역·시설·관측 결과로 표시하지 않습니다.
- AX 메인 이미지는 직원 제공 저장소의 `satellite.webp` 전체 프레임이며 확대·자동 이동·잘림을 적용하지 않습니다. AX 서비스별 캡처와 조작은 AX 페이지에서 볼 수 있습니다.
- GeoDAP 화면은 공개 소개 페이지의 작업화면 미리보기 영역을 프레임 비율에 맞춰 보여 줍니다. 실제 로그인한 운영 서비스 화면이라고 주장하지 않습니다.
- 공개 글 자료실은 텍스트 기준 2,024건(국문 1,215, 영문 809)의 중복 제거 기록입니다. 원본 이미지와 첨부파일의 완전한 이관은 확인되지 않았습니다.
- 회사 60초 본편과 AX 30초 본편, 요소별 신규 영상은 미완료입니다. Higgsfield CF01 생성은 요금제 제한으로 거절되어 결과 파일이 없습니다.
