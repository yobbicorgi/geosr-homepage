# Higgsfield 영상 제작과 검수

갱신 2026-09-29

현재 범위는 검수한 이미지의 영상 제작과 홈페이지 통합까지 포함한다
사용자의 최신 영상 모델 지정은 Seedance 2.0이다

## 실제 사용할 입력

- 이미지는 ChatGPT 웹의 자체 이미지 생성으로 만들고 내려받은 고해상도 원본만 사용한다
- 원본 파일과 생성 대화 및 프롬프트와 해상도·해시를 미디어 원장에 기록한다
- 생성된 이미지를 화면으로만 확인한 상태와 로컬 원본 확보 상태를 구분한다
- 각 장면의 현장·지형·장비·객체 비율과 기술 의미를 먼저 확인한다
- 탐지 박스와 분할 마스크 및 격자·유동·분석 UI는 이미지와 영상 생성 단계에 함께 포함한다
- 별도 후반 그래픽을 덧씌우지 않는다 영상 편집은 검수된 클립의 연결과 전환으로 제한한다

## 접수 순서

1. [최신 제작 계획](production-plan.json)의 해당 장면을 선택한다
2. 실제 원본을 열어 대상·행동·결과와 시작·전개·끝의 가능성을 검수한다
3. 모델은 Seedance 2.0을 사용하고 기본은 16:9 무음 1080p로 둔다
4. 최종 이미지와 길이·해상도를 포함한 현재 견적과 잔액을 확인한다 과거 견적을 현재 비용으로 사용하지 않는다
5. 사용자의 승인된 예산 안에서 한 장면씩 접수하고 작업 ID·설정·비용을 기록한다
6. 결과를 처음부터 끝까지 재생하고 연속 프레임을 검수한다 실패한 장면을 원인 수정 없이 반복 생성하지 않는다
7. 합격 파일만 홈페이지의 고유 슬롯에 연결하고 원본 이미지·버튼·자동 재생·모션 감소 동작을 확인한다

## 합격 기준

- 대표 대상의 실제 행동과 그에 따른 환경이나 분석 결과의 변화가 읽혀야 한다
- 카메라 pan·zoom과 잔물결만 있는 결과는 동적 장면으로 합격시키지 않는다
- 장비와 케이블·선체·지형은 시간에 따라 무너지거나 서로 관통하지 않아야 한다
- AI의 모든 대상에 박스와 실루엣 마스크가 유지되며 이동과 변형을 따라야 한다
- 수치모델의 격자와 확산장은 수역과 지형에 대응하고 질적 설명을 실제 계산 결과로 주장하지 않는다
- 도입부 생성 장면은 개념 설명용이며 실제 제품과 기술 원문은 상세에서 원본으로 제공한다
- 같은 영상이나 이미지를 메인·분야·AX에 반복 배치하지 않는다

## 현재 결과와 제한

9월 29일 관찰한 잔액은 980.75 크레딧이며 다음 접수 때 다시 확인한다
이전에 생성한 AI 영상 두 편은 주석 소실과 대상 추적 불일치로 제외했다
본 방향 재검토 구간에서는 추가 유료 생성을 접수하지 않았다

새 CTD 관측선과 하구 모델 이미지는 브라우저 화면 검토를 거쳤으나 원본 저장이 완료되지 않았다
로컬 원본 확보와 세부 픽셀 검수를 완료하기 전에는 영상 입력으로 사용하지 않는다

작업별 상세 근거는 `media-source/editorial/media-production-handoff.json`과 같은 폴더의 영수증 JSON을 따른다
[미디어 방향](02-MEDIA-DIRECTION.md)과 [복사용 카드](PROMPT-CARDS.md)가 최신 장면 기준이다
