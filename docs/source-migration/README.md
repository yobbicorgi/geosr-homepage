# GeoSR public-source migration capture

This folder contains an internal migration evidence capture from the public first-party GeoSR site. It is a source inventory, not approved replacement copy. Korean page text is preserved verbatim at the word/character level in `pages.jsonl`; visible text from non-Korean routes is preserved separately with a source-language label. Parsing only decodes HTML entities and normalizes layout whitespace. Check each source URL and date again before publication.

## Outputs

- `pages.jsonl` — one record per visited in-scope page, including title, source language, exact Korean visible text (`source_text_ko_preserved`) or original non-Korean visible text (`source_text_original`), source URL, query/record IDs, date candidates, links, images, attachments, retrieval time, and review flags.
- `inventory.csv` — compact page index for spreadsheet review.
- `assets.jsonl` — first-party file/image references with retrieval status, local path and SHA-256 when downloaded, or the reason it was skipped.
- `inventory.json` — machine-readable page and asset inventory summary.
- `duplicates.json` — exact duplicate body and downloaded-asset groups.
- `migration-coverage.json` / `migration-coverage.md` — route/board/path counts, query and duplicate-body statistics, and comparison with the local technology index and prior source inventory. Page totals count fetched URL variants (pagination, board lists/details, and filters), not unique articles; see the current totals in `migration-coverage.md`.
- `ui-copy-provenance.json` / `.csv` — exact-source Korean matches versus newly authored or untranslated UI copy in current site bundles.
- `request-log.jsonl` — response codes, final URLs, byte counts, and retrieval timestamps.
- `assets/` — reasonably sized first-party public assets needed as migration candidates; original basenames are retained, and hash suffixes are used only for collisions.

## Collection policy

The crawler uses the first-party site only, checks `robots.txt`, keeps TLS verification enabled, makes sequential requests at a minimum 1.25-second interval, and records failures rather than retrying aggressively. It follows public menu, English-route, pagination, detail, image, and attachment links in the company/business/research/equipment/news/career/IR/policy routes until the allowed first-party link frontier is drained. The HTTP root is treated as a canonical redirect to the HTTPS site. It does not authenticate, fetch third-party pages, or request robots-disallowed `/site/` and `/upload/` URLs; those links remain inventoried as not fetched. Per-file download cap is 20 MiB and total cap is 250 MiB.

No credential or license scans should be published from this capture without a currentness, rights, and personal-data review. The public CV/resume template is inventoried but deliberately not downloaded because it may collect personal data. Records flagged `personal_contact_review_required` need review before public reuse. The conservative phone/email scan matches the shared company-contact footer on every row. The capture includes 86 distinct email strings and 44 distinct phone strings; business/personal status is unverified, so the archive is not approved for direct publication. Publicly linked files are migration candidates; their display/republication rights still require confirmation. URLs and source text are evidence only; a source-backed Korean string is not necessarily currently approved marketing copy. New English text is not official unless the source site publishes that exact text.

The inventory is generated by `scripts/crawl_geosr_public.py`; derived comparison and provenance reports are generated by `scripts/build_source_migration_reports.py`. Run `python scripts/validate_source_migration.py` after generation to verify JSONL/CSV counts, first-party/robots boundaries, downloaded file signatures, sizes, and SHA-256 values. Re-run from the repository root with Python 3. The crawl timestamps in generated records indicate the actual retrieval time.
