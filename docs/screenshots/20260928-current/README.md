기존 `docs/screenshots/` 루트의 미분류 캡처 16개는 저장소 내 참조가 없고 이 날짜별 기록보다 이전 화면이라 정리했다. 이 폴더와 `20260929-detail-review/`의 기록은 유지한다.

사업 적용 분야의 최신 문구는 2026년 9월 29일 미리보기에서 확인했다. 해당 크기의 새 캡처와 전체 메뉴의 QHD·FHD·모바일 재촬영은 이후 검수 단계에서 추가한다. 새 상세 화면은 [2026년 9월 29일 상세 페이지 기록](../20260929-detail-review/README.md)에 있다.

QHD와 모바일 수치는 CSS viewport 기준이다. 브라우저 캡처 한 장으로 키보드 접근성이나 모든 화면 크기의 동작까지 승인하지 않는다.
