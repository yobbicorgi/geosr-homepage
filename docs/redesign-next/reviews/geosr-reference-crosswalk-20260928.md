# 한화오션 화면 원리와 GeoSR 적용 대조

작성일 2026-09-29  
상태: 화면·인터랙션 적용 검수 중

한화오션 사이트의 메뉴와 주요 세부 페이지를 브라우저에서 확인한 뒤 정보의 흐름과 화면 동작을 GeoSR의 목적에 맞춰 옮긴다. 사용자가 요청한 세부 구성과 상호작용은 알아볼 수 있을 정도로 충실하게 적용하고 GeoSR 자료로 내용을 채운다. 브랜드 자산과 실제 콘텐츠는 GeoSR 자료로 구성하며 참고 페이지의 소스·사진·영상·문구를 복사하지 않는다.

## 적용 기준

| 연구·혁신 내용을 대표 장면과 정보 블록으로 설명 | 연구개발과 학술 실적을 별도 목록과 상세 페이지로 정리 | 전체 원문 기록을 유지하고 메인에는 대표 정보와 탐색 경로만 둔다 |

| 소식 썸네일과 날짜·제목의 목록 | 메인에 공지와 보도자료를 소수만 보여주고 전체 목록은 검색 게시판으로 제공 | 뉴스 기록 전체는 별도 페이지에서 분류·검색·페이지 이동으로 제공한다 |

## 페이지별 적용 범위

내부 페이지는 자료의 성격에 따라 미디어 도입 또는 제목·검색·목록의 직접 탐색 구조를 사용한다. 각 페이지는 도입부에 해당 메뉴와 맞는 대표 이미지를 사용하고 이후에는 원문과 실제 이미지를 우선한다. 생성 콘셉트 이미지는 페이지를 여는 시각 요소로 제한하고 실제 기록·관측·모델 결과·제품 화면으로 오해되지 않도록 표시한다.

## 타이포그래피와 배치

참고 페이지에서 관측한 기준은 데스크톱 메인 제목 약 100px, 모바일 메인 제목 약 40px, 참고 주요 섹션 제목 데스크톱 약 72px·모바일 약 28px, 메뉴 데스크톱 약 18px·하위 항목 약 16px이다. 제목과 메뉴의 위계 및 미디어와 텍스트의 상대 배치를 가깝게 적용한다. GeoSR의 로컬 Pretendard와 한국어 문장 길이에 맞춰 자간과 줄바꿈 및 기록 목록의 밀도는 조금씩 조정하고 큰 글자와 빈 공간이 과해지지 않게 확인한다.

메인 제목은 큰 크기를 허용하되 한 화면의 위계를 제목·짧은 설명·탐색 버튼으로 제한한다. 긴 원문과 수백 건의 실적은 읽기 폭을 통제한 게시판과 상세 화면에 둔다. 수치와 지도 등 실제 기록을 보여주는 이미지는 자르거나 다시 그려 실제 결과처럼 보이게 하지 않는다.

## 스크롤과 조작

- 일반 세로 스크롤을 기본으로 유지한다.
- 기술 갤러리는 데스크톱에서 페이지 스크롤로 좌우 이동을 유도하고 탭·드래그·트랙패드를 함께 지원한다.
- 모바일은 가로 스와이프와 분류 탭을 사용한다.
- 메인·회사 미디어의 확대는 섹션 진입 구간에서만 제한적으로 수행한다.
- 슬라이드에는 이전·다음·자동 전환 정지 조작을 제공한다. `prefers-reduced-motion`과 화면 밖 재생 정지를 따른다.
- 모바일 내비게이션은 터치와 키보드로 열고 닫을 수 있는 세로 아코디언으로 구성한다.

메인 전체 구간의 관측값과 화면별 적용 판단은 [한화오션 메인 전체 스크롤 추가 관측](hanwha-layout-scroll-review-20260928.md#메인-전체-스크롤-추가-관측--2026-09-29)에 적었다. 이미지 장면을 고를 때는 해당 분야의 설명·원자료·이웃 섹션과의 반복 여부를 같이 확인한다. 현재 메인 기술 갤러리에서 공간정보 장면의 측량 항공기가 가로 프레임 위쪽에 잘리는 문제를 발견해 초점을 재배치했다.

## 참고 검수 범위와 남은 검수

메인 드롭다운과 모바일 회사 메뉴, 회사 소개, 연혁, 해양 사업, 시추 상세 모달, 채용 안내, 뉴스 목록과 상세, R&D 설비 페이지를 실제 스크롤해 관측했다. 31개 메뉴 주소의 DOM 방문 기록은 모든 페이지를 끝까지 시각 검수했다는 뜻이 아니다. 해상도별 실제 페이지 확인 상태와 미완료 범위는 [한화오션 화면 관측 기록](hanwha-layout-scroll-review-20260928.md)에 구분해 적었다.

이 대조표는 사용자가 원하는 만큼 참고 화면의 구도와 상호작용을 충실히 적용하면서 GeoSR의 실제 기록·기술 분류·색상·문장·이미지·메뉴 관계로 완성하기 위한 작업 기록이다. 세부 수치와 크롭·전환은 GeoSR 자료가 잘 보이는 범위에서 다듬는다. 참고 페이지의 로고와 미디어 및 독창적인 카피를 가져오지 않고 같은 장면을 그대로 복제하지 않는다.

## 2026-09-29 구현 재검수
