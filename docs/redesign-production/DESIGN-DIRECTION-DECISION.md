## 선택: B 기반 하이브리드

B를 기본 정보 구조로 채택한다. 현장 근거와 기술 정보를 편집형 위계로 읽을 수 있고, 섹션 높이와 탐색 밀도를 조절하기 쉽다. 공식 사이트에는 A의 전체 화면 hero film 프레임 연출과 C의 키보드로 조작 가능한 연구 흐름 및 AX 미리보기 상호작용을 적용한다.

이번 디자인·QA 범위는 1440, 1920, 2560 CSS px desktop이다. 모바일은 후속 범위로 제외한다. Hero는 정확히 한 viewport 높이로 채우며 header는 미디어 위에 투명하게 겹친다. 첫 화면에는 다음 section이 나타나지 않는다. 현재 홈 정체성 문구는 사용자가 승인한 `Geo Data Intelligence`다. 이는 기존 방향 문구의 GeoDAP과 유사성 우려를 뒤집는 후속 결정이므로 이번 방향으로 기록한다. 한글 문구는 영어를 직역하지 않고 회사의 업무를 자연스러운 한국어로 설명한다. 영상이 들어오기 전에는 출처가 확인된 Earth poster를 유지하고 작은 제작 준비 상태를 표시한다. Hero 이미지와 이후 영상을 같은 slot에서 교체한다. AX의 Detect는 검증된 원본 캡처가 없어 16:9 준비 상태를 보여준다. 기존 Predict/Monitor poster는 새 라이브 캡처가 아니며, 출처·버전·사용 권리를 확인할 때까지 대표 미리보기로만 표시한다.

## 제외 및 유의점

- 대시보드 과밀도, 한 화면의 불필요한 지표·패널, 검증되지 않은 값이나 지도는 제외한다.
- 콘텐츠 높이에 비해 과도한 빈 화면과 장식 목적의 넓은 여백은 제외한다.
- 기존 공식 4개 분류를 Home에 카드로 반복하지 않는다. Home은 OBSERVE / ANALYZE / MODEL / PREDICT / DELIVER 흐름으로 안내하고, 원래 분류·ID는 기술 디렉터리에서 보존한다.
- 라임·네온, 실제 분석처럼 보이는 가상 레이어, 사람·손 이미지는 사용하지 않는다.
- 회사 정체성 카피는 GeoDAP의 “Earth Data Intelligence” 문구를 반복하지 않는다. GeoDAP은 독립 서비스로 분리한다.

## 후속 승인 및 정보 흐름 기준

- Home 연구 흐름은 OBSERVE → ANALYZE → MODEL → PREDICT → DELIVER의 다섯 단계다. 이전 문서에 남은 네 단계 구성은 폐기한다. AX 기능의 Detect → Predict → Monitor는 별도 플랫폼 기능 소개로 유지한다.
- Home은 5단계 업무 이야기, AX, GeoDAP, 자격 자료, 연구·소식, 문의 순으로 구성한다. AX와 GeoDAP은 서로 다른 서비스이며 화면과 설명을 섞지 않는다.
- AX에 보이는 Flood3D/Buoy 포스터는 이 작업에서 재캡처한 화면이 아니다. 대표 인터페이스 미리보기이며 출처·제품 버전·사용 권리는 검토 중이다. 위성 시설물 Detect는 같은 조건을 충족하지 못하므로 미리보기를 노출하지 않고 16:9 준비 상태를 보여준다.
- 현재 공식 진입점은 `dist/index.html`이다. `redesign-preview.html`은 독립 미리보기이며 공식 페이지의 기준이 아니다. 구체적인 페이지 자료와 미디어 상태는 [source inventory](SOURCE-INVENTORY.md), [content architecture](CONTENT-ARCHITECTURE.md) 및 현재 route 구현을 따른다.

## 구현 확인 범위

`dist/index.html`이 공식 Home route이며 `dist/home.js`, `dist/cinematic.css`와 공용 페이지 렌더러가 콘텐츠를 구성한다. `dist/redesign-preview.html`은 내부 검토용 미리보기다. 사진 위치·촬영일, 캡처 버전, 일부 자료 권리, 자격 문서 현행성은 공개 전에 원출처와 대조해야 한다. 회사 이력·조직·회사 소개서·채용 정보 및 문의 backend는 별도 콘텐츠 이관·운영 게이트다.
