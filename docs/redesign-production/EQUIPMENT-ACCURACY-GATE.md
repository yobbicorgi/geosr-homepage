# C05–C08 장비 정확성 gate

**원본 장비 cutout 보존이 제작의 기준이다.** 공식 원본 URL과 보존 파일은 [equipment source pack README](equipment-sources/README.md) 및 [manifest](equipment-sources/manifest.json)를 따른다. 공식 장비 사진에서 장비 픽셀을 alpha mask/cutout으로 분리해 형태·부품·비율을 그대로 유지한다. ImageGen은 배경, 수면, 환경, 자연광만 만든다. 장비 자체는 ImageGen으로 재생성·수정·인페인팅하지 않고 후반 합성에서 원본 cutout으로 배치한다. 기하 왜곡이나 부품 변경이 보이면 사용하지 않는다. 공개·파생 사용권은 별도 확인이 필요하다. 원본 각도나 해상도가 합성에 적합하지 않으면 생성형 장비 대체물을 만들지 말고 새 회사 사진을 요청한다.

The generated still files were discarded from the repository; their SHA-256 provenance remains in the shot prompt records. They are not production or website assets.

## 공통 완료 기준

- 원본 URL, 로컬 원본 경로, SHA-256, 장비명, 재사용 허가 상태와 사용 crop을 기록한다.
- alpha mask 경계와 장비 픽셀을 원본과 나란히 비교한다. 장비를 생성·인페인팅하거나 원근 왜곡하지 않는다. 크기 변경은 비율을 유지한 균일 scaling만 허용한다.
- ImageGen 출력은 배경·수면·환경·자연광 plate로만 제한하고, 장비는 후반 합성에서 원본 cutout으로 넣는다.
- 원본 각도·해상도가 목표 구도에 맞지 않으면 새 회사 사진을 받는다. 해상도 부족을 생성형 세부 묘사로 보완하지 않는다.
- 생성 문자·로고·UI·수치·그래프, 사람·손·얼굴, 가짜 지리·현장, 근거 없는 장비 조합이 없다.
- 2560×1440 결과와 사용 원본을 대조해 본체 형태·부품·비례의 왜곡이 없는지 확인하고, main review가 장비 fidelity를 새로 승인해야 한다. 승인 전에는 네 장면 모두 rejected 상태를 유지한다.
