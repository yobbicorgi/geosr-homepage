# GeoSR 전면 개편 — 제작 시작점

2026-09-17 · 메인 에이전트 설계 · **조사·설계 완료 / 구현 착수 전**

## 지금의 범위

한국 기업다운 정보 구성과 신뢰, 기술을 보여주는 영상, 선명한 국문·영문 경험을 갖춘 홈페이지 **목업**을 준비한다. 기존 화면을 다듬는 작업이 아니라 전면 재설계다. 이번 단계는 문서와 정적 설계도까지이며, 사이트 코드·영상 제작·유료 생성·배포를 실행하지 않는다.

처음에는 아래 네 파일만 읽는다. 전체 조사 폴더·1,105개 게시물을 미리 읽거나 홈페이지에 전부 넣지 않는다.

1. [페이지 디자인](01-PAGE-DESIGN.md): 형태, 화면 순서, 색·글자·메뉴, 국영문.
2. [영상·스크롤·모션](02-FILM-MOTION.md): 20초 메인 영상, 60초 소개 영상, 기술 영상과 상태 전환.
3. [목업 범위](03-MOCKUP-SCOPE.md): 소량 샘플, 빈 도형·게시글 표시, 구현 순서·완료 기준.
4. [설계 보드](visuals/main-design-board.svg): 메인이 작성한 화면·영상 배치. 정적 설계이며 완성 사이트가 아니다.

자료가 필요할 때만 [조사 근거](04-RESEARCH-INDEX.md)와 [기술·자료 맵](content-map.md)을 연다. `existing-work-synthesis.md`는 과거 작업 조사 기록이며 화면 설계 지시가 아니다.

## 결정 사항

- 기본 언어 한국어, 동등한 영어 전환. 같은 페이지·항목·필터를 유지한다.
- 사업·기술 / 연구·성과 / 플랫폼 / 관측·장비 / 회사소개 / 소식. 문의는 별도 버튼.
- 첫 진입은 데스크톱·모바일 모두 화면 전체를 채우는 무음 자동재생 영상. 영상 위에는 최소 문구·메뉴·조작만 둔다. 스크롤 뒤 밝고 읽기 쉬운 기술·성과 섹션으로 이어진다.
- 영상 분위기는 살리되, 첫 3~5초 안에 기술 자료가 등장한다. 단순 풍경·가짜 HUD는 제외.
- 목업용 대표 자료만 사용한다. 예시 행·빈 미디어에는 ‘목업 / Demo’를 표시한다.
- 원본 자료와 현재 프리뷰는 유지한다. 전체 자료 이관·번역·운영 연결은 후속 단계다.
- Higgsfield는 아직 결제하지 않았다. 이번 단계에서 생성·크레딧 사용·클라우드 사이트 생성은 하지 않는다.

## 문서 우선순위

최신 사용자 지시 → 이 폴더의 `00`~`04` 및 `main-design-board` → 사실 확인용 원문·데이터. 이전 `design-blueprint`와 `geosr-design-wireframe`은 서브에이전트 초안으로, 폴더 밖 복구본에만 보관한다. 기존 `PRODUCTION-HANDOFF.md`의 자료 출처와 기술적 사실은 참고하지만, 영상 길이·순서·레이아웃은 이번 설계가 대체한다.

## 진행을 재개할 때

사용자가 구현 시작을 지시하면 `03-MOCKUP-SCOPE.md`의 순서로 목업을 만든다. 데이터 전체 이관이나 영상 유료 생성으로 작업을 확대하지 않는다. 서브에이전트는 조사·검증만 담당하고 디자인·설계 결정은 메인이 맡는다.
