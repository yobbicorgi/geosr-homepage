# 회사 홈페이지 영상 방향 결정 · 2026-09-28

## 결정된 방향

- [올포랜드 메인](https://www.all4land.com/main.do)에서 참고한 것은 실제 세계 규모의 항공 뷰와 여러 시점이 이어지는 편집 리듬이다. 원본 영상·구도·코드·그래픽은 가져오지 않는다.
- GeoSR의 본편은 실제 한국 연안과 주변해역에서 회사의 여러 기술이 어떻게 자료를 만들고 활용하는지 보여준다. 무인선·실험실·위성 모형 중 하나가 주인공이 되지 않는다.
- 해안·도시·해수욕장·항만은 정확한 장소와 이용권을 확인한 실사로 표현한다. 생성된 가상 지형을 실제 한국 위치나 GeoSR 사업지처럼 쓰지 않는다.
- 위성 관측, 드론 지형조사, AI 영상분석, 해저 음향조사, ADCP·부이 관측, 채수·화학분석, 생태조사, 수치모델과 시계열 예측을 자료가 뒷받침되는 장면으로 나눈다.
- Higgsfield는 부족한 카메라 이동과 전환 또는 비자료 배경을 보완한다. 지리·수심·유속·AI 마스크·모델 결과·제품 UI의 내용은 실제 자료를 후반 합성한다.
- 60초 회사 본편과 24초 첫 화면 루프, 분야별 짧은 영상, AX 전용 영상, GeoDAP 짧은 영상을 별도 편집한다. 웹 최종 영상은 실제 1920×1080 이상에서 만든다.
