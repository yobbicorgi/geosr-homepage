# GeoSR 홈 하단 아트 디렉션 2026-09-21

## 문제

사용자 재검토에서 기존 개편은 전형적 박스 반복으로 판단됨
특히 연락 영역은 어두운 글자와 배경 충돌로 읽을 수 없는 상태
이전 비례 개선을 미감 승인으로 취급하지 않는다

## 메인 설계

전체 화면 hero는 보존한다
그 아래는 상자 크기 변경 대신 서로 다른 정보 형식을 조합한다
기본 정렬선은 화면 좌우 8%이며 FHD 기준 rem 체계를 따른다

- 전문 분야: 기존 2열 박스 폐기 / 실제 이미지를 화면 오른쪽 74%에 넓게 놓는 전폭 무대 / 왼쪽에서 이미지를 덮는 네이비 그라데이션 / 그 위에 제목과 분야 설명을 배치 / 하단 얇은 4분야 선택을 이미지와 겹침 / 상단 섹션 문구는 작은 오버라인만 / 과학 자료 합성 금지 / 실제 사진 비율을 유지하며 대상이 잘리지 않도록 contain
- 연구: 흰 배경의 편집형 인덱스 / 왼쪽 28% 섹션 제목 / 오른쪽 72% 3개 수평 행 / 번호와 분류 및 제목과 날짜를 정렬 / 남색 큰 카드와 R&D 워터마크 제거 / hover에만 옅은 블루와 수평 이동
- 플랫폼: 짙은 네이비의 독립된 두 제품 쇼케이스 / 카드 테두리 및 카드 배경 제거 / 크게 놓인 제품명 뒤로 미디어가 겹치는 z축 레이아웃 / 각 32% 소개와 68% 미디어 / 각 서비스명을 크게 쓰되 보조 문구는 자연스럽게 / AX 개념 자리는 데이터 장식이 아닌 3개 기능어의 타이포그래픽 구조 / GeoDAP 실제 이미지 비율 보존 / 두 제품의 위계 동일
- 인증: 기존 분류와 문서 앞면 갤러리 유지 / 타이포와 여백을 플랫폼 다음의 조용한 신뢰 영역으로 정리 / 실제 자료 보존
- 소식: 단순한 읽기 중심 목록 유지 / 연구 인덱스와 다른 조밀한 행 높이
- 공통 문의: 밝은 중성색 위 남색 버튼 상자 폐기 / 단색 브랜드 블루 #155db5 전폭 배경 / 흰 제목과 명확한 작은 링크 / 헤드라인 '다음 연구를 함께 시작합니다' / 설명 '사업 상담과 기술 문의를 기다립니다' / 연락처와 문의 링크를 분리 / 거대 화살표 제거하고 실제 링크에만 작은 화살표

## 모션

분야 전환은 미디어 fade + 16px 이동 500ms
플랫폼 화면은 viewport 진입 시 24px 이동 + opacity 700ms
연구 행 hover는 6px 이내 250ms
강한 틸트와 자동 반복 및 가짜 과학 시각화 금지
reduced-motion에서는 이동 없이 즉시 표시
본문은 JS 오류가 있어도 숨기지 않는다

## 반응형 및 검수

FHD/QHD/UHD 동일 비례 유지
모바일에서는 1열과 가로 스크롤 가능한 분야 선택으로 전환하며 화면 밖 텍스트 금지
문의 제목은 모든 상태에서 흰색 고정으로 대비 확보
한영과 링크 및 분야 전환과 인증 기능 확인
영상 제작과 신규 생성 이미지는 이번 범위에서 제외


## 구현과 검수

홈 첫 화면은 변경하지 않고 전문 분야를 이미지와 텍스트가 겹치는 전폭 장면으로 변경했다
연구는 순번을 갖는 편집형 목록으로 바꾸고 플랫폼의 카드 배경과 테두리를 제거했다
공통 문의는 브랜드 블루 배경과 흰 제목 및 별도 문의 링크와 연락처로 재구성했다
기존 WAAPI 진입과 탭 전환 및 reduced-motion 동작을 재사용한다

검수 중 발견한 이전 스타일 충돌을 수정했다

- figcaption top/bottom 동시 지정으로 늘어난 띠
- 전문 분야 설명의 남아 있는 최소 높이
- 플랫폼 설명의 기존 좁은 width
