# GeoSR 홈페이지 통합 설계서

작성 2026-09-29 · 상태: 설계 기준 및 구현 대조 중

이 문서는 페이지 구조와 영역별 콘텐츠 및 수정 작업을 결정하는 메인 문서다
사용자의 최신 지시가 우선이며 CURRENT-DIRECTION.md는 제작 제약을 요약한다

## 1 목적과 판단 기준

- 첫 방문자가 회사의 연구·엔지니어링 범위와 데이터 기술을 이해한다
- 해양만이 아니라 하천·호수·댐·하구·항만·해저 업무를 포함한다
- 메인은 회사 정체성과 대표 기술을 보여주고 상세에서 근거와 전체 기록을 제공한다
- 인공지능을 첫 기술로 제시하고 위성·원격탐사와 공간정보·측량을 구분한다
- 회사가 실제로 하는 일을 먼저 확인한 뒤 시각자료를 정한다
- 사진이 멋있다는 이유만으로 다른 기술에 배치하지 않는다
- 한화오션의 정보 위계와 정렬 및 스크롤 전개를 참고하되 회사 고유 자료로 구현한다

## 4 공통 레이아웃과 동작

### 상단

- 로고 왼쪽 가로 메뉴 중앙 언어 전환과 전체 메뉴 오른쪽
- 투명 헤더는 어두운 첫 장면에서만 사용하고 밝은 본문에서는 읽기 쉬운 표면으로 전환
- 데스크톱 드롭다운은 하위 메뉴가 같은 기준선에서 펼쳐지도록 구성
- hover뿐 아니라 키보드 focus와 Escape로 조작 가능
- 모바일 전체 메뉴는 분류별 아코디언이며 닫을 때 원래 초점 복원
- 언어 변경은 가능한 한 현재 페이지와 선택 기록을 유지
- 웹 탭 제목은 GeoSR

### 타이포그래피와 간격

- 로컬 Pretendard와 회사 파랑·짙은 남색 및 밝은 중성색 사용
- 메인 고정 문구는 Geo Data Intelligence이며 왼쪽 정렬
- 본문 제목도 동일 페이지의 왼쪽 정렬선을 공유
- 한화오션의 실제 동일 viewport 캡처와 제목 면적 및 줄 수를 비교한 뒤 크기 확정
- 임의로 큰 글자를 화면 중앙에 놓지 않으며 장식 영문 라벨을 반복하지 않음
- 작성 카피에는 쉼표와 마침표를 사용하지 않음 원문 게시글·논문·날짜·수치는 보존
- 번역투와 과장 수식어 및 혁신적인 최고의 새로운 미래 같은 상투어 제외
- FHD 1920×1080 QHD 2560×1440 모바일 390×844 기준 확인
- 회사 기록과 목록은 첫 화면에서 실제 내용이 보이도록 도입부 길이 제한

### 공통 모션

- 사용자가 화살표를 눌러야만 내용을 볼 수 있는 이미지 전환 제거
- 자동 전환이나 스크롤에 따른 전환 사용 정지와 reduced-motion 지원
- 이미지가 작은 도입 프레임에서 넓어지는 효과는 주제 전환에 사용
- 모든 구간을 화면 높이만큼 늘리거나 빈 spacer로 전환을 흉내내지 않음
- 영상은 무음 자동재생 뷰포트 이탈 시 정지 모바일 재생 실패 시 적합 poster
- 모바일에서 중요한 자료를 잘라 맞추지 않음

### 하단

- 회사 로고는 보조 크기로 배치 거대한 GeoSR 워드마크 제거
- 실제 회사 주소와 연락처 및 개인정보처리방침
- 내부 작업명 원문 아카이브 제작 출처 파일 경로는 일반 방문자 동선에서 제외

## 5 메인 페이지 영역별 상세 설계

### H01 첫 화면

목적: 조사·관측·모델·AI를 수행하는 GeoSR의 기술 범위를 즉시 전달

- 문구: Geo Data Intelligence 영어 고정 왼쪽 고정
- 설명은 필요한 최소한으로 제한 첫 장면에 분야 목록을 길게 나열하지 않음
- 매체: 서로 다른 기술의 역동적 클립을 연결한 무음 1080p 영상
- 내용: 실제 대상의 움직임과 자료 취득 또는 분석 결과의 변화
- 장면 후보: 위성 자료 취득 어류 AI 탄성파 처리 수치모델 현장 관측
- 해파리 제외 정적 풍경 확대만으로 구성한 영상 제외
- 제목이 생물과 주요 장비 및 분석 효과를 가리지 않도록 구도 검수
- 본편의 모든 원본 컷을 원장에 기록하고 같은 페이지 다른 영역에서 반복 금지
- 완료 조건: 전 구간 재생과 연결부 확인 제목 좌측 유지 중복 없음

### H02 회사 소개

목적: 단일 장비가 아니라 관측에서 분석으로 이어지는 회사 전체 역할 설명

- 제목 후보: 지오시스템리서치
- 설명 방향: 해양과 내륙 수환경을 조사하고 관측자료와 수치모델 및 인공지능으로 분석하는 회사
- 위 문장은 원문 회사소개와 대조한 뒤 최종 확정
- 링크: 회사 소개
- 매체: 관측자료와 지리 공간 및 모델·AI 분석의 관계를 설명하는 별도 이미지
- 단독 잠수부와 단독 선박 및 파도는 사용하지 않음
- 인포그래픽은 허용하되 자료 간 관계가 읽히고 장식 네온이나 별자리가 없어야 함
- 그림 전체가 의미를 갖는 경우 3:1 크롭 대신 원본 비율에 맞게 영역 구성
- 실제 회사 시설이나 운영 화면으로 오인시키지 않음
- 완료 조건: 회사 범위 전달 메인 클립 중복 없음 잠수부 제거

### H03 사업 및 기술

목적: 8개 역량의 차이와 대표 업무를 빠르게 파악

- 인공지능 수치모델·예측 위성·원격탐사 공간정보·측량 관측·조사 환경분석·생태 연안재해·방재 데이터·시스템 순서
- 각 분야에 이름 짧은 업무 설명 대표 장면과 상세 진입 링크
- 동일 카드 격자만 반복하지 않고 제목·설명 도입 뒤 미디어 전개
- 분야마다 매체를 다르게 배정하며 같은 이미지가 큰 패널과 작은 타일에 반복되지 않도록 확인
- 데이터와 장비 및 모델 결과가 필요한 분야를 자연 풍경으로 대체하지 않음
- 아래 21개 상세 대응표를 사용하며 새 임의 분류로 원문을 누락하지 않음

### H04 AX Platform

목적: 회사 기술이 분야별 플랫폼으로 구현된다는 소개

- 제목: 해양·환경 데이터 분석 플랫폼
- 메인 이미지: AX 기술의 통합 활용을 보여주는 별도 콘셉트
- 실제 플랫폼 화면은 상세 진입 후 곡면 갤러리에서 제공
- 왼쪽 제목과 짧은 설명 및 내부 링크
- 지형 장면만으로 플랫폼 기능이 읽히지 않으면 대체 제작
- 위성 탐지 이미지 하나를 여러 곳에 재사용하지 않음
- 완료 조건: 내부 삽입 유지 곡면 갤러리 유지 제목 정렬과 문맥 확인

### H05 GeoDAP

목적: 별도 데이터 서비스 소개

- 제목: 지구환경 데이터 플랫폼
- 관측·모델·위성 자료 탐색을 짧게 설명
- 실제 GeoDAP 메인 캡처 전체를 비율 보존하여 사용
- object-fit cover로 메뉴나 화면을 잘라내지 않음
- 서비스 열기 링크는 외부 새 창
- AX와 종속 관계로 설명하지 않음

### H06 수환경 연구 장면

목적: 광역 수환경 연구의 자료 처리와 해석 역량을 보여줌

- 기존 파도 장식 슬라이드와 본편 재사용 영상은 교체 대상
- 별도 자료동화 또는 예측 장면을 회사 원문에 근거해 제작
- 같은 페이지 H01 수치모델 컷의 재사용이나 단순 다른 크롭 금지
- 내용이 H03과 실질적으로 중복되면 별도 섹션 유지 필요성을 다시 판단
- 자료가 없다는 이유로 관계없는 풍경으로 완료 처리하지 않음

### H07 소식

목적: 최근 회사 활동으로 전체 게시판에 진입

- 실제 공지·보도자료만 사용 날짜와 원제 확인
- 짧은 선별 목록과 전체 보기 링크
- 연구 실적 전체 또는 인증 목록을 여기까지 나열하지 않음
- 미래 날짜 게시물은 등록일과 사건일을 구분하여 검토
- 기사 이미지가 없는 글에 임의 생성 이미지를 붙이지 않음

## 6 회사 소개 상세

| 영역 | 콘텐츠 | 시각 구성 | 확인 사항 |
|---|---|---|---|
| 도입 | 회사의 연구·엔지니어링 역할 | 제목과 짧은 설명 후 관련 대표 매체 | 단독 관광 풍경 금지 |
| 회사 개요 | 원문 회사 정보 | 정돈된 항목표 | 설립연도 주소 수치 원문 대조 |
| 조직 | 실제 부서와 상하 관계 | 반응형 조직도 | 임의 조직명 생성 금지 모바일 연결 읽기 |
| 연혁 | 전체 원문 기록 | 기간 탐색과 연도별 기록 | 파도·실험실 등 무관한 기간 이미지 제거 |
| 인증·면허·지식재산권 | 실제 문서 전체 | 분류와 문서 갤러리 확대 | 문서 전체 비율과 제목 연결 |
| 장비 | 실제 보유장비 | 분류 갤러리 상세 | 생성 장비 사진을 보유장비로 표시하지 않음 |
| 채용 | 원문 채용과 복지 | 짧은 도입 뒤 항목 | 긴 빈 공간 및 단어별 줄바꿈 제거 |
| 문의 | 실제 연락처 위치 | 간결한 주소·연락처·지도 | 가짜 폼 접수 기능 금지 |

연혁은 한화오션의 기간 탐색과 기록 정렬 원리를 참고한다
실제 시점과 연관된 회사 사진이 없으면 사진을 넣지 않는다
67개라는 과거 수치는 현재 원문 파싱 결과와 대조해 보존 여부를 확인한다

4 보유기술과 활용분야
5 실제 원문 자료 갤러리 및 확대보기
6 관련 연구·사업 기록과 문의

원문 내용은 요약문으로 대체하지 않는다
원문 그림이 도입부에도 쓰이면 아래 같은 그림을 반복하지 않고 도입부에서 확대 접근을 제공한다
서로 다른 기술의 영상은 이름이 비슷해도 바꿔 쓰지 않는다

- 제목은 회사명 또는 간결한 회사 역할 설명 하나만 사용

- 거짓 숫자와 실제처럼 꾸민 운영 대시보드는 사용하지 않음
- 글자를 이미지 안에 만들지 않으며 페이지 설명은 HTML로 제공

- 검수 실패 조건: 단순 네트워크선 그림 관광풍경 단독장비 컷 실제 의미 없는 그래프
