# 생성 이미지 원본

이 폴더에는 웹사이트 설명용 생성 이미지의 원본과 제작 영수증을 보관한다. 최신 이미지 제작은 ChatGPT 웹 대화에서 진행한다. 과거 도구로 만든 자산은 생성 이력에만 남긴다. 이 이미지는 GeoSR의 실제 시설이나 수행 사진, 관측값 또는 검증된 분석 결과를 뜻하지 않는다.

- `prompts.json`에는 제작 배치별 프롬프트와 생성 도구를 기록한다
- `manifest.json`에는 원본과 웹 파일 경로, 실제 해상도, 해시, 사용 위치와 채택 상태를 기록한다
- `.png`는 생성 원본이며 웹에는 압축한 `dist/assets/editorial/*.webp`를 사용한다
- 화면 크기와 맞지 않아 교체한 원본도 프롬프트 검토 이력을 위해 manifest에서 상태를 구분한다
- 새 분석 장면의 선·격자·분할 그래픽은 이미지 또는 영상 제작 단계에서 함께 만들고 원래 GeoSR 결과 자료와 구분한다

가로형 장면은 주로 1672×941이다. 기존 생태 조사 세로 이미지는 1122×1402로 원본을 보존하고, 가로형 갤러리와 회사 소개에는 `ecology-survey-wide`를 사용한다. 원본 해상도를 늘려 고해상도라고 표시하지 않는다. 메인 첫 화면은 해안·해양 관측·내륙 저수지와 하천·AI를 순서대로 보여준다. GeoDAP 뒤의 파도 전환 구간은 별도 장면을 쓴다. 파도 전환 구간은 해안선·외해·포말을 보여주는 분위기 슬라이드이며 회사의 조사 실적이나 예측 결과를 나타내지 않는다.
지원 가능한 최대 크기를 요청한 사실과 실제 전달된 크기를 구분한다

기술 상세 도입 장면에는 항만 환경영향 검토, 하구 부유물 시료 조사, 염생식물 연구, 미세조류 분석, 연안 월파, 해안 카메라 모니터링에 맞춰 별도 콘셉트 이미지를 추가했다. 모두 회사의 실제 현장 기록으로 표현하지 않는다. 기술별 실제 지도·그래프·장비·관측 자료는 `dist/assets/source-records/`의 원본을 갤러리에 남긴다.

연안침식 모니터링은 기존 해빈 조사 사진의 해변과 이안제 구도를 참고해 별도 고해상도 콘셉트를 만들었다. 이 이미지는 현장 사진이나 침식 분석 결과가 아니며 원본 사진과 실제 조사 자료는 상세 페이지의 기술 자료 갤러리에 보존한다.

해양공간계획은 해상풍력 입지 검토와 시각 주제가 겹치지 않도록 항로·어업·보전 구역을 조율하는 장면으로 구성했다. 흐린 구역선과 항로선은 개념 표현이며 실제 해역 경계나 분석 결과가 아니다.

`manifest.json`의 `promptRecord`가 `reconstructed-brief`인 항목은 앞선 생성 작업의 전체 프롬프트가 현재 기록에 남아 있지 않아 장면과 용도에 근거해 제작 브리프를 복원한 것이다. 이후 제작 프롬프트는 `verbatim-generation-prompt`로 구분한다.

기술 ID 65의 첫 콘셉트는 ID 46 통합모델링의 항공 하구 장면과 시각 구도가 겹쳐 외해와 섬 군락을 사선으로 바라보는 `regional-ocean-forecast-v2`로 바꿨다. 기존 해류·수온 지도와 모델 검증 그림은 원자료 갤러리에 그대로 둔다. 교체 전 이미지는 제작 이력에 남기며 현재 상세 페이지에서는 사용하지 않는다.

위성 원격탐사 분야의 대표 컷은 큰 광선과 비현실적인 위성 스케일이 없도록 다시 제작한 `satellite-optical-native-20260929`로 교체했다. 수직 시점의 가상 연안과 관측 범위·수역 처리 영역을 보여주는 설명용 시안이다. ID 56의 실제 위성 자료는 원문 갤러리에 유지한다.
