선택한 보드 기준을 공통 변수와 의미 있는 컴포넌트 클래스에 반영
새 `final-final.css` 같은 후행 덮어쓰기 파일을 추가하지 않음
사용되지 않는 코드 제거는 호출·DOM·참조 확인 후 별도 작은 커밋으로 진행
관련 없는 원문·다운로드·검수 자료를 청소 명목으로 삭제하지 않음

구현 순서 — Home 중간 → AX → Company → 기술 → 연구·소식 → 장비 → 문의·footer
한 페이지의 시각 기준이 흔들리면 전 페이지를 동시에 수정하지 않음

산출 — 개선된 KO·EN 화면 / 공통 토큰 / 모션 감소 대체 / 변경 전후 캡처
통과 — 단순 여백 수정이 아닌 화면 구성 차이가 보이며 정보 탐색과 기존 링크·원문 관계 보존
