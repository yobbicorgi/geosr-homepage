# 영상과 이미지의 제작 방향

> **2026-09-28 갱신:** 현재 컷 순서와 프롬프트는 [회사 근거 원장](16-COMPANY-FILM-EVIDENCE-20260928.md)과 [1080p 콘티](14-1080P-FILM-STORYBOARD-20260928.md)를 따른다. 이 문서는 장비·물리·자료의 검수 참고다. AX 페이지는 제공된 저장소의 AX 부분만 삽입한다.

## 세 종류를 분리

| 결과물 | 역할 | 화면 | 현재 상태 |
| --- | --- | --- | --- |
| 회사 본편 60초 | 회사 기술의 실제 대상과 결과 | 광역 현실 환경 → 위성·AI → 드론·해저·유속·부이 → 채수·생태 → 모델·예측 → 광역 환경 | 콘티 확정 중 / 검수된 본편 없음 |
| AX 전용 약 30초 | 직원 제작 제품의 기능 | 탐지·예측·관측의 실제 UI와 별도 전환 | 제품 실제 화면은 삽입됨 / 검수된 영상 없음 |
| GeoDAP·분야별 짧은 영상 | 해당 화면 또는 기술의 시각 근거 | 실제 서비스 메인 또는 해당 분야 자료 | 검수된 영상 없음 |

회사 본편에는 AX·GeoDAP 화면을 넣지 않는다. 두 서비스는 각각의 별도 영상과 홈페이지 소개 영역에서 보여준다.
AX 전용 영상은 실제 앱 UI가 주인공이며 UI를 모델로 다시 생성하지 않음
플랫폼별 기능 시연에서 생성 UI나 다른 서비스의 결과를 대신 쓰지 않음
독립된 AX 서비스가 이미 자동 연동되는 하나의 시스템이라는 인상도 피함

## 회사 60초 편집 기준

현행 13컷 시간표와 화면 비중은 [1080p 콘티](14-1080P-FILM-STORYBOARD-20260928.md)를 따른다. 연안·하구·바다·도시의 광역 현실 환경에서 출발하되 실제 회사 기술의 여러 분야가 균형 있게 보인다. `production-plan.json`의 CF01–CF13과 생성된 `PROMPT-CARDS.md`는 원본 프레임을 붙일 제작 카드이며 아직 `generationReady=false`다.

광역 환경 컷은 카메라의 전진·선회·거리감을 살리고 장면마다 실제 세계 같은 규모가 읽혀야 한다. 장비와 분석 장면은 현장 맥락을 보조한다. 별도 장소를 하나의 실측 공간처럼 관통하지 않으며 위치가 다르면 명확한 컷으로 전환한다.

Higgsfield의 생성 환경·전환은 실제 촬영이 아니다. 출처가 확인된 실제 지형·장비와 맞지 않는 가상 위치를 GeoSR 사업지나 특정 한국 해안으로 소개하지 않는다. 위성·지도·자료·모델 층은 실제 원본 기반으로 합성한다. 기술적 시각 효과는 후반 편집에서 자료와 정합해 관측점·측선·격자를 더한다. 영문·한글 제목은 HTML에서 관리한다.

## AX 30초 편집 기준

| ID | 편집 시간 | 핵심 시각 | 연결과 제한 |
| --- | --- | --- | --- |

| AX03 | 14–22 | 연안재해 화면에서 조건 변경과 결과 확인 | 실제 제품 동작만 사용 / 개발 중 기능은 제외 |
| AX04 | 22–27 | 관측 화면에서 정점·시계열 확인 | 실제 날짜·수치·범위를 유지 |
| AX05 | 27–30 | 세 제품 분야를 간결하게 정리 | 실제 화면 조각은 맥락이 보이게 편집 / 마감 그래픽은 별도 층 |

AX는 실제 직원 제작 화면의 사용 과정을 보여준다
선택된 대상 → 분석 과정 → 이해 가능한 결과가 매 컷 보여야 함
유리 판넬을 반복 생성하는 이전 AX02 후보는 재사용하지 않음
한 가지 양식장 탐지 이미지를 모든 플랫폼의 대표 기능으로 확장하지 않음

## 이미지 제작과 합성 구분

`production-plan.json`의 각 장면은 입력 근거와 이미지 지시 및 모션 지시를 모두 가짐
`method`가 `source-composite`이면 생성 모델 대신 원본 지리·자료를 보존한 합성 작업 지시로 사용
`imagegen-reference`이면 ImageGen으로 콘셉트 후보를 만들되 참조 장비의 형상 검수를 거침
출처와 사용 권한을 확인할 수 없는 제3자 자료는 공개용으로 확정하지 않음
사용자의 회사 자료 사용 지시를 무시하고 모든 내부 초안마다 허가를 반복 요청하지는 않음

사진처럼 보인다고 실제 조사 사진이 되는 것은 아님
생성 실험실은 GeoSR 실험실의 실사진이라고 부르지 않음
장비 썸네일이 작으면 사진에 없는 기구·단자·케이블을 고해상도 사실로 지어내지 않음
실물 디테일을 확보하지 못하면 제한된 시점의 콘셉트 또는 다른 검증된 장면을 선택

## 과학·물리 검수 항목

| 대상 | 확인할 것 | 실패 예시 / 조치 |
| --- | --- | --- |
| 위성 | 본체·패널 강체 형태 / 태양광·그림자 / 센서의 지구 방향 | 본체가 줄어들거나 패널이 바뀜 → 해당 생성물 제외 / 별도 합성 |
| 지리 | 한반도·제주·일본·해협과 해안선 / 지구 표면 정합 | 가짜 항구·방파제 또는 육지 뒤섞임 → 생성 배경 제외 |
| SST·SSS·Chl-a | 센서·시점·해상도·단위·결측 / 육지 마스크 | 자료 층마다 다른 시점인데 동시 관측처럼 합침 → 시각·설명 수정 |
| 수심측량 | 선박 위치와 트랜스듀서 / 아래로 펼친 음향 관측 맥락 | 소나를 수중 광선으로 표현 → 얇은 도식 합성 또는 효과 제거 |
| 드론 | 사진측량·지형 LiDAR·수심 LiDAR의 원리 구분 | 일반 드론이 깊은 해저까지 스캔 → 관측 대상 변경 |
| 부이·CTD | 부력·흘수·계류 / 케이블 하중 경로·장력·수면 접점 | 케이블 공중 연결·불가능한 매달림 → 재생성 전 원본 구조부터 수정 |
| ROV·센서 | 실물 구조 / 테더 / 관측 대상 / 스케일 | TPRBM을 확인 없이 다른 센서로 해석 → 명칭 보류 / 원본 확인 |
| 실험실 | 장비 사용 단계 / 용기·튜브 연결 / 시료 종류 | 열린 분석기에서 실제 측정 빛이 나옴 → 시료 준비 단계로 제한 |
| 생물 | 실제 시료/현미경 자료의 배율·형태 | 생성 이미지를 특정 종·검출 결과로 주장 → 실자료 대체 또는 개념 표시 |
| 수치모델 | 지형·시간·경계조건·육지 마스크 / 결과 의미 | 해류·침수·농도장을 같은 효과로 혼용 → 변수별 별도 합성 |

[NOAA 다중빔 원리](https://oceanexplorer.noaa.gov/technology/sonar-multibeam/)는 음향 관측의 방향과 수심 관계를 검토하는 근거임
[NOAA LiDAR 개요](https://oceanservice.noaa.gov/facts/lidar.html)는 지형용과 수심용 LiDAR를 구분하는 근거임
[NASA 해양 염분 자료](https://salinity.oceansciences.org/overview.htm)와 저장소 GIBS 원장은 염분 자료의 별도 센서·제품 확인에 사용
위 링크를 읽었다는 사실이 생성 이미지의 모든 디테일 합격을 뜻하지 않음

현재 보존된 NASA 입력은 월별 MODIS SST와 월별 Aquarius SSS 및 일별 MODIS Chl-a 제품이 섞여 있음
동일 센서·동일 순간 자료가 아니며 chlorophyll 결측을 생성 보간으로 지워서는 안 됨
`../redesign-production/keyframes/sources/corporate-film-c04-v1/gibs-c04-source-manifest.json`에서 실제 요청·날짜를 재확인

## 실제 플랫폼 녹화

서비스별 상세 동작과 참조 파일은 장면 원장의 `platformCaptures`에 저장
1920×1080 또는2560×1440 CSS viewport에서 본문이 모두 로드된 뒤 캡처
로그인 정보·사용자 정보·내부 식별자·개인정보는 공개 결과에 넣지 않음
화면 녹화는 실제 읽기 동작과 시각화 결과만 사용 / 저장·삭제·유료 연산을 시연용으로 실행하지 않음

원본8–15초 → 편집3–5초를 목표로 하되 핵심 결과는 최소0.8초 유지
빠르게 재생해도 커서 동작과 결과의 인과관계가 읽혀야 함
16:9 전체 화면 → 같은16:9의 기능 확대 → 전체 맥락 복귀 순서
편집 중 직사각형 화면의 한쪽 메뉴만 잘라 화면 중앙에 띄우지 않음
확대 시 비율과 글자 선명도를 유지하고 필요한 맥락이 사라지면 전체 화면으로 복귀
MP4를 기본으로 하고 GIF는 특별히 필요한 짧은 예시만 사용

환경 플랫폼은 SST와 SSS의 날짜·기간을 원본 그대로 기록
결측이 심한 chlorophyll 후보를 억지로 가득 찬 자료처럼 만들지 않음
`flood-xai`는 개발 중으로 확인되어 실제 기능 시연 대기 / 가짜 화면으로 대체 금지

  "scientificMeaning": "pending",
  "visualQuality": "pending",
  "continuity": "pending",

정지 프레임은100% 크기로 확인 / 영상은 전체 재생과 시작·중간·끝 및 문제 구간을 확인
오류가 있으면 프롬프트·참조·합성 방식 중 원인을 수정하고 다시 검토
오류 없는 생성을 약속하는 대신 미확인 항목이 있는 결과를 공개 합격으로 넘기지 않는 절차를 사용

## 예산과 납품

현재 이 패키지는 생성 크레딧을 사용하지 않음
다음 제작자는 크레딧·모델·720p·종횡비·개수·비용을 화면에서 확인한 뒤 작은 배치로 실행
배치는 광역 연안·하구 환경 → 현장 → 분석·모델 순서로 품질 게이트를 통과한 것만 진행한다. AX 상세는 제공된 저장소의 AX 화면·내용만 로컬 삽입했고 AX 전용 영상은 후속 계획으로 둔다
생산 완료 / 재작업 / 원본 대기 / 크레딧 대기를 구분하고 크레딧이 실제로 부족할 때만 다음 충전 배치로 이동
자동 일일 재충전을 가정하거나 승인 없는 정기 실행을 만들지 않음

초안 H.264 MP4 /16:9 /1280×720 /24또는30fps / 무음 또는 오디오 트랙 제거
최종 해상도와 인코딩은 실제 납품 비용·디코딩 성능을 확인해 결정
원본과 웹용 파일을 분리하고 poster와 정지 대체 이미지를 함께 납품
수치자료의 글자와 범례는 생성 영상에 굽지 말고 후반 합성 또는 HTML로 관리
완성 후 `dist/film-manifest.json`에 검수된 결과만 연결하고 초안 표시를 해제할 근거 기록을 함께 남김
