## 검수

기존 `env-poster.webp`는 1280 × 720 파일이지만 이미지 자체의 좌우에 검은 여백이 있었다
새 캡처는 좌측 항목 메뉴·중앙 지도·우측 분석 안내가 16:9 화면 전체를 채운다
수치와 일자는 당시 서비스에 표시된 내용 그대로이며 캡처가 자료 정확성이나 최신성을 별도로 검증했다는 뜻은 아니다
웹사이트에서는 실제 화면의 정지 미리보기임을 표시하고 실시간 서비스 화면으로 오인시키지 않는다

클로로필 화면은 띠 형태의 결측/표출 패턴이 눈에 띄어 대표 캡처로 채택하지 않았다
고급 COG 표출은 확인 중 로딩이 지속되어 기본 상태로 복구한 뒤 종료했다
따라서 클로로필 이미지를 임의로 보정하거나 새로 그리지 않았다

satellite / flood3d / surge / sealevel / buoy / rip / news의 기존 포스터는 메인이 직접 픽셀 화면을 확인했다
이 7개 포스터는 실제 UI가 프레임을 채우며 별도의 검은 letterbox 여백이 확인되지 않았다
원본 플랫폼 UI에 있는 지도 배경·패널 여백과 인코딩 과정에서 들어간 검은 띠를 구분했다
