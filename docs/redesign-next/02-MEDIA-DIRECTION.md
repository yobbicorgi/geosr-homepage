[회사 영상 장면 설계와 위성 2단계 콘티](reviews/20260929-company-film-scene-system.md)에는 실제 관찰한 기업·기술 영상과 메인 10개 주제 약 48초 편집 순서 및 각 분야의 입력·분석·활용 관계를 기록했다. 위성은 궤도 통과와 영상 분석을 별도 4초 장면으로 나눠 제작한다.

## 수정의 이유

이전 안은 넓은 자연 전경에 치우쳤고 영상도 원본 구조를 유지하는 데 집중해 장면 안에서 실제 업무가 일어나지 않았다
새 기준은 방문자가 그림만 보아도 관측 대상과 조사 방식 또는 분석 목적을 파악할 수 있게 하는 것이다
사진이 조금 움직이는 결과를 완성 영상으로 취급하지 않는다

## 위치별 역할

- 메인 Geo Data Intelligence는 회사 범위를 대표하는 10개 주제 약 48초 연속 영상으로 재설계한다 위성·드론·연안 감시·탄성파·현장 계측·실험·AI·수치모델·생태·연안 적용을 포함하고 같은 자연 전경이나 모델 장면을 연속 반복하지 않는다
- 한 장면은 2–3개의 핵심 동작으로 구성한다 광역 장면과 장비 및 분석 장면의 크기 차이로 편집 리듬을 만든다
- CTD는 현장 계측의 한 장면이며 회사 전체를 대표하는 소재로 독점하지 않는다
- 파도는 별도 전환 구간에서 물성을 보여준다 기술 설명을 대신하지 않는다
- 대표 분야 이미지는 자체 주제를 선명하게 보여준다 완성 정지 이미지에 의미 없는 자동 확대·흔들림을 추가하지 않는다
- 기술 상세 원문 그림·실제 장비 사진·연구 기록은 보존한다 생성 장면을 실제 관측·회사 소유 설비·실적으로 주장하지 않는다
- AX 도입은 개념을 보여주고 곡면 갤러리는 실제 제공 화면을 보여준다 GeoDAP은 실제 전체 화면을 자르지 않고 외부 연결한다
- 목록·게시판·인증 문서는 정보 탐색이 우선이다 공통 홍보 영상을 넣지 않는다

## 제작과 검수

1. 이미지는 ChatGPT 웹에서 생성하고 원본 다운로드를 사용한다 Higgsfield에서 정지 이미지를 만들지 않는다
2. 대상·시점·시작 상태·핵심 동작·종료 상태·주제와의 관계 및 배치 위치를 기록한다
3. 박스·마스크·격자·분석 UI는 이미지나 영상 생성 단계에서 함께 만든다 사후 오버레이를 추가하지 않는다
4. 영상은 검수한 ChatGPT 원본을 입력으로 Seedance 2.0에서 만든다 실제 비용 확인 후 한 장면씩 검수한다
5. 시작·중간·끝과 핵심 동작 중의 연속 프레임을 본다 구조 변형·주석 추적 실패·수역 밖 확산·물리적 불연속은 제외한다
6. 편집은 검수한 클립 연결과 전환만 수행한다 프롬프트 불량을 덧그린 박스로 보완하지 않는다
7. 정지 이미지의 pan·zoom이나 환경의 미세한 흔들림만 있는 결과는 동적 업무 장면 합격이 아니다
8. 미래 영상 자리에만 영상 대체 예정 배지를 표시한다 완성 정지 이미지에는 배지를 붙이지 않는다

## 현재 판정

- AI 해파리 영상 재시도는 대상과 박스 추적이 어긋나 제외했으며 같은 입력의 추가 유료 반복 중단
- AI 어류 5개체 정지는 박스와 마스크 검수 후 사업 분야 소개에 배치
- 신규 해안 전경 후보는 연구 주제가 드러나지 않아 메인 채택 제외
- 신규 CTD와 수환경 모델은 장면 목적과 동적 시작 상태 재검수 중
- AX 상세 하구 플룸 영상 1건은 원본과 업로드가 맞았지만 시작 분포가 상류로 바뀌고 끝 분포가 하구에서 분리되어 제외했다 54크레딧을 사용했으며 원본 정지 이미지는 유지한다
- 위성 모자이크 6초 영상 1건은 54크레딧을 사용해 생성했다 지형 정합과 상류→하구→해역 분석층 진행은 통과했지만 시점과 화면 규모가 완전히 고정되어 메인 첫 화면 대표 오프닝에는 부적합하다 기술 설명 삽입 또는 메인 하단 후보로만 보존하며 사이트에 반영하지 않았다
- 기존 `coastal-aerial.png`는 방파제와 항만 입구 및 항로 구조가 모호해 메인 첫 화면 교체 대상으로 판정했다 새 정지 원본은 좌측 제목 안전 영역과 자연스러운 해안 구조를 함께 검수한다
- 9월 29일 최신 제작 순서는 메인 첫 화면 → 메인 하단 → 각 메뉴 내부다 메인 첫 화면의 원본·시작/끝 상태·콘티와 비용을 먼저 검토하고 다음 유료 접수 전에 보고한다
- 새 메인 오프닝은 해안의 서로 다른 깊이 층에서 실제 전진·하강·측면 시차가 읽히도록 만든다 뒤의 현장 CTD는 연결된 장비가 물에 들어가는 사건 AI는 대상 이동과 주석 추적 수치모델은 연결 수역의 분포 변화를 각각 보여준다 카메라 이동만으로 각 장면을 합격시키지 않는다
- 파도 → CTD → 모델 → 분석의 4장면 초안은 AI·위성과 대상 다양성이 부족해 최종 확정하지 않음
- 비용·잔액·해시는 제작 원장이 기준이며 이 장면 목록은 유료 생성 승인이 아님
