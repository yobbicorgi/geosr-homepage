## 전체 이미지·영상 공통 연출 기준

### 최신 선택과 배치

- 사용자의 최신 지시에 따라 서브에이전트를 사용하지 않고 메인 담당이 순서대로 직접 진행한다

- 동일 페이지에서는 같은 이미지나 영상 컷을 반복하지 않는다 메인 편집 영상에 포함된 장면을 메인 하단에서 다시 사용하는 것도 중복이다 메인과 별도의 세부 페이지 간 재사용만 허용한다 중복 위치는 문맥에 맞는 별도 장면을 제작해 교체한다

- 어류 R2 영상은 사용자가 수영 및 카메라 동작을 긍정 평가했다 이 동작을 보존하면서 탐지 박스와 마스크를 보강한다 분석 효과가 약한 현재본을 완성된 AI 소개로 판정하지 않는다
- AI 대표는 어류로 통일하며 해파리는 메인 편집본과 세부 영역에서 제외한다 해파리 신규 제작도 진행하지 않는다
- Geo Data Intelligence는 모든 장면에서 왼쪽 고정이다 AX와 GeoDAP 소개 제목도 같은 왼쪽 기준선을 사용한다
- 이미지 탐색용 이전·다음 화살표를 강요하지 않는다 자동 전환 또는 스크롤 전환으로 보여주며 정지 기능과 모션 감소 설정을 지원한다 게시판 페이지 이동은 유지한다

### 모든 영상의 생성 전 필수 검토

사용자 지시에 따라 모든 영상 프롬프트는 ChatGPT 웹에서 사전 검토를 받는다

1. 실제 제작에 사용할 기준 이미지를 첨부한다
2. GeoSR 기술 홍보 목적과 해당 분야 및 원하는 완성 장면을 설명한다
3. 대상의 동작과 카메라 경로 및 생성 단계에 포함할 기술 효과를 명시한다
4. 프롬프트와 이미지의 충돌 및 정적인 결과로 이어질 제약을 검토하도록 요청한다
5. 검토 의견을 사용자 요구와 대조하고 최종 프롬프트에 반영한다 후처리 오버레이 등 사용자 지시와 충돌하는 제안은 채택하지 않는다
6. 대화 URL과 입력 이미지 경로 및 검토 의견과 최종 프롬프트를 장면별로 기록한 다음 비용을 확인하고 생성한다

자체 검수만으로 이 절차를 대체하지 않는다 ChatGPT 검토 완료는 결과 품질 보증이 아니므로 생성 후 동작과 사실성 및 배치 검수도 수행한다

2026-09-29 사용자 교정은 모든 분야와 모든 배치에 적용한다

- 목적은 GeoSR 기술을 소개하는 실사형 기업 홍보 콘텐츠다 실제 분석 화면의 픽셀 단위 재현을 요구하지 않는다
- 장면마다 대표 기술과 대상의 행동 및 기술 효과를 먼저 정한다 풍경만으로 해당 기술의 소개를 대신하지 않는다
- 영상은 대상의 실제 동작과 카메라 이동 및 깊이 변화가 읽혀야 한다 고정 이미지의 평행 이동이나 미세한 파도만으로 완성 판정하지 않는다
- 인공지능은 자연스러운 대상 움직임에 탐지·분할 효과가 대응한다 수치모델은 변화하는 예측 표현을 보여주며 측량·관측은 촬영·취득과 자료 형성의 관계를 보여준다
- 정지 이미지는 해당 기술이 읽히는 순간을 구성한다 모든 이미지에 억지로 그래픽을 추가하지 않고 장비·실험·연구 내용에 맞는 표현을 선택한다
- 기술 효과는 생성 단계에 포함한다 별도 HTML 그래픽이나 후처리 박스·마스크를 덧붙이지 않는다
- 생물의 운동과 장비 구조 및 지형·원근·스케일의 개연성은 유지한다 정밀한 실제 측정값을 꾸며내는 대신 소개 목적의 설명적 효과를 사용한다
- 2026-09-29 최신 사용자 의견은 기존 드론 움직임·선박 스캔·수치모델 격자·선박 CTD·확산·해파리·초기 바다 S자 네온 영상의 활용을 허용한다 과거 드론 제외 판정은 활용 후보 재개로 변경한다 정확한 생성 결과를 확인해 문맥에 맞게 배치하며 기존 어류 평행이동 영상의 제외는 유지한다

상세 교정 근거: [모션 검수 기준 교정](reviews/20260929-motion-acceptance-correction.md)

## 우선순위

이 문서는 2026-09-28 대화에서 변경된 지시를 통합한 현재 기준이다
과거 레퍼런스와 시안의 승인 상태를 현재 승인으로 사용하지 않는다

1. 한화오션만 현재 디자인 레퍼런스로 사용한다 다른 기업 사이트는 현재 설계 기준에 추가하지 않는다
2. 주요 메뉴 전체를 실제 방문하고 페이지 끝까지 스크롤하며 레이아웃과 모션을 조사한다
3. FHD QHD UHD와 모바일에서 실제 CSS viewport를 확인한다
4. AX 곡면 가로 갤러리를 유지하고 나머지 모든 화면은 한화오션의 구성·디자인·배치·조작 요소를 기준으로 통일한다
5. GeoDAP만 별도 외부 서비스로 연결하며 실제 화면 전체를 잘림 없이 보여준다
6. 검수한 ChatGPT 웹 원본을 이미지와 슬라이드로 먼저 배치하고 승인된 장면만 Seedance 2.0 영상으로 교체한다 현재 작업은 영상 제작과 통합까지 포함한다

영상 제작과 배치 순서는 메인 첫 화면 → 메인 화면 하단의 장면 → 각 메뉴 내부 장면이다 앞 순서의 콘티와 시작·끝 프레임 및 원본 적합성을 먼저 검수하고 다음 장면을 접수한다
메인 첫 영상은 서로 다른 기술을 표현하는 5~10초 장면을 연결한다 합격한 한 장면은 같은 기술의 세부 페이지 도입에서 재사용할 수 있다 메인에서는 회사 전체의 흐름을 보여주고 세부에서는 원문 자료와 함께 깊이를 더한다 무관한 분야에 같은 컷을 돌려 쓰지 않는다

메인 장면 순서와 위성 촬영→자료 분석의 상세 콘티는 [회사 영상 장면 설계](reviews/20260929-company-film-scene-system.md)를 따른다 외부 기업·기관 영상은 장면 구조와 과학적 표현을 살펴본 참고일 뿐 현재 홈페이지의 디자인 레퍼런스는 한화오션으로 유지한다
7. 사업·기술·미디어 구성은 [회사 전체 조사](../company-audit/README.md)를 근거로 정하며 위성영상과 공간정보를 분리하고 인공지능을 독립 분야로 우선 소개한다
8. 국문 내용을 기준으로 한영의 항목과 본문을 맞춘다 기존 영문에 없는 내용은 국문 전체를 번역하고 이미지와 첨부파일도 동일하게 제공한다

## 참고와 독자 제작

한화오션의 페이지 흐름과 메뉴·드롭다운·스크롤 전환·대형 미디어·텍스트 배치·슬라이드 조작 등 세부적인 화면 문법을 높은 충실도로 적용한다
메인과 세부 페이지의 순서와 시선 흐름은 레퍼런스처럼 또렷하게 유지하고 GeoSR의 회사 자료에 맞춰 섹션 수와 내용 및 장면을 채운다
필요한 차이는 GeoSR 로고와 파랑 계열 색상, 로컬 Pretendard, 메뉴 이름, 업무 자료와 자체 이미지에 맞춰 조정한다
레이아웃을 일부러 멀리 바꾸지 않는다 콘텐츠가 다르면 미디어 비율·텍스트 정렬·전환 타이밍 같은 작은 차이로 화면을 자연스럽게 맞춘다
타사 로고·전용 폰트·소스 코드·사진·영상·고유 문구는 복사하지 않는다 레퍼런스의 화면 설계 원리를 GeoSR의 콘텐츠와 자체 자산으로 다시 구현한다
타사와 구별하기 위한 것은 임의의 장식이 아니라 GeoSR의 실제 정보와 로고·색상·문장·이미지다

상세 반영 관계는 [한화오션과 GeoSR 구성 대조표](reviews/geosr-reference-crosswalk-20260928.md)에 기록한다

- 미디어 내부의 탐지 박스와 분할 마스크 및 분석 UI·격자·그래픽은 이미지나 영상 생성 단계에서 함께 제작한다 HTML·SVG·Canvas나 영상 후처리로 덧씌우지 않는다 영상 편집은 검수된 클립 연결과 전환만 허용한다 박스 유지 지시와 UI 금지 지시처럼 충돌하는 문구를 접수 전에 검토한다

## 고정 요소

- 영문 메인 문구는 `Geo Data Intelligence`
- 실제 GeoSR 로고와 파랑 계열 색상
- 로컬 Pretendard Variable 1.3.9 및 SIL OFL 라이선스
- 모든 웹 탭 제목 `GeoSR`
- 자연스러운 한국 기업 문장과 동등한 영문 페이지
- 직접 작성하는 홍보 문구에는 쉼표와 마침표를 사용하지 않는다
- 원문 게시글과 논문 제목 및 주소 등 데이터는 임의로 변형하지 않는다
- 직원 저장소에서 삽입한 AX 곡면 가로 갤러리는 유지한다

## 화면 구성

### 메인

전폭 이미지 슬라이드 → 회사 소개와 미디어 확장 → 대표 사업 및 기술 → AX 소개 → GeoDAP 소개 → 파도 장면 → 주요 소식

현재 첫 화면은 네 장의 임시 이미지 슬라이드이며 최종 장면 구성은 아니다 9월 29일 사용자 지시에 따라 위성·원격탐사와 현장 계측 및 AI 분석과 수치예측의 대상·행동·결과가 읽히는 영상으로 재설계한다 넓은 자연 전경이나 관측선 한 종류로 회사 전체를 대표하지 않는다 구체적인 장면 선택과 배치 원칙은 [미디어 방향](02-MEDIA-DIRECTION.md)을 따른다
한화오션 메인의 우측 구간 안내 원리를 가져와 첫 화면·회사 소개·사업 분야·AX Platform·GeoDAP·수환경 연구·소식으로 바로 이동하는 구간 탐색을 둔다. 현재 장면은 스크롤 위치에 따라 표시하고 일반 휠 스크롤은 가로채지 않는다. 760px 이하에서는 탐색이 화면을 덮지 않도록 감춘다
사업 및 기술 영역의 대표 인공지능 장면은 사용자가 선택한 어류 탐지·분할을 유지한다 회사 기술 59의 영상기반 해양생물 탐지와 연구진의 어류 YOLOv8-Seg 학술 1933 및 해양생물 탐지·계측 학술 2009를 근거로 한다 RTD-YOLO 부유 쓰레기 분할 학술 3065는 다른 대상의 별도 상세 사례다 수중 카메라 시점과 어류 자세가 자연스러워야 하고 탐지 박스와 마스크는 같은 개체의 윤곽에 맞춘다 광어가 해저에서 떨어져 옆으로 유영하는 이미지는 불합격이다 생성형 분석 그래픽은 설명용 콘셉트로 원장에 구분하며 실제 계산 결과로 주장하지 않는다 세부 근거는 [원문 기반 기술 장면 콘티](reviews/20260929-source-backed-visual-scenes.md)와 [사업·연구 근거별 이미지 검수](reviews/20260929-content-visual-evidence.md)에 있다
천부지층 탄성파 기술 57은 실제 원본 흑백 단면을 상세 갤러리에 그대로 둔다 도입에는 그 단면을 참조해 만든 측선과 단일 2D 자료 단면의 공간적 콘셉트를 사용한다 영상에서는 조사선 이동과 단면의 순차적 드러남 및 대비 변화를 보여준다 이는 자료처리 기술의 설명 장면이며 실제 처리 결과·수치·3D 지질 해석이라고 주장하지 않는다
회사 소개에는 시료 분석 장면을 사용한다 생태 조사와 항공 측량은 해당 분야의 대표 장면으로 남겨 같은 메인 안에서 이미지를 반복하지 않는다 추가 소개 장면은 새 원본 검수 후 보완한다
인증 목록과 연구 전체 목록 및 원문 자료실을 메인 대형 섹션으로 나열하지 않는다
기술은 인공지능 → 수치모델·예측 → 위성·원격탐사 → 공간정보·측량 → 관측·조사 → 환경분석·생태 → 연안재해·방재 → 데이터·시스템 순서로 소개한다
이 순서는 새 홈페이지의 탐색 구조이며 회사의 공식 조직도나 매출 비중으로 표현하지 않는다
해양·연안뿐 아니라 하구·하천·호소·댐·저수지·항만·해저와 육상 지형·시설물을 실제 업무 근거에 맞춰 포함한다
기술 역량과 적용 분야는 서로 다른 기준으로 탐색하며 기존 4개 사업 분류와 21개 기술의 원문 ID 및 실적 연결을 보존한다
분야별 이미지는 해당 기술의 입력·처리·결과에 맞춘다. 파도 사진은 기술 분야를 대표하지 않고 GeoDAP 뒤의 별도 전환 구간에서만 쓴다. 재해예측과 위성 분야는 각각 맞는 원문이나 콘셉트로 보여준다
연안재해는 해빈과 배후 공간 및 분석 대상의 관계가 드러나야 한다 데이터·시스템은 환경과 자료 및 분석 화면의 관계를 생성 미디어 안에서 구성하고 상세에서는 실제 제품 화면을 보여준다 별도 벡터 개념도나 사후 그래픽을 얹지 않는다
저해상도 해빈 분석과 관측 장비 자료는 회사의 실제 원문 근거로 상세 페이지에 보존하고 메인 대형 이미지로 확대하지 않는다
메인에 저해상도 소개서 그림이나 오래된 사진을 크게 늘려 사용하지 않는다

### 메뉴와 하단

### 내부 페이지

모든 하위 페이지는 한화오션의 도입부·대형 미디어·섹션 전환·내비게이션 위계를 같은 수준으로 적용하되 자료의 성격에 맞게 목록·연혁·갤러리·상세 본문을 구성한다
회사·기술·AX·장비·채용 도입에는 주제에 맞는 대표 미디어를 사용한다 소식·연구 목록은 제목과 검색 및 목록으로 바로 시작한다 문의와 개인정보 페이지도 기능과 본문을 우선한다 영상은 검수된 이미지 슬라이드를 대체할 수 있도록 미디어 영역을 유지한다
사업 및 기술 상세와 연구·사업·학술·소식 기록의 본문·제목·원문 이미지는 geosr.com에서 이관한 원본을 기준으로 제공한다 생성 이미지는 도입부에만 사용하고 원문 이미지와 설명 및 첨부 파일을 덮어쓰지 않는다
세부 기술 페이지의 대표 이미지가 원문 자료와 같으면 대표 이미지 영역에서 한 번만 보여주고 주요 자료 갤러리에서는 중복 항목을 숨긴다 원본 파일과 확대 기능 및 원래 순번은 유지하며 대표 이미지에 원문 자료 표기를 붙인다
영상으로 교체할 자리에는 `영상 대체 예정`만 표시하고 확정 정지 이미지에는 제작 상태 배지를 붙이지 않는다 생성 출처와 설명용 콘셉트 여부는 미디어 원장과 이미지 대체 설명에 기록한다 UI 격자·유동 방향·영역 연결선은 설명용 그래픽이며 실제 관측·모델 계산 결과나 제품 화면처럼 표기하지 않는다
기업 개요와 연혁 및 조직도는 원문과 기록 수를 유지하면서 읽기 좋은 HTML 구조와 시기별 탐색으로 제공한다
인증과 면허는 문서 비율을 유지한 갤러리로 제공한다
연구·사업·학술·공지 등 대량 원문은 검색과 분류 및 페이지 이동이 가능한 게시판으로 제공하고 상세 화면에는 원문 제목·본문·관련 실제 이미지를 우선 배치한다
장비는 실제 보유 장비의 원본 사진과 설명을 사용하며 새 이미지는 페이지 대표 장면으로만 구분한다
AX 소개는 삽입된 곡면 가로 갤러리를 유지하고 실제 제품 화면은 상세 탐색에 배치한다 GeoDAP은 외부 서비스로 연결한다
