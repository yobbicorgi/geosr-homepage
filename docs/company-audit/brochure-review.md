# 회사소개서 내용과 이미지 검토

검토일 2026-09-28

## 검토 범위

국문과 영문 PDF 각각 25개 펼침면을 텍스트 추출과 페이지 렌더로 모두 확인했다
PDF 페이지 번호와 인쇄 면수는 다르다 아래 번호는 PDF 페이지다
원본 PDF와 SHA256 및 이미지 객체의 실제 픽셀 크기는 `brochure-visual-inventory.json`에 기록했다
벡터 도형과 이미지가 섞인 페이지는 이미지 객체 하나를 추출한다고 전체 그림이 보존되지 않는다

국문은 내용의 기준이며 영문은 동일 정보를 제공하도록 보완한다
2025 파일명만으로 모든 수치가 2025 기준이라고 해석하지 않는다 연혁은 2023년 5월에서 끝난다
조직과 최신 연혁 및 사업장은 2026년 현재 원사이트와 대조한 내용을 적용한다

## 국영문 차이와 주의점

- 영문 19페이지의 한국수력원자력 사업 설명이 국문과 달리 어획 영향 연구로 반복돼 있다 새 본문은 국문에 있는 원자력발전소 주변 해역 생물 모니터링·경보 내용을 기준으로 한다
- 영문 16페이지 텍스트 추출에는 편집 메모인 `고해상도 이미지 요청`이 두 번 포함된다 페이지 렌더에서는 메모가 보이지 않았다 숨은 텍스트를 홈페이지 본문으로 이관하지 않는다
- 14페이지의 침수예상도 160개소와 15페이지의 179개소는 범위·시점이 명확하지 않아 메인 실적 수치로 사용하지 않는다
- 영문 9·13·18·20·21페이지는 사진 수와 배치가 국문과 다르다 이미지 순서만으로 언어 대응을 만들지 않는다
- 영문 8페이지의 최상급 홍보 문구와 과거 하드웨어 사양은 새 홈페이지 대표 카피로 채택하지 않는다
- 지도·예측 이미지의 기초자료 제공기관과 기존 범례는 보존한다 회사 자체 관측이나 최신 운영자료로 재표기하지 않는다

## 이미지 최신화 기준

1. 명료한 실제 사진과 충분한 크기의 기술 자료는 원본을 그대로 사용
2. UI·차트·지도는 화면 전체와 범례를 보존하고 확대 보기를 제공
3. 오래된 도식은 내용의 관계를 확인한 뒤 HTML·CSS로 다시 구성
4. 설명용 대표 장면은 동일한 대상·장비·작업을 유지하면서 구도·조명·화질을 개선
5. 생성된 자연 장면에 잘못된 해저 절벽이나 과장된 광선이 생기면 채택하지 않음
6. 생성된 이미지를 실제 사업 사진이나 실측 데이터로 표시하지 않음

현재 제작 후보 중 하구 수치모델 이미지는 수면 아래 인위적인 절벽처럼 보이는 형상 때문에 대표 비주얼에서 제외했다
기술 상세 페이지는 검수한 원사이트 이미지를 우선 연결하고 새 미디어는 개별 검수 후 교체한다
