# 세부 페이지 참고 화면과 적용 점검 · 2026-09-29

## 확인 근거

한화오션 세부 화면의 구간별 관측은 [한화오션 화면 관측](hanwha-layout-scroll-review-20260928.md)과 [실시간 시각 검토](hanwha-live-visual-review-20260929.md)를 근거로 한다. 9월 28일 FHD 스크롤 관측에는 기업안내와 연혁, 해양 사업과 제품 상세, 채용, 뉴스 목록과 상세, R&D 설비가 포함된다. 9월 29일 1264×709 시각 검토와 31개 메뉴 DOM 방문은 별도의 범위다. 이 문서는 그 관측에서 확인된 **배치와 작동 방식**을 GeoSR 세부 페이지에 연결한다. 한화오션의 문구와 사진 및 코드는 사용하지 않는다.

추가 FHD 실사에서 한화오션 연혁 첫 화면은 약 80px 헤더 아래 흰 여백과 좌측 제목, 넓은 실사 배너 순서였다. 아래에는 네 기간 선택과 연도별 사건 문장이 함께 나타났다. GeoSR 연혁은 이 정보 흐름을 참고하되 GeoSR 원문의 네 기간과 67개 사건을 그대로 사용한다.

## 이번 로컬 확인

내부 미리보기 `http://127.0.0.1:18102/`에서 2026-09-29 캡처한 첫 화면은 [`docs/screenshots/20260929/subpage-review`](../../screenshots/20260929/subpage-review)에 있다. 회사·소식·연구·사업·장비·문의·채용·개인정보 8개 경로를 2560×1440, 1280×800, 390×844에서 확인했다. 국문·영문 8개 경로의 QHD와 모바일 32조합에서 `h1` 렌더, 가로 넘침 0px, 페이지 JavaScript 오류 없음, 본문 로딩을 확인했다. `verify_redesign_routes.mjs`의 18개 KO/EN 경로와 201개 참조 파일 요청도 통과했다. 이는 로컬 미리보기 검증이며 공식 도메인의 배포 검증이 아니다.

## 회사·사업 페이지 보강과 화면 확인 경계

9월 29일 후속 수정에서 회사 도입 뒤에 공개 출처로 확인한 설립 시기·연구 환경·사업장 사실을 별도 프로필 구간으로 배치했다. 연혁은 과도하게 큰 단일 연도 대신 기간별 사건 목록의 행 간격을 정리했다. 사업은 기술 분야 선택 메뉴를 데스크톱에서 따라오게 하고 기술 설명의 번호·제목·본문을 분리했으며, 아래 응용 분야는 짙은 배경의 독립 장으로 구분했다. 기술 상세 본문의 최대 폭도 1120px로 제한했다. 이 변경은 `company.html`과 `business.html`에만 `subpage-editorial.css`를 연결해 적용한다. 회사·장비·채용 도입의 이미지 순환은 제작 중인 영상의 최종 대체안으로 확정하지 않는다.

위 스크린샷은 이 후속 CSS·연혁 수정 **이전**의 기준 화면이다. 현재 연결된 브라우저 제어가 없어 수정 후 FHD·QHD·모바일 화면 및 스크롤 상호작용은 아직 실측하지 못했다. `node --check`로 변경 JavaScript 구문을 확인했고 `verify_redesign_routes.mjs`는 국·영문 18개 경로와 202개 로컬 참조의 응답을 확인했다. CSS 배치와 고정 위치의 최종 판단은 브라우저 화면으로 다시 확인해야 한다.

연구·소식 게시판은 긴 제목과 본문을 읽는 화면에 맞춰 큰 페이지 제목의 상한을 낮추고, 상세 본문을 1120px 안으로 제한했다. 장비 사진 원본은 80개 모두 너비 440–476px이므로 목록을 FHD 4열·QHD 5열로 조정해 지나친 확대를 피했다. 상세 끝에는 각 공개 원문으로 가는 링크를 추가했다. 국문 연구 719건·소식 384건·장비 80건의 원문 URL 1,183개가 모두 있음을 자료에서 확인했다. 세 분야는 공개 영문 대응 자료 또는 SHA가 맞는 검토 번역으로 1,183건 모두 영어 화면에서 접근 가능하다. 인증 자료 127건은 제목 영문 검토를 마쳤고 125건은 검토된 미리보기를 제공하며 나머지 두 건은 이미지 검토 상태로 남긴다. 갤러리는 여전히 회사 페이지 안에 있어 별도 경로 분리는 공통 라우터와 탐색 메뉴 변경이 필요하다.
