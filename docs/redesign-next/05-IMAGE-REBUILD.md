# 영상 기반 이미지 정리와 재생성

2026-09-22 · 메인이 직접 생성 및 육안 검수 · 홈페이지 전체 디자인 완료나 영상 완성 판정은 아님

사용자의 최신 요청에 따라 디자인 보드 확정 전에도 잘못된 영상 기반 이미지를 정리하고 필요한 시안을 다시 생성함

## 실제 결과

- 기존 생성 이미지 10개를 `dist/assets`에서 삭제
- ImageGen 9회 실행 중 6개 출력을 작업용 이미지로 채택
- 지구 재도색 1개는 지리 동일성 미확인으로 미채택
- 첫 현미경과 좁은 비율의 무인선은 수정본으로 교체
- 최종 6개는 원본 출력 그대로 저장한 1672×941 PNG이며 정밀한 16:9 납품 파일이나 FHD·QHD 원본이라고 표시하지 않음
- 16:9 영상 내보내기에서 비례 확대 후 1픽셀 미만 수준의 세로 크롭으로 맞출 수 있음 의미 있는 내용 크롭이나 검은 여백 없음
- 기존 회사 사진과 실제 플랫폼 캡처 및 NASA 자료는 보존
- 새 영상 생성 및 유료 크레딧 사용 없음

이미지 파일별 실제 프롬프트와 입력 참조 및 SHA-256과 삭제 이유는 [재생성 원장](IMAGE-REBUILD-REGISTER.json)에 저장
작업용 이미지를 원본 실사진이나 분석 결과라고 주장하지 않음

## 실제 화면 연결

- 홈 관측 분야 → CF05 새 무인선 콘셉트 / 실제 사진이라는 기존 설명 수정
- 홈 환경·생태 및 해당 사업 분야 → CF10 새 실험실 전경
- 회사 소개 포스터 → CF10 새 실험실 전경
- 홈 모델링 영역 → CF12 파랑 계산 개념 이미지 / 실제 계산 결과 아님을 화면에 명시 / 삭제한 허구 지형 재사용 차단
- AX 헤더의 영상 미재생 시 포스터 → 기존 탐지 콘셉트 / 유리 패널 제거
- `expertise-1` 및 `expertise-2` 및 `business-environment`의 이전 영상은 재검수 보류 / 새 포스터를 덮어 재생하지 않음
- 회사 첫 화면의 기존 지구 오프닝과 AX 탐지 초안 및 실제 플랫폼 기능 영상은 이번 이미지 작업에서 교체하지 않음
- [이미지 검토 화면](http://192.168.6.85:18102/media-review.html)에서 6개 이미지를 같은 16:9 틀로 확인

탈락 자료를 사용하던 과거 자동 편집기는 제거했다
새 콘티를 구현하는 별도 편집 파이프라인으로 전환하기 전 실행 금지

## 검수 근거와 한계

회사 장비 원본은 `docs/redesign-production/equipment-sources/manifest.json`과 원본 폴더에 보존
ROV의 통신 테더 맥락은 [제조사 운용 안내](https://bluerobotics.com/learn/bluerov2-operation/)를 확인
멀티빔은 음향 신호의 부채꼴 관측 원리이며 임의의 수면 레이저로 표현하지 않음 [NOAA 설명](https://oceanexplorer.noaa.gov/technology/sonar-multibeam/)
이 자료는 원리를 검토하는 근거이며 생성 이미지의 모든 부품이나 실제 수행 사실을 인증하는 자료가 아님

지구 재생성은 밝기·입체감은 개선됐으나 작은 해안선의 동일성은 입증할 수 없어 미채택
CF01–04와 CF13은 기존 출처 있는 지도·해양 자료를 원본 보존 합성으로 완성 / CF12의 실제 결과 경로도 같은 원칙 적용 / 현재 파랑 시안은 별도의 개념 표현 경로
SST·염분·클로로필은 출처 기간과 관측 센서가 서로 다름 동일 시각·동일 위성에서 동시에 얻은 결과처럼 표시하지 않음

8. 실제 플랫폼별 UI 영상은 별도 촬영 계획으로 진행 / 생성 모델 사용 금지
