# AX 메인 연출 재설계 기준

2026-09-17 사용자 반려 후 메인 재검토

## 반려한 안
- 실제 플랫폼 전체 UI를 브라우저 창처럼 배치하는 안은 메인 대표 이미지로 부적합
- 항만 위에 지형 레이어 3장을 띄우는 생성안도 AI 합성 티가 강하고 플랫폼의 구체적 기능과 대응하지 않음
- 두 번째 안은 배포하지 않았으며 활성 소스에서 제거함
- 새로운 이미지의 채택 여부는 예쁜 바다 풍경이 아니라 아래 기능 대응과 실제 자료 검수로 판단

## 기능 근거
- site/dist/ax-v2.js의 플랫폼 설명과 기존 실제 서비스 캡처를 함께 확인
- Satellite AI 실제 캡처: 완도권 위성영상 위의 해양시설 분류·탐지 폴리곤
- Flood 3D 실제 캡처: 마산만 주변 3차원 지형과 태풍 시나리오에 따른 침수 영역
- Ocean Buoy 실제 캡처: 관측망 지도와 남해111 관측 지점의 수온·풍속 등 시계열
- 픽셀에 보이는 수치와 기간은 과거 캡처 값이며 새 컨셉 이미지에 실시간 값처럼 재사용하지 않음

## 메인 AX: 서로 다른 역할을 연결하는 짧은 3개 장면

| 역할 | 대응 플랫폼 | 무엇을 보여줄지 | 피해야 할 표현 |
|---|---|---|---|
| 탐지 | Satellite AI | 한국 연안의 실제 양식시설 영상에서 시설 윤곽만 선별되는 전후 변화 | 대상과 무관한 바다 네온 선 / 임의 시설 수 / 떠 있는 지도 |
| 예측 | Flood 3D / Storm Surge / Sea Level | 실제 해안 도시 지형 위에서 태풍·해수면 변화에 따라 침수 영역이 바뀌는 과정 | 생성된 지형을 실제 예측 결과로 사용 / 과장된 해일 / 붕괴 장면 |
| 모니터링 | Ocean Buoy / Ocean Environment / Coastal Safety | 실제 부이 관측 / 해양환경 변수 변화 / 해변 현장 감시를 차례로 연결 | 부이가 위성처럼 넓은 수온장을 직접 관측한다는 암시 / 장비 기능 혼동 |

- News Scouter는 자연현상 보도를 지역별로 탐색·분석하는 별도 세부 장면으로 다룸
- Flood XAI는 개발 중이며 완성된 기능이나 성과를 연출하지 않음
- AX와 GeoDAP을 하나의 시스템이나 포함 관계로 보이지 않게 유지
- 모든 플랫폼을 한 장의 상징적 그림에 억지로 합치지 않음

## 표현 및 제작 순서
1. 각 장면의 실제 대상·입력·결과가 대응하는 원자료를 지정
2. 실제 자료를 사용해 지형과 탐지 대상의 윤곽을 고정
3. 생성 모델은 촬영 분위기와 영상 가안에 사용하고 분석 결과 자체를 만들어내게 하지 않음
4. UI 창과 메뉴를 배제한 브랜드 영상 프레임으로 설계
5. 장면별 근거와 시각 검수를 메인이 통과시킨 후 웹에 반영

## 현 상태
- 기존 공개 검토본은 유지 중이며 반려 이미지가 배포된 적은 없음
- 새 시안 제작 전 단계이며 이 문서는 최종 이미지나 완료 선언이 아님
