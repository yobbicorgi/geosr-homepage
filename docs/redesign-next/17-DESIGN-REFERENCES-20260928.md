## 현재 적용 방향

- 메인 제목은 두 언어 모두 `Geo Data Intelligence`로 고정
- 첫 화면은 현실적인 광역 장면과 짧은 회사 설명으로 구성
- 기술 영역은 대표 미디어와 분야 탐색을 같은 높이에서 읽도록 구성
- 단순 구체와 수학적 파형을 만든 Three.js 초안은 채택하지 않음
- 실시간 3D는 사용자 조작이 실제로 필요한 부분에서만 사용
- 직접 구현한 렌더가 부족하면 출처와 사용 조건을 확인한 전문 시각화 또는 검수한 영상으로 대체
- 모델과 관측을 구분하고 외부 시각화를 GeoSR의 계산 결과나 실적으로 표시하지 않음
- AX 곡면형 가로 갤러리는 유지하고 주변 문구와 메뉴 밀도를 개선
- 원문 보존과 자산 출처는 관리 문서에 기록하고 방문자에게는 필요한 설명만 표시

## 전문 시각화 적용

[NASA SVS Perpetual Ocean 2](https://svs.gsfc.nasa.gov/5425/)의 1080p 무음 버전에서 88–112초 구간을 발췌했다
ECCO2 모델의 해양 순환을 보여주는 시각화이며 GeoSR 자체 계산 결과가 아니다
연구 분야 설명을 위한 짧은 발췌를 사용하고 작은 출처 링크를 유지한다
사용 조건은 [SVS 사용 안내](https://svs.gsfc.nasa.gov/help/)와 [NASA 미디어 안내](https://www.nasa.gov/nasa-brand-center/images-and-media/)에서 확인했다
NASA 로고나 보증 표현을 사용하지 않으며 관련 음악도 사용하지 않는다

검토 과정에서 만든 `technical-scene.js`와 전용 Three.js 복사본 및 지구 텍스처는 사용하지 않으므로 제거한다
기존 AX 갤러리의 렌더러는 이 삭제 대상이 아니다
