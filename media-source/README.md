- `editorial/` 생성 이미지 원본과 프롬프트 및 검수 기록
- `editorial/unselected/` 다운로드 폴더에서 회수한 미채택 원본
- `video-production-20260929/` 영상 원본과 생성 기록 및 메인 편집 스크립트
