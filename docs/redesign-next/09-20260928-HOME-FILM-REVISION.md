# 회사 홈페이지 메인 영상 방향 변경 · 2026-09-28

## 사용자 결정

- [올포랜드 메인](https://www.all4land.com/main.do)의 광역 실사 뷰, 여러 장소를 이어 보여주는 리듬과 기업 영상의 분위기를 참고한다. 해당 영상·프레임·랜드마크·그래픽은 복제하거나 재사용하지 않는다.
- GeoSR 영상은 실제 세계처럼 보이는 바다·연안·하구·도시와 현장을 주인공으로 한다. 우주·장비·병·현미경 등의 국소 장면이 메인을 지배하지 않게 한다.
- 올포랜드보다 색, 촬영 동선, 장면 전환과 기술적 표현을 강하게 하되 임의의 네온선·가짜 수치·실측처럼 보이는 허구 지도는 사용하지 않는다.
- 회사 홈페이지 메인과 그 중간의 AX Platform 소개에 집중한다. 사용자가 제공한 GitHub 저장소에서는 AX 관련 화면과 설명만 현재 사이트에 **삽입**한다. 회사 소개와 다른 페이지는 현재 회사 홈페이지 원장을 따른다.
- 신규 영상 제작 도구는 Higgsfield다. 이전 제작 도구의 출력·프롬프트·프로젝트 지시는 폐기한다.
- 사용하지 않는 신규 임시 출력과 명백한 중복 자료는 확인 후 삭제한다. 회사 원본·검수 증거·사용 여부가 불명확한 자료는 보존한다.

## 실제로 확인한 참고 영상

2026-09-28에 위 페이지의 메인 `<video>`를 재생 확인했다. 1920×1080, 약 53초, 무음 반복 영상이다. 확인한 구간에는 도로 위 항공, 저수지·댐의 광역 항공, 강과 도시, 해안 도시 및 사옥 주변으로 이어지는 여러 시점과 얇은 공간정보 그래픽이 있었다. 화면 대부분은 현실 촬영 같은 넓은 풍경이며 그래픽은 풍경을 가리지 않는다. 이것은 **구도와 편집 리듬**의 참고이고 GeoSR의 촬영 자료나 사용 허락을 뜻하지 않는다.

## GeoSR만의 화면 언어

- 화면 비중 목표: 광역 현실 환경 65–75%, 현장 관측과 사람 없는 연구 환경 15–25%, 근접 실험·장비 10% 이하. 한 장면 안에서도 환경의 규모가 먼저 읽혀야 한다.
- 대표 장소: 외해와 섬, 하구와 도시, 항만·연안, 관측 수면, 수중, 연구 장면. 지리 출처가 없는 생성 풍경은 특정 한국 지역이나 실제 사업지로 설명하지 않는다.
- 촬영감: 높은 드론 시점의 전진·선회, 낮은 해수면을 따라가는 트래킹, 수면 위아래 매치 컷. 매 컷에 하나의 명확한 카메라 동작만 둔다.
- 색: 깊은 남색·해양 청색과 실제 노을의 따뜻한 하이라이트. 채도와 명암은 충분히 강하게 하되 플라스틱처럼 번지는 색과 상시 네온 효과는 제외한다.
- 기술: 검증된 자료가 있는 위치에만 정합된 관측점·측선·점군·모델 격자를 후반 합성한다. 생성 영상 자체에는 수치, 지도, 텍스트, UI를 굽지 않는다. 자료가 없으면 그래픽 없이도 성립하는 장면으로 둔다.
- 홈페이지 첫 화면의 `Geo Data Intelligence`는 HTML 텍스트로 유지한다. 왼쪽 읽기 영역과 밝기 대비를 확보한다.
- 최종 60초는 첫 프레임과 끝 프레임의 환경·빛·운동 방향을 맞춰 반복된다. 빠른 몽타주라도 정지하거나 늘여서 길이를 채우지 않는다.

## Higgsfield 제작 설정과 실행 상태

- 2026-09-28 Higgsfield 개인 워크스페이스는 **free 요금제·10 크레딧**으로 확인했다. `seedance_2_0_mini` 5초·720p·16:9 무음은 5크레딧, `kling3_0_turbo`는 7.5크레딧, `seedance_2_5`는 35크레딧으로 견적됐다. 견적은 구매나 생성 완료를 뜻하지 않는다.
- CF01 5초 초안 생성 요청은 **Requires basic plan or higher** 응답으로 거절됐다. 작업 ID와 영상 파일이 생성되지 않았으며 비용 차감도 확인되지 않았다. 요금제 변경이나 구매는 하지 않는다.
- 프롬프트는 `PROMPT-CARDS.md`와 [Higgsfield 제작 카드](10-HIGGSFIELD-PRODUCTION.md)에서 새 광역 컷부터 확인한다. 실제 전송 문장은 컷별 검수 기록에 전문을 남긴다.

## 채택과 삭제 기준

후보마다 시작·중간·끝 프레임과 전체 재생을 확인한다. 풍경의 지형, 파도, 선박, 그림자, 이동 방향의 변형을 확인하고 홈페이지 제목이 읽히는지 본다. 근거 없는 실측 그래픽과 지리 오류가 있으면 공개 슬롯에 연결하지 않는다. 불합격 새 출력과 제작 중 임시 파일은 판정·파일명·이유만 남긴 뒤 삭제한다. 회사 원본과 검증된 실제 플랫폼 캡처는 유지한다.

## 웹 적용 경계

현재 홈페이지 중간의 AX Platform 소개는 유지한다. 본편 영상에는 AX UI나 AX 전용 콘셉트를 넣지 않는다. 새 컷이 검수되기 전 `dist/film-manifest.json`을 완료 상태로 바꾸지 않는다. 내부 미리보기와 공식 배포를 구분한다.
