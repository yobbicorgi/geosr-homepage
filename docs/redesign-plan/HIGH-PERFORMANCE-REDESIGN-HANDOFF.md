## 현재 코드

- 홈 전문 분야는 전폭 미디어 위에 문구와 분야 탐색을 겹침
- 연구·사업·학술 사례는 입체 스택에서 선택하며 원문 기반 상세 링크 유지
- AX는 세 분류·아홉 서비스 탐색과16:9 실제 시연 및 원본 확대
- 홈 플랫폼은 남색 선택 무대 / AX·GeoDAP마다 기능 요약3개 / GeoDAP 전체 캡처와 독립 외부 링크 보존
- 회사 전문 분야는6분야 탐색과 대표 장면 및 수행 정보를 동시 표시
- 모바일은 한 분야·한 플랫폼씩 선택 / 연혁·자격·세부 정보 펼침 / 문서4건부터 더 보기
- 홈 문서 갤러리는 앞면 원근 이동 / 회사 페이지는 검색 컬렉션 한 곳
- 한영50개 렌더 조건과 모바일 메뉴·탭·확대·실패 복구를 검수

이전 문서의 디자인 보드3개 미구현 지시는 현재 상태에 맞지 않음
보드의 주요 구성은 실제 페이지에 반영되었으므로 새 비교 페이지를 복제하지 않음
사용자의 최종 디자인 승인이나 외부 심사를 통과했다고 판정하지 않음
