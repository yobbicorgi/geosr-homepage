# GeoSR 회사·사업·기술 조사

조사일 2026-09-28 · 새 홈페이지의 분류와 카피 및 미디어 제작 근거

## 먼저 확인할 결론

GeoSR는 해양 풍경이나 무인선 하나로 설명할 수 있는 회사가 아니다
원문은 **지구환경 엔지니어링과 종합 수환경 연구**를 설명한다
대상은 해양과 연안뿐 아니라 하구·하천·호소·댐 및 저수지·항만·해저·육상 지형과 시설물까지 이어진다
조사와 계측에서 실험 분석·수치모델·인공지능·공간정보 및 시스템 개발과 운영까지 수행한다

사용자가 중요도를 명확히 지정한 **인공지능은 독립적인 첫 기술 분야**로 다룬다
이는 단순 유행어 추가가 아니다 인공지능 활용기술과 영상기반 생물 탐지 원문 및 연구·논문과 2026년 AI&예측 조직이 근거다

## 2 원사이트와 소개서의 분류는 다르다

### 웹사이트의 4개 사업 분류

1. 수환경 보전 — 하구·하천 과정 / 수환경 통합모델링 / 해양공간계획 / 해역이용협의 및 해역이용영향평가 / 해양생태계 보전 및 모니터링
2. 수환경 건강성 회복 — 해양쓰레기 및 미세플라스틱 / 살아 숨 쉬는 연안 / 생태계·적조·비브리오균·대장균 모델링
3. 재해예방 — 연안침식 모니터링 / 연안재해 감시 및 취약성 평가 / 재해·재난 예측
4. 스마트 기술 — 인공위성 영상 / 탄성파 자료처리 / CCTV 영상 / 해양생물 탐지 / 빅데이터 / 인공지능 / 해상풍력 정보도 / 무인선 / 무인항공 측량 / 실시간 해양예측

### 2025년 소개서의 4개 사업 분류

1. 수환경 보전과 회복
2. 기후변화와 연안재해
3. 스마트 기술
4. 재생에너지와 탄소중립

소개서는 웹사이트보다 관측시스템 설계·제작·설치·운영과 항로표지·수중공사·디지털트윈·탄소흡수력 평가를 명확히 설명한다
따라서 웹 메뉴 21개 제목만 재배열하면 회사 업무가 누락된다
소개서 PDF 3쪽의 업무도에는 23개 활동이 표시돼 있다

한국어 주요 메뉴 19개와 푸터 개인정보 페이지 및 기술 상세 21개를 직접 방문했다

## 6 발견한 콘텐츠 차이와 주의사항

- 원사이트 영문 연구는 62건으로 국문 82건보다 20건 적다
- 원사이트 영문 측량장비는 42건으로 국문 44건보다 2건 적다
- 항목별로 보면 국문에만 있는 최신 장비는 3건이고 영문에만 있는 과거 장비가 1건이므로 숫자 차이만으로 대응을 추정하지 않는다
- 영문 공지 목록은 비어 있고 영문 개인정보 페이지도 한국어다
- 원문 게시일과 사업 수행연도 및 논문 발행연도를 구분해야 한다
- 과거 기사와 경조 자료가 2022년에 일괄 등록된 사례가 많다 게시일을 실적 연도로 사용하지 않는다
- 학술 제목이 원사이트 제목 필드에서 잘린 사례가 있다 본문의 논문 필드가 온전하면 표시 제목으로 활용하고 둘 다 잘렸다면 추정 복원하지 않는다
- 현재 연락처 페이지는 군포·부산·포항을 안내한다 과거 삼척 사무소 기사만으로 현재 사업장을 추가하지 않는다
- 2004년 기사 속 인원·매출·국내유일 표현을 현재 수치나 지위로 재사용하지 않는다
- 공개 인증 목록은 유효기간 검증과 별개다 원문 스캔 중 보호 대상은 현재 보호 정책을 유지한다
- 소개서 안에서도 침수예상도 대상 개소 수가 160과 179로 달라 검증 없이 대표 수치로 사용하지 않는다
- 홈페이지 공개 내용에는 개별 논문의 원문 전체가 없는 경우가 있다 게시된 서지정보 검토를 논문 전문 검토라고 표현하지 않는다

## 7 한영 콘텐츠 기준

국문을 기준으로 항목과 내용을 동일하게 제공한다
영문에 누락된 항목은 국문 제목과 본문을 전체 번역하고 원문 이미지와 첨부파일을 같은 항목에 연결한다
기존 영문과의 연결은 게시글별로 확인하며 두 언어의 게시글 ID가 서로 다르다는 점을 반영한다
동일 제목의 연차 과제와 중복 등록을 번역 과정에서 임의로 합치지 않는다
원문 자료는 수정하지 않고 번역과 원문 간 대응 및 번역 검토 상태를 별도 데이터로 기록한다
이미지 속 문서 원본과 논문의 공식 제목 및 고유명사는 임의로 번역하거나 재작성하지 않는다

## 남은 작업

본문 이미지와 첨부파일의 로컬 이관 결과는 별도 미디어 감사 원장에 기록한다
목록 대조 성공을 영문 번역이나 새 홈페이지의 디자인 완성으로 보고하지 않는다
이 조사 근거에 맞춰 새 분류·이미지·카피를 수정하고 시각 검수를 다시 진행한다
