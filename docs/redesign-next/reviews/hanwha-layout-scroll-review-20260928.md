# 한화오션 화면 관측과 GeoSR 반영

실제 브라우저 관측 2026-09-28

## 관측 범위

- 기업안내 /whoweare/au/ FHD 1920×1080 처음부터 하단까지 스크롤
- 연혁 /whoweare/history/ FHD 처음부터 1973년과 하단까지 스크롤
- 메인 드롭다운 QHD 2560×1440 마우스 진입 후 확대 관측
- 모바일 390×844 전체 메뉴와 회사 메뉴 아코디언 관측
- 해양 사업 /whatwedo/pf/ FHD 상단부터 하단까지 스크롤
- 시추 설비 /whatwedo/drd/ 분류 탭과 Drillship 상세 모달 관측
- 채용 안내 /careers/ri/ FHD 상단부터 하단까지 스크롤
- 소식 /media/news/ 및 첫 보도자료 상세 FHD 상단부터 하단까지 스크롤
- R&D 설비 /whatweinnovate/rd/ FHD 10201px 전체 페이지 스크롤
- 앞선 31개 URL DOM 방문 기록은 전체 시각 검수 완료를 의미하지 않음

## 확인한 구성

기업안내는 84px 400 제목으로 시작하며 작은 미디어가 스크롤에 따라 전폭으로 확대된다
소개 본문은 우측 약 42% 영역에 20px 300 줄높이 30.4px로 배치한다
큰 현장 사진과 기업 정보 표 및 세 가지 가치 영역을 지나 확장형 검은 푸터로 끝난다

연혁은 넓어지는 사진 뒤에 네 시대 선택 메뉴를 고정한다
중앙 연도와 사진이 확대되고 연도별 기록이 중앙의 가는 선 양옆으로 나타난다
문서 전체 높이는 FHD에서 약 21379px로 매우 길다
GeoSR은 67개 기록을 유지하되 기간과 연도 탭으로 좁혀 읽도록 구성한다

QHD 데스크톱 메뉴는 상단 항목에 마우스를 올리면 전체 하위 열이 동시에 펼쳐진다
밝은 반투명 배경과 흐림 처리 위에 검은 글자가 표시된다
주 메뉴 글자는 관측 시 18px 400이며 하위 메뉴는 16px 400이다
주 메뉴 중심선 아래에 하위 항목이 정렬되고 활성 항목 아래에 가는 선이 생긴다

모바일 메뉴는 짙은 배경의 세로 전체 화면이다
분류별 얇은 구분선과 우측 접기 화살표가 있으며 회사 메뉴를 누르면 세부 항목이 들여쓰기 형태로 나타난다

## GeoSR 구현

- 자체 콘텐츠의 6개 주 메뉴에 전체 열 드롭다운 적용
- 회사 소개 9개 항목과 사업 분야 9개 항목을 고려해 높이 자동 측정
- 반투명 밝은 면과 GeoSR 파랑의 선택 표시 사용
- 모바일은 짙은 남색 단일 열 아코디언
- 키보드 Tab과 ArrowDown 및 Escape 지원
- 전체 메뉴의 포커스 순환과 배경 inert 및 닫기 후 포커스 복원
- 회사 소개의 이미지 3장 전환과 스크롤 확대
- 국문 기준 연혁 67건과 현재 사명 비전의 영문 보완

로고 원본 코드 사진 영상 문구는 참고 사이트에서 가져오지 않음
전체 페이지의 반응형 시각 검수는 진행 중

## 추가 관측과 적용 판단

### 사업 상세

해양 사업은 왼쪽 84px 제목과 오른쪽 짧은 설명 및 타원형 버튼으로 시작한다
이미지는 약 80% 폭에서 전폭으로 넓어지며 같은 위치의 제목이 흰색으로 바뀐다
사진 하단의 분류 탭 뒤에 3열 사진 목록을 배치한다
사진과 제목 사이에 테두리 상자와 배경 장식을 추가하지 않는다
시추 설비의 Drillship 모달은 FHD에서 약 1104px 폭이다
상단 16:9 사진 아래 흰색 설명 영역을 두고 닫기는 모달 바깥 우측 상단이다

GeoSR은 기술 개요와 원문 상세의 분량 차이를 유지한다
대표 장면의 확대와 분류 선택을 연결하고 모든 세부 내용을 거대한 슬라이드에 넣지 않는다

### 채용

채용 안내는 확대 이미지 다음에 왼쪽 안내 제목과 오른쪽 약 42% 폭의 단계 목록이 이어진다
숫자와 가는 세로선이 전형 순서를 표시하며 마지막 단계에만 강조색을 쓴다
신입과 경력 사이에는 큰 현장 사진을 넣는다
FHD 전체 높이는 약 6863px다
GeoSR 채용은 실제 수집한 모집 분야와 근무 조건 및 지원 안내를 분명하게 제공한다
현재 모집 상태를 검증하지 않은 채 채용 중이라고 표시하지 않는다

### 소식 및 글 상세

목록은 사진 3열 2행과 사진 아래 분류 및 날짜와 제목으로 구성된다
검색은 목록 위 오른쪽이며 한 줄 테두리와 검색 아이콘을 사용한다
하단에 페이지 번호와 이전 다음 이동이 있고 검은 푸터로 이어진다
상세 제목은 60px 400 줄높이 79.2px이며 본문 폭은 FHD 1104px이다
사진과 문단은 같은 폭을 사용하고 첨부자료는 밝은 회색 박스로 묶는다
목록 버튼과 이전 다음 글은 본문 끝에 배치한다
GeoSR의 수백 건 기록은 검색 가능한 게시판을 유지하며 긴 글의 읽기 폭과 첨부 구분에 적용한다

### R&D 설비

확대되는 도입 사진 뒤에 시설 전체 항공사진과 번호별 위치 표시를 보여준다
지도 위에 흰색 목록 패널을 겹치고 각 시설 안내로 연결한다
왼쪽 큰 제목과 오른쪽 사양 및 소개 본문을 조합한다
대표 세로 사진 하나와 작은 사진 여러 개가 가로 방향으로 이동하는 비대칭 갤러리를 사용한다
두 번째 사업장은 같은 구성으로 이어진다
GeoSR은 보유 장비 원본과 장비 설명을 유지하며 실제 자료가 충분한 범위에 이 방식을 적용한다
자료가 없는 시설 배치도나 장비 배치를 만들어 실제 시설처럼 표시하지 않는다

## 구현 검수 추가 기록

- 공통 푸터를 남색 배경과 회사 정보 및 6개 분류별 하위 메뉴로 재구성
- 모바일 하단 메뉴는 한 분류씩 펼치는 아코디언으로 구성
- QHD 영문 드롭다운 모든 하위 열의 표시와 가로 넘침 없음 확인
- UHD 3840×2160 헤더 로고와 주 메뉴 및 언어 문의 메뉴 버튼의 좌표가 화면 안에 있음을 확인
- 390×844 영문 푸터 아코디언 표시와 aria-expanded 및 aria-hidden 동기화 확인
- 390×844 채용 화면 제목이 헤더 아래에 배치되며 가로 넘침 없음 확인

전체 메뉴별 모바일 화면과 모든 내부 기능 검수는 아직 진행 중이다
