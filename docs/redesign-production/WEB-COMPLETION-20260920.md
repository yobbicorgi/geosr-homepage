## 모션과 접근성

- 탭 전환에 짧은 페이드와 위치 이동을 적용했다
- 문서 카드는 앞면을 유지한 작은 Y축 회전과 수평 스크롤로 표현한다
- 페이지 스크롤을 강제로 가로 스크롤로 바꾸지 않는다
- 카드 진입 모션은 기본 콘텐츠를 숨기는 전제 없이 점진적으로 적용한다
- 키보드 탭 이동과 메뉴 Escape 닫기 및 문서 대화상자의 포커스 복귀를 확인했다
- prefers-reduced-motion에서는 문서 회전과 전환이 제거된다
- 이미지·영상 실패 시 기존 포스터 또는 준비 영역이 남는다

## 미디어와 사실성

- 영상 생성·녹화·편집·유료 크레딧 사용 없음
- 기존 검토된 지구 이미지와 실험실 콘셉트 이미지를 유지했다
- 실험실 이미지는 실제 시설이나 분석 결과로 표시하지 않는다
- 무인선은 GeoSR 원본 사진을 사용하며 조사 기술 중 하나의 사례로 설명한다
- 해양환경 플랫폼의 검은 좌우 여백이 있던 캡처는 실제 FHD 화면 2장으로 교체했다
- 수온 화면과 8일 합성 염분 화면의 출처·기준일은 PLATFORM-CAPTURE-20260920.md에 기록했다
- 클로로필은 기능 설명을 유지했으나 이번 캡처 품질이 적합하지 않아 추가 화면으로 사용하지 않았다
- 개인정보 검토가 필요한 면허 이미지 2개는 갤러리·전체 목록·상세에서 이미지 자체를 공개하지 않는다
