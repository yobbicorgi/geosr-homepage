국문과 영문은 별도 축소 목록이 아니라 같은 항목을 공유하며 기존 홈페이지의 영문 병기 표현을 우선 사용하는 규칙은 `research-docs/33_한영_공통콘텐츠_및_공식용어_원칙_20260916.md`에 기록

## 로컬 실행

이 폴더에서 Node.js로 실행

```powershell
node preview-server.cjs
```

기본 포트 18101, 바인드 0.0.0.0

게시판과 자료실은 로컬 JSON을 읽으므로 index.html 파일 직접 열기보다 HTTP 프리뷰 사용 권장

프리뷰는 공개 웹 배포가 아니며 다른 컴퓨터에서는 같은 내부망 접근과 방화벽 조건이 필요

연구 문서·원본 캡처는 프리뷰 서버에서 차단되며 디렉터리 목록과 파일 쓰기 기능 없음

## 현재 구현 참고

메인은 기존 영상 → 6분야 기술 → 최신 공개 기록 10건 → 인증·지식재산권 원본 이미지 → AX·GeoDAP 소개의 콘텐츠 흐름을 가진 PC 검토본이다. 전체 1,105건은 자료실과 통합 검색에서 확인한다.
인증·특허 이미지는 원본 출처를 유지하고, 새 영상·ImageGen·Higgsfield 생성은 실행하지 않았다. 기존 생성·재제작 시안은 미승인 참고 자산이다. 이 현재 표현과 순서는 사용자 승인 전 구현 참고일 뿐이며, 색·폰트·레이아웃·모션 방식은 다른 제작 환경에서 변경할 수 있다.
AX와 다른 서브페이지의 최종 시각 일관성·콘텐츠 감수는 남아 있다.

자료는 이 폴더 내부 JSON과 이미지·첨부로 제공, 원 사이트 URL은 원문 출처 메타데이터에만 유지

GeoDAP과 DOI·출판사·언론 원문은 의도한 외부 연결, 이메일·전화도 유지

기존 메인 영상은 보존, AX 영상은 자리만 마련, 업스케일·신규 영상·Higgsfield 생성 없음. 기존 생성·재제작 시안은 미승인 참고 자산
