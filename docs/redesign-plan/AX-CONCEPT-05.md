# 메인 AX 이미지 수정 / 2026-09-17

- 사용자 지시: 메인 AX Platform에 실제 플랫폼 캡처를 쓰지 않고 컨셉 이미지 사용
- 사이트 창 프레임과 위성/Flood3D 캡처 중첩을 제거
- GPT ImageGen으로 만든 연안 관측·분석·예측 레이어 컨셉 적용
- 파일: site/dist/assets/ax-concept-v5.png
- 이미지 제작 지시: 한국 연안·항만·하천의 사실적 항공 장면 위에 동일한 연안 형상의 영상·분류·예측 레이어 3개를 분리해 표현
- 네온과 네트워크 선 및 가짜 UI는 제외하고 자연색·회색·제한된 황금색 사용
- 메인 검수: 항만 출입구가 열려 있음 / 제방 및 해안선 연결 / 하천과 해역 연결 / 과도한 네온 없음 / 플랫폼 캡처 없음
- 한계: 실제 지명이나 측량 자료가 없는 가안으로 지리적 정확성과 수리·예측 결과를 검증한 이미지가 아님
- 레이어 간 정밀한 좌표 일치는 최종 영상 제작 시 실제 공간정보를 이용해 고정해야 함
- 미래 영상: 연안 관측 장면 → 영상 레이어 → 분류·분석 레이어 → 예측 레이어 순서로 전개
- 플랫폼의 실제 UI와 기능 영상은 상세 소개에서 유지
- GeoDAP은 독립 플랫폼으로 기존 소개와 접속 구조 유지

## 사용자 반려 — 사용 금지
- AI 합성 티가 강하고 실제 플랫폼의 기능과 연계가 약하다는 사용자 피드백
- 이 이미지는 배포하지 않았으며 활성 시안에서도 제외
- 기존 검토본으로 복구하고 기능 근거부터 다시 설계
- 떠 있는 지형 레이어를 AX 전체의 상징으로 재사용하지 말 것
