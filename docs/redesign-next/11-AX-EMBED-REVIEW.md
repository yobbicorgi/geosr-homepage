제공 저장소: [123choigem-tech/geosr-homepage-ax-platforms](https://github.com/123choigem-tech/geosr-homepage-ax-platforms), 확인한 HEAD `253362894f38c38497750dc688fb679e2d83534d`. 제공 저장소의 AX 섹션은 `index.html`의 `#platforms`이며, 화면 구성은 `portal/flutter-20260921/gallery.js`, `style.css`, `curve.svg`에 있다.

처음 작업에서는 플랫폼 캡처와 분류만 참고하고 별도의 짙은 색 대문과 화면·설명 분할 패널을 만들었다. 이는 사용자가 요청한 AX 부분의 교체 삽입이 아니었다. 직원 결과물의 강점은 아래와 같다.

- 흰색 편집형 화면에서 큰 제목, 짧은 설명, 분류와 번호 목록을 한 번에 읽을 수 있다.
- 여러 플랫폼을 작은 카드로 나열하기보다 곡선형 큰 화면 하나에 시선을 집중시키고 양옆 화면을 살짝 보여 다음 탐색을 유도한다.
- 목록·카드 전환, 분야별 필터, 번호 목록, 화살표·방향키·드래그를 같은 데이터에 연결해 탐색 경로가 많다.
- 전체 대문 역시 실제 세계 규모의 영상 장면과 절제된 본문, 하단 장면 선택으로 구성이 명확하다. 회사 메인 개선에는 이 화면 규모와 리듬을 참고하되, 해당 저장소의 회사 본문은 가져오지 않는다.

`dist/ax-platform.html`과 별칭 `dist/platforms.html`은 직원 갤러리를 GeoSR의 기존 헤더·푸터 사이에 삽입한다. 기존 AX 탐색기 스크립트·스타일과 미사용 AX 스타일은 두 페이지의 로드 목록에서 제거했다. 홈페이지 메인 중간의 AX 소개는 실제 위성 시설물 탐지 화면을 보여 주며 이 로컬 AX 소개 페이지로 이동한다. GeoDAP은 독립 서비스로 유지한다.

제공 저장소에 섞인 회사 소개·연구·조직·채용·문의와 임시 외부 플랫폼 주소는 삽입하지 않았다. 화면 8장은 정적 캡처이며 실시간 데이터나 현재 서비스 운영 상태를 뜻하지 않는다. Flood XAI는 실제 화면이 없어 개발 중으로 표시한다. 원본의 `LIVE PLATFORM` 문구는 이 근거 범위에 맞춰 `플랫폼 화면`으로 바꿨다.
