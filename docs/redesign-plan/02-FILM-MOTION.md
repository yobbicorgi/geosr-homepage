# 영상·모션 설계 — 풍경에서 기술로

메인 설계 · 2026-09-17 · **스토리보드만 작성, 영상 제작하지 않음**

## 1. 현재 영상의 진단과 계승

현재 프리뷰의 `assets/journey-autoplay-20260915/journey-1696.mp4`는 원본50초, 1696×954다. 현재 설정의2배속에서는 약25초로 보인다. 조사에서0/10/20/30/40/45/49초 프레임을 확인했다. 위성·태풍→파도→부이/선박→수중→해저→선형 그래픽의 흐름이다. 전체 프레임을 전수 검수한 것은 아니다.

살릴 것: 높은 시점에서 수면과 해저까지 내려가는 카메라의 연속성, 해양기업의 분위기, 밝고 어두운 깊이 변화. 바꿀 것: 기술을 뜻하는 선이 뒤쪽에 등장하지만 무엇을 측정·계산하는지 알기 어렵다. 이를 의미 없는 HUD나 임의 숫자를 더하는 방식으로 해결하지 않는다.

**새 장면의 규칙: 무엇을 관측하는가 → 어떤 자료가 되는가 → 무엇을 판단하게 하는가.** 과학 데이터를 아름답게 보여주되, 실제 출력·설명용 개념 그래픽·생성 장면을 혼동하지 않는다.

## 6. 움직임의 작동 방식

### 첫 화면

**데스크톱·모바일 모두 첫 화면100svh 전체에서 무음·인라인·반복 자동재생을 시작하는 것이 기본 동작이다.** 첫 프레임이 나타나기 전 공백을 없애기 위해 동일 구도의 포스터를 즉시 보이고 영상 준비 즉시 전환한다. 클릭해야 시작되는 구성을 기본으로 삼지 않는다. 플랫폼의 자동재생 제한·저속연결·데이터절약·모션감소 때만 포스터와 명시적 재생 버튼으로 대체한다. 재생/정지 버튼은 항상 보이고 배경이 화면에서 절반 이상 벗어나면 멈춘다. 다시 들어오면 사용자가 수동 정지했는지 기억한다. 스크롤이 영상 시간을 임의로 바꾸지 않는다.

### ‘관측에서 판단까지’ 네 단계

데스크톱1440×900 기준 섹션 높이1,440px, 미디어 높이560px, 고정 시작점 헤더 아래112px. 단계는4개이며 아래의 자연스러운 페이지 스크롤로 전환된다. 섹션의 유효 스크롤 거리(섹션높이−미디어높이)를0~1로 정규화해 0/.33/.66/1의 기준점에서 단계1/2/3/4로 전환한다. 끝에서 고정을 해제한다. 창크기가 바뀌면 이 관계를 다시 계산한다.

| 상태 | 큰 화면 | 함께 읽히는 설명 | 전환 |
|---|---|---|---|
|1 관측|실사 또는 관측위치|무엇을 얻는가|처음 보일 때250ms 등장 |
|2 구성|점군·지형·입력자료|무엇을 계산에 쓰는가|기존 layer는 남기고 새 layer를400ms reveal |
|3 계산|모델 결과|어떤 변화를 해석하는가|동일 자료이면 공간정합, 아니면 명확한 컷 |
|4 판단|예측/적용 결과|어떤 결정에 도움이 되는가|결과와 관련 기술 버튼을 안정된 화면으로 유지 |

스크롤을 반대로 하면 이전 단계로 돌아간다. 단계 버튼 클릭·키보드 선택도 가능하고, 선택 직후 스크롤 관찰자가 되돌리지 않게 그 단계 위치로 이동한다. reduced-motion에서는 이동 애니메이션 없이4장을 순서대로 펼친다. 모바일/태블릿에서는 고정·스크럽을 해제하고 미디어+설명4개를 자연스럽게 쌓는다. 캔버스가 손가락 스크롤을 가로채지 않는다.

### 비교·목록·메뉴

- 실제 비교 가능한 이미지가 있을 때만 드래그 비교를 쓴다. 원본/결과 버튼과 키보드 방향키를 함께 제공한다. 목업에서는 ‘비교 이미지 목업’ 표시.
- 업무목록 선택: 사진200ms 교체, 텍스트는 즉시 변경. 자동 캐러셀 없음.
- 메뉴220ms, 바텀시트240ms, 이미지 진입400ms. 상태전환의 의미가 없으면 효과를 넣지 않는다.
- hover 확대는1.02 정도의 작은 UI효과. 이 제한은 영상 자체의 카메라 이동·다이브·공간변환에 적용하지 않는다.
- 부드러운 스크롤 강제, 길게 붙잡는 가로스크롤, 끊임없는 숫자카운터는 쓰지 않는다.

## 7. Higgsfield 제작 준비

결제 전에는 스토리보드·원본 후보·포스터 구도만 확정한다. 결제 후에는 **한 장면 시험 → 내용·형태 검수 → 나머지 제작** 순서로 진행해 한 번에 여러 영상에 비용을 쓰지 않는다.

- 실제 기술 결과: 지도·수치·그래프·탐지 결과는 원자료/정밀 그래픽으로 유지한다.
- 창작 가능한 영역: 실사 분위기 연결, 카메라 이동, 추상적인 공간·입자 전환, 빛·질감. 설명용 개념 장면은 ‘기술 개념’으로 구분한다.
- 실제 장비·특정 해역·회사 실적처럼 보이는 생성물은 사실을 확인한 원본과 혼동하지 않게 한다.
- 프로젝트마다 입력원본, 생성프롬프트, 사용모델, 비용, 장면버전, 사용여부를 기록한다. 비용은 실행 전 도구의 실제 견적을 사용하며 이 문서에서 추정하지 않는다.
- 영상 안에 한영 문구를 굽지 않는 것을 기본으로 한다. 웹 UI와 자막으로 언어를 분리해 영상 중복 생성을 줄인다.

## 8. 제작 전 필요한 것 / 지금 없어도 되는 것

실제 새 영상 제작에는 대표 관측·모델·AI 원본과 자료 관계 확인이 필요하다. **화면 목업에는 필요하지 않다.** 빈 미디어와 단계 도형으로 레이아웃·전환·조작을 먼저 완성한다. 새 영상 구매·촬영·유료 생성·전체9클립 제작을 목업 완료 조건으로 삼지 않는다.
