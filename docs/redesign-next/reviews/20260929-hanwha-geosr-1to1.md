## 실측 관찰

- 한화오션 메인은 QHD에서 `#KV` 1440px, `#WHOWEARE` 3600px, `#WHATWEDO` 1014px, `#SHIPCAROUSEL` 2258px, `#SHOWROOM` 1381px, `#INNOVATE` 3532px, `#BUSINESS` 2160px, `#STORY` 4038px, `#MEDIA` 856px이었다. 긴 높이는 **연속된 영상/전환을 고정해 보여주는 시간**에 사용된다.
- `Who we are`: 흰 화면의 짧은 제목과 16:9 영상 프레임에서 시작해 스크롤 시 실사 선박 영상이 전체 화면으로 확장된다. 선박의 물리적 이동이 계속 보여 정지 이미지 확대와 다르다.
- `Business`: 다섯 개의 세로 실사 띠가 QHD 가로 화면에 동시에 보이고 각 장면에 짧은 명칭이 있다. GeoSR에서는 물·자연 풍경만 반복하지 않고 AI 분석 화면, 수치모델 격자, 위성 관측, 현장 장비, 분석 실험으로 나눈다.
- `Story`: 실제 파도 포말 영상이 전체 화면을 채우며 오른쪽 아래에 큰 문구를 둔다. GeoSR의 영상 브리지에도 피사체 자체의 움직임이 필요하다.
- 한화오션 연혁의 FHD 화면은 상단의 단순한 `연혁` 제목 → 넓은 단일 실사 이미지 → `NOW–2020` 등 연대 앵커 → 연도별 사건 목록 순서다. 시각 강조와 기록 읽기 영역을 분리한다.
- GeoSR 메인의 FHD 화면은 `top` 1080px, `about` 약 998px, `expertise` 약 2592px, `platforms` 약 1760px, `water-research` 약 734px, `news` 약 318px. 현재 `expertise`의 긴 스크롤은 여러 분야를 한눈에 보여주지 못한다.

## 미디어 제작·배치 원칙

1. **영상 자리에는 영상**을 완성해 넣는다. 생성 전후 검수용 이미지는 최종 슬라이드 대안으로 취급하지 않는다.
2. 순서: 메인 첫 영상 → 메인 하단 영상 → 각 세부 페이지 영상. 이미 검수된 장면부터 제작/삽입한다.
3. 메인 영상은 실물과 카메라가 움직이는 연속 사건으로 만든다. 조사선·CTD/ADCP, 위성의 연안 관측, AI 탐지/분할, 수치모델의 공간·시간 변화, 하천·호소·연안의 환경을 균형 있게 배치한다. 특정 장비만 회사 전체를 대표시키지 않는다.
4. **이미지 자리**는 한 장의 고해상도 이미지로 확정한다. 현장 구조물·지형·장비·객체 크기·작업자 보호구·광원·시점·데이터 표현을 각각 검수한다. 동일 이미지를 다른 기술 영역에 반복하지 않는다.
5. 영상 위에 별도의 가짜 탐지 박스나 데이터 UI를 즉석에서 얹지 않는다. 탐지·분할·모델링 표현은 원본 장면의 콘티와 영상 생성 단계에서 정확히 구현한다.
6. 원본 회사 기술·사업·연구 상세 자료는 그대로 접근 가능하게 두고, 메인·서브의 대표 장면은 새 미디어로 연출한다.

## 2026-09-29 화면 수정·검증 기록

- 메인의 8개 가로 탭과 240svh 고정 구간을 제거하고 5개 대표 분야를 한 화면에 보이는 세로 비주얼 판으로 교체했다. 데스크톱에서 각 분야는 hover·키보드 포커스로 넓어지고, 모바일에서는 기본 가로 스와이프로 이동한다. 전체 8개 분류는 사업 상세에 남아 있다. FHD 1920×1080에서 분야 구간은 약 2592px에서 약 948px로 줄었다.
- 사용하지 않는 `data-capability-showcase` 자바스크립트·스타일을 제거했다. 휠 스크롤은 해당 구간에서 일반 세로 스크롤로 동작한다.
- 회사 연혁의 낡은 750px 작업선 사진과 설명 딱지를 제거하고 1672px 이미지 한 장을 본문 폭에 맞게 배치했다. QHD 2560×1440 및 모바일 390×844에서 기록 목록 진입과 이미지 구도를 확인했다. 연혁 67개 사건은 네 기간에 걸친 연도별 목록으로 읽을 수 있다.
- `verify_redesign_routes.mjs`는 18개 KO/EN 경로와 201개 참조가 통과했고 `verify_metadata_accessibility.mjs`는 교체한 구성 기준으로 통과했다. 화면 검수는 전체 페이지 완료를 뜻하지 않는다.
- 영상 프롬프트 조사와 실패/교정 기록은 [Seedance 2.0 실사·동적 영상 프롬프트 조사](20260929-seedance-real-motion-research.md)에 따로 정리했다. 1080p 메인 오프닝은 아직 승인된 장면이 없으며 검수용 이미지 슬라이드는 최종 영상으로 간주하지 않는다.
- 연구·사업 게시판의 QHD 상단 여백과 제목 아래 간격을 더 줄여 첫 화면에서 자료 행을 빠르게 읽을 수 있게 했다. AI·모델링·관측의 대표 장면은 [실제 연구 근거를 대조한 콘티](20260929-source-backed-visual-scenes.md)를 기준으로 교체한다. 현재 수치모델 대표 이미지는 평범한 하구 풍경 대신 하구에서 연안으로 이어지는 흐름 방향이 이미지 안에 표현된 별도 콘셉트로 교체했으며 실제 계산 결과라는 의미는 아니다.
