## 회사의 역할과 두 영상의 목적

**기업 메인 영상은 GeoSR의 정체성을 보여준다**
육상·하천·해안·해양을 조사하고 화학·생태 분석, 수치모델, AI, 위성자료로 해석하고 예측하는 종합 엔지니어링 회사가 주제다. 실제 공간을 관측한 결과가 지형·수심·분포장·예측 결과로 이어지는 장면을 만든다

**AX는 플랫폼 종류와 기능을 소개한다**
상단 종합영상 한 편과 하단 플랫폼별 짧은 기능 영상/그래픽·설명을 구성한다. 기업 홈페이지의 AX 소개에서 이 페이지로 이동한다. 서비스 접속 버튼이나 운영상태를 중심으로 설계하지 않는다. GeoDAP은 독립 버튼과 간단 소개를 유지하며 AX 목록에 포함하지 않는다

**영상의 주제는 플랫폼과 연결된 현상·기술의 콘셉트다**. 예를 들어 태풍이 해안에 접근하면서 수위와 위험 시점이 변하는 장면, 도시 지형 위에서 침수 범위·깊이가 변하는 장면을 만든다. 플랫폼 이름·핵심 기능을 해당 장면에 연결하고 전체 UI·패널·버튼의 재현은 영상 제작 목표에서 제외한다. 현재 캡처는 기술 이해와 구성 검토를 위한 임시 참고 이미지다

영상은 사용자 승인과 원본·권리 확인 뒤 제작한다. 현재는 장면·근거·한영 문구·기능 설명만 준비하며, 새 영상 생성·ImageGen·Higgsfield 플러그인·유료 크레딧은 사용하지 않는다. 기존 생성·재제작 시안은 실제 자료나 제작 승인본이 아니다. 모바일 검수·제작은 별도 단계로 보류한다
