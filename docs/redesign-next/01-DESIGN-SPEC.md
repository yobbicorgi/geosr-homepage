# 화면 설계와 품질 기준

## 비교 결론과 관찰 범위

현재는 정돈된 기업 사이트 단계임
레퍼런스의 장점은 효과 수가 아니라 하나의 시각 중심과 정보 위계 및 화면 간 리듬에 있음
현재의 좌측 제목·우측 이미지와 이어지는 목록을 반복하는 방식만으로는 원하는 인상을 만들기 어려움
전문 분야 이미지가 서로 다른 품질과 시점을 갖고 모델링 영역은 아직 빈 시각 언어에 가까움
CSS 여러 겹과 중복 렌더 함수는 향후 페이지 간 불일치를 키울 위험이 있음

## 확정할 시각 방향

**현실의 관측 장면에서 데이터의 해석으로 이어지는 연구기업 편집 디자인**

대형 미디어를 무대로 쓰고 설명은 빈 공간에 정렬함
실제 이미지가 바뀔 때 관련 문구와 자료 링크도 한 단위로 바뀜
둥근 SaaS 카드나 네온 장식으로 기술성을 대신하지 않음
멋은 넓은 화면과 정밀한 타이포 및 필요한 순간의 깊이 전환에서 만듦

### 공통 크기와 색

- FHD CSS viewport 1920×1080 기준 좌우 여백 96px / 내부 12열 / 열 사이 24px
- QHD와 UHD는 같은 16:9 CSS viewport에서 위 기준을 각각 4/3배와 2배로 비교
- 기존 `desktop-system.css`의 rem 체계를 먼저 조사하고 같은 역할의 두 번째 scale을 추가하지 않음
- 전체 페이지 transform 확대 금지 / 200% 사용자 확대에서 텍스트와 조작 유지
- FHD 기준 Hero 영문 80–88px / 대표 한글 44–56px / 내부 h1 56–64px / h2 36–44px / 본문 18px / 보조 14px
- 긴 한글 문장은 28–36자 안팎에서 자연스럽게 줄바꿈 / 영문은 별도 행 길이 조절
- 기본 `#08151F` / 깊은 남색 `#0B2438` / GeoSR 계열 블루 후보 `#2275B7` / 밝은 바탕 `#F2F5F6` / 밝은 바탕 본문 `#102B3B`
- 위 색은 회사 공식 CI 확정값이라는 주장이 아닌 구현 후보임 로고 원본과 기존 브랜드 자료를 대조해 확정
- 작은 글자·버튼은 실제 계산 색으로 4.5:1 이상을 내부 목표로 검사 대형 장식 문자로 본문 대비 문제를 가리지 않음
- 배경 영상에는 일정한 명암 마스크를 적용하고 텍스트 가독성을 위해 영상을 지나치게 검게 만들지 않음

### 세 가지 먼저 만들 보드

**B01 연구 흐름 무대 — Home 중간**

FHD에서 높이 약 900px / 12열 중 미디어가 9열을 차지하고 제목은 좌측 4열과 부분 겹침
관측 장면에서 “관측과 조사” → 실험 장면에서 “환경과 생태 분석” → 모델 장면에서 “변화를 예측하는 연구”
각각 실제 수행 내용 1문장과 관련 기술로 가는 링크 하나만 배치
장면 이름은 HTML이고 과학 데이터 위에 읽기 어려운 문구를 올리지 않음
스크롤 연출을 쓰면 최대 220vh 안에 3막 종료 / 사용자는 일반 휠로 계속 이동
정지 화면만으로도 내용이 전달되어야 하며 과도한 고정 스크롤을 멋으로 간주하지 않음

**B02 AX 기능 무대 — AX 중간**

탐지·예측·모니터링 분류가 한 줄 / 아래 서비스 이름과 현재 선택 상태
왼쪽 8열의16:9 화면 전체가 실제 UI / 오른쪽4열에는 주요 기능2개와 입력 자료·결과 형태
새 서비스 선택 시 이전 화면이18px 옆으로 빠지며 투명해짐 / 새 화면은 반대쪽18px에서 정위치
프레임 자체를 좁은 창으로 crop하지 않음 기능 확대는 별도16:9 컷을 제작
전체 화면1초 → 실제 동작1.5초 → 결과1초 → 전체 맥락0.5초 정도를 기본 리듬으로 삼음

**B03 문서 갤러리 — Company 중간**

분류는 인증 / 면허·등록 / 지식재산권
FHD에서 제목·분류·갤러리·하단 링크를 합쳐 약600–700px 안에 들어오도록 설계
가운데 문서는 정면 / 양옆 문서는 최대±10도 Y축 회전과94% 크기 / 앞면이 항상 보임
문서 앞면은 aspect-ratio 보존 / 텍스트는 사진 안에서 억지 확대하지 않고 아래 HTML 제목으로 안내
드래그와 버튼 및 방향키 조작 / 조작 전 자동 넘김 없음 / 확대 시 개인정보 보호 상태 유지
좌우 화살표는 실제 이전·다음 버튼으로만 사용

## 시각 완료 조건

- FHD·QHD·UHD를 같은 CSS16:9 조건으로 캡처해 제목 줄바꿈과 주요 정렬선·미디어 비중을 비교
- 핵심 경로 Home / AX / 기술 / 연구 / 장비 / 회사 / 소식 / 문의의 KO·EN 실제 화면 확인
- 390×844와768×1024에서 순서·가로 넘침·본문·탭 재배치 확인
- 대표16:9 UI 화면과 GeoDAP 이미지에 내장 검은 여백·잘린 메뉴·변형이 없음
- 움직임을 끈 정지 화면도 충분한 위계와 설명력을 가짐
- 각 섹션이 왜 목록·카드·미디어·갤러리인지 설명 가능하며 동일 네모 구성의 반복을 피함
- 전문가 관점 검수에서는 회사 실제 수행 범위와 콘텐츠 연결을 확인하고 “화려해 보임”만으로 통과하지 않음
- 실제 화면 비교 증거 없이 디자인 완료라고 쓰지 않음 사용자 미승인을 사용자 승인으로 바꾸지 않음
