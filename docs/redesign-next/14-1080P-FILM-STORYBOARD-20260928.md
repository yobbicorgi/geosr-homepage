> **검토용 콘티 / 유료 생성 보류** — 회사 본편은 무인선이나 현장 장비가 중심이 아니다. [회사 기술·사업·논문 근거 원장](16-COMPANY-FILM-EVIDENCE-20260928.md)을 먼저 읽고 위성·AI·조사·환경·수치모델·정보 시스템이 골고루 드러나는 광역 실사 기반의 기술 영상으로 만든다. 컷의 원본과 시작·중간·끝 프레임을 확인한 뒤에만 Higgsfield에 제출한다.

## 공통 연출 원칙

- [올포랜드 메인](https://www.all4land.com/main.do)의 실제 세계 규모와 다중 시점 리듬을 참고한다. 해당 영상·랜드마크·그래픽은 재사용하지 않는다.
- 장소가 확인된 실사와 회사 자료를 먼저 고른다. 출처·장소가 확인되지 않은 도시·해안 생성 장면을 실제 촬영이나 사업지처럼 사용하지 않는다.
- **실사 + Higgsfield 생성 장면 + 실제 자료 기반 모션 그래픽**을 편집한다. 단순 캡처 나열은 산출물이 아니다.
- 실제 자료의 지도·UI·수치·해안선 픽셀은 후반 합성으로 유지한다. 생성 모델에는 물리적으로 그럴듯한 환경·카메라 동선·자료 사이 전환을 맡기고 측정값과 운영 UI를 새로 그리게 하지 않는다.
- 회사의 21개 기술 기록을 영상에 각각 나열하지 않는다. 광역 위성·드론/공간정보·AI 영상분석·음향/유속/부이 관측·수질/생태·모델/예측을 균형 있게 대표한다. 무인선은 현장조사 분야의 선택 가능한 2–3초 보조 컷이다.
- 메인 영상은 무음이고 자막·로고·수치를 장면에 굽지 않는다. 필요한 제목은 웹의 HTML과 영상 편집의 별도 그래픽 층에서 다룬다.

**표현상 핵심 차이:** 위성 영상은 넓은 공간의 관측 자료, 드론은 해안 지형의 정사영상/점군, 멀티빔은 해저 수심, ADCP는 수층 유속, 부이는 정점 시계열, 채수는 실험실 분석, 수치모델은 조건을 둔 계산이다. 이들을 같은 푸른빛 효과로 통일하면 회사 기술이 오히려 흐려진다. 색은 일관되게 두되 마스크·측선·벡터·입자·시계열은 실제 자료 형식에 맞게 구분한다.

CF01의 장소 후보로 2024년 [부산관광아카이브 해운대 영상](https://www.visitbusan.net/archive/eng/dataSearchEng/view.nm?dataSid=METADATA009478)을 확인했다. 실제 재생 화면은 해안선을 위에서 내려다보는 약 29초의 가로 영상이다. 상세 페이지에는 장소·제작일·공공누리 제1유형 출처표시 조건이 명시되어 있다. **현재는 참조 후보**다. 실제 원본 파일의 해상도·화질·다운로드 절차·편집 적합성을 확인하고 사용 시 웹 크레딧에 출처를 표시한다. 이 지역을 GeoSR 사업지라고 부르지 않는다. 같은 아카이브의 [오륙도 영상](https://visitbusan.net/archive/eng/dataSearchEng/view.nm?dataSid=METADATA010035)은 실제 재생 화면이 꽃 근접 장면 중심의 세로 영상이라 회사 메인 광역 컷에서 제외했다.

2025년 회사 소개서 2면의 연안 사진은 출처가 회사 문서인 실제 사진이다. 촬영 장소와 날짜가 적혀 있지 않아 최종 CF01 원천으로 확정하지 않았다. 지금 웹의 정지 포스터는 영상 제작 전의 임시 이미지다.

## AX Platform과 GeoDAP

AX 영상은 0–6초 현실 해역에서 공간정보로 진입하는 전환 6–14초 직원 제작 위성영상 탐지 UI 14–22초 연안재해 예측 UI 22–27초 관측 UI 27–30초 세 분야가 한 화면 언어로 정리되는 마무리로 편집한다. 화면 캡처는 직원 저장소의 실제 동작을 FHD 이상으로 다시 녹화한다. 힉스필드는 UI 밖 공간·전환·동선의 완성도를 높이는 데 쓰고 한글·숫자·버튼은 캡처 또는 편집 레이어로 보존한다.

GeoDAP은 실제 메인 화면을 처음 2초 동안 충분히 보여주고 지도 기반 자료 탐색으로 이어간다. 지도에서 데이터로 들어가는 짧은 전환이 부족하면 Higgsfield 장면을 만들되 실제 GeoDAP UI 자체는 재생성하지 않는다. 독립 서비스 화면의 촬영·사용 맥락을 확인한다.

## 프롬프트 패키지 상태

이전 가상 하구·도시 CF01 프롬프트는 **철회**했다. 가상 해안 포스터를 장면의 시작 프레임으로 사용하지 않는다. 다음 카드에는 후보 원본 ID·실제 장소·권리·첫 프레임·마지막 프레임·한 가지 카메라 동작·합성 경계·금지 요소를 모두 채운 뒤 제출한다.

**공통 지시 초안**

> Create a silent five-second 16:9 cinematic transition for a GeoSR earth-science company film at native 1920x1080. Use the supplied documented real-world reference for geographic identity and framing. Preserve coastlines, islands, structures, scale, light direction and physical continuity. Use one deliberate camera movement only. Leave clean negative space for separate editorial graphics. The clip represents a visual transition and not an actual recording of GeoSR field work.
