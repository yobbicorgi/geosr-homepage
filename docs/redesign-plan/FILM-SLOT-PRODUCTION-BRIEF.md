# GeoSR film slot production brief

이 문서는 [`dist/film-manifest.json`](../../dist/film-manifest.json)의 9개 pending 슬롯을 위한 제작 기준이다. 현재 슬롯에는 실제 미디어를 연결하지 않으며, 모든 가안은 사람과 손을 제외한 사물·환경·화면 중심으로 만든다.

공통 기준:

- 한국의 연안·항만·하천·육상 환경공학 맥락을 사용하되, 확인되지 않은 지형·시설·수치·분석 결과를 사실처럼 만들지 않는다.
- 무인선은 여러 관측 기술 중 하나로만 다룬다. CTD, 부이, 시료병, 퇴적물·플랑크톤 채집 도구, 현장·실험 장비와 균형을 맞춘다.
- 위성 장면은 출처·취득일·좌표·처리 이력이 확인된 한반도 주변 실제 데이터 레이어만 사용한다. 가짜 지도, 위성 합성, 측정값, UI 라벨은 금지한다.
- 파란 네온 선, 과도한 데이터 그래픽, 사람·손, 가짜 한국 지형을 쓰지 않는다. 기본 색은 deep navy, pale marine blue, light blue-gray, mist white다.
- GIF·MP4·캡처는 16:9 무대 안에서 `object-fit: contain`으로 전체 비율을 보존한다. 모션은 화면별로 `slow-push`, `lateral-pan`, `detail-focus` 중 하나만 적용한다.
