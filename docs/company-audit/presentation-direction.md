2026-09-28 · 원문 조사에 근거한 편집 설계안

## 정보 구조

기술 역량과 적용 분야는 서로 다른 탐색 기준으로 제공한다
원사이트 4개 분류와 21개 기술의 원문 ID 및 연결은 보존한다
새 화면의 분류를 기존 회사 공식 조직이나 원문 분류였다고 표현하지 않는다

매출 순위나 공식 투자 비중을 추정한 순서가 아니다

### 적용 분야

- 하천·호소·댐과 통합 물환경 관리
- 연안·항만 개발과 환경영향 평가
- 기후변화·연안재해 대응
- 해상풍력 입지와 해양공간계획
- 생태계 보전·복원과 블루카본
- 관측 인프라·항로표지·수중시설 운영

기술 여러 개가 하나의 사업에 함께 쓰일 수 있다
위성영상을 공간정보의 다른 이름처럼 표현하지 않고 자료 취득·분석과 공간 구축·활용의 역할을 구별한다

## 이미지 및 모션 제작 기준

| 분야 | 무엇을 보여줘야 하는가 | 피해야 할 대체 이미지 |
|---|---|---|
| AI | 하천 수면의 부유 쓰레기나 수중 생물 등 식별 가능한 대상과 분할·탐지 관계 / 실제 결과는 상세에서 | 별자리·뇌 모양·네온 회로·위성 풍경 한 장 |
| 수치모델 | 하천-하구-해역의 연계 영역과 수리·확산·수질 변화 / 과학적 시각화와 현실 공간 대응 | 파도 사진만 / 물리와 관계없는 발광선 |
| 위성 | 넓은 관측 범위와 다중밴드·검보정·환경 변수의 관계 | 드론이나 경비행기 사진을 위성업무로 배치 |
| 공간정보 | 지형·시설물의 정사영상과 DEM·점군·GIS 결과 대응 | 위성 탐지 캡처 반복 |
| 관측·조사 | 해양·하천·호소 중 서로 다른 현장과 센서의 설치·관측 또는 해저탐사 | 무인선 한 종류로 모든 관측을 대표 |
| 환경·생태 | 채수·퇴적물 분석과 현장 정량조사 및 서식지·복원 / 여러 장 구성 | 열대 산호 관광사진 / 실험실만으로 생태 전체 대체 |
| 연안방재 | 해빈·방파제·도시 저지대 등 대상과 침식·월파·침수 분석 및 대책의 관계 | 바다 파도 클로즈업만 |
| 데이터·시스템 | 현실 공간과 자료·모델·운영 화면의 연결 / 상세에서는 직원 AX 갤러리 | 목적 없는 가상 도시와 HUD |

새 이미지의 콘셉트를 승인된 실측 결과로 주장하지 않는다
실제 업무 맥락은 분명히 표현하되 수치·정확도·장소·플랫폼 화면을 지어내지 않는다
AI 콘셉트의 분할·박스는 이미지와 영상 생성 단계에서 대상과 함께 제작한다 별도 후처리나 웹 오버레이로 붙이지 않으며 영상에서는 대상의 이동과 형태 변화에 계속 정합해야 한다
상세 페이지의 실제 제품 캡처와 메인 콘셉트 이미지는 역할을 구별한다

## 현재 화면에서 수정할 항목

1. 다섯 분야로 제한한 기존 `businessGroups`와 `homeFields`를 조사 기반 단일 데이터로 정리
2. 독립 AI 분야 및 명시적인 AI 설명 추가
3. 위성·영상·공간정보 혼합 명칭 제거
4. 파도 이미지의 재해 분야 사용 제거
5. 유인 경비행기로 보이는 생성물을 UAV 기술에 쓰지 않기
6. 메인 소개에 육수와 해양을 함께 표현
7. 하천·호소·댐 및 해저·항만 업무를 각 관련 상세로 연결
8. 기존 기술 21개 및 소개서 고유 업무가 새 구조에서 누락되지 않는지 대조
