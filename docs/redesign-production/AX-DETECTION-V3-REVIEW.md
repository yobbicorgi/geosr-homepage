## 목적과 사용 범위

AX의 시설물 탐지 기능을 설명하는 8초 콘셉트 장면이다
실제 플랫폼 출력이나 실제 양식장 촬영을 주장하지 않는다
회사 소개 60초 영상에는 사용하지 않는다
AX 30초 본편 전체가 완성된 상태도 아니다

이미지 설계는 열린 수면에 세 시설물 군을 배치하고 왼쪽을 웹 문구 공간으로 비운다
해안선이나 항로 및 방파제를 새로 만들지 않는다
종료 이미지는 같은 시설물 외곽에 가는 아이보리색 선만 추가한다
새로운 시설물이 생기거나 광선이 바다로 나가는 연출은 금지한다

## 관찰한 결과

- Flow 재생 화면과 1초 간격 8개 프레임을 직접 관찰했다
- 세 시설물 군의 수와 배치는 유지됐다
- 시설물 외곽선이 위에서 아래로 순차적으로 나타났다
- 별도 지형이나 시설물 증식 및 UI 생성은 관찰되지 않았다
- 바다는 작게 움직이며 카메라가 과하게 회전하지 않았다
- 실제 위치나 탐지 정확도 및 수량을 나타내는 텍스트는 넣지 않았다

**판정은 설명용 초안 연결 허용**이다
특정 양식장 설계와 계류 및 수중 그물 구조를 검증한 공학 도면이 아니다
실제 시설물 사례로 활용하려면 해당 위치의 원본 영상과 구조 자료로 대체해야 한다
영상의 모든 프레임에 대해 무오류를 보증하거나 과학적 관측 자료로 승인한 것이 아니다

## 홈페이지 연결

홈페이지 AX 소개 장면과 AX 소개 페이지의 메인 슬롯에 같은 검수 초안을 연결한다
`720p 탐지 콘셉트 초안 · 예측·모니터링 제작 중` 상태를 표시한다
하단 플랫폼별 실제 화면에는 이 콘셉트를 섞지 않는다
예측과 모니터링은 별도 의미를 갖는 장면으로 추가 제작해야 한다

## 다음 제작 기준

예측은 같은 지리 기준 위에서 입력 조건과 예상 영향 영역의 관계를 보여준다
모니터링은 관측 지점에서 들어온 상태 변화가 공간 자료에 갱신되는 관계를 보여준다
가상의 수치와 실제 관측값을 혼합하거나 의미 없는 유리판을 반복하지 않는다
