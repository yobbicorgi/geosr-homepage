1. 메인 본편은 **넓은 현실 환경 35–40% / 실제 현장 행동 20–25% / 실제 자료 기반 그래픽 25–30% / 광역 귀환과 마감 10% 안팎**으로 설계한다. 장비의 얼굴을 길게 보여주는 광고로 만들지 않는다.
2. 동일한 한반도 영상 위로 위성·드론·ADCP·모델 데이터를 한꺼번에 얹지 않는다. 각 장면은 **하나의 기술 질문과 하나의 판독 가능한 결과**만 보여준다.
3. Higgsfield는 실제 장소·장비의 보이지 않는 결과를 꾸며내는 도구가 아니다. 원본에 없는 부드러운 카메라 움직임, 배경, 장면 사이 전환의 후보를 만든다. 해안선·지도·센서·수치·탐지 마스크·제품 화면은 출처가 있는 레이어로 후반 작업한다.
4. 회사의 기술 범위는 넓지만 60초에 21개 기술과 수백 건의 실적을 모두 넣으면 읽히지 않는다. 본편은 대표적인 **관측 → 공간화 → 분석 → 예측 → 활용**의 흐름을 보여주되 서로 다른 사업을 한 프로젝트의 연속 공정처럼 암시하지 않는다. 상세 분야는 홈페이지 각 페이지와 분야별 짧은 영상으로 연결한다.

### 현재 파일의 화질과 성격

- 회사소개서 2면 사진은 PDF 내부에서 **1657×1173px**로 확인했다. 현재 첫 화면의 정지 포스터에 쓸 수는 있지만 QHD에서 확대하면 선명도가 부족하며 FHD 영상의 원본 촬영 파일은 아니다.
- 소개서 9면의 분석·실험 관련 큰 삽입 이미지는 **750×433px**, 18면의 관측 장비 이미지는 최대 **750×389px**, 21면의 해저·측량 이미지는 최대 **830×484px** 수준이다. 장비 형태 확인과 시안에는 도움이 되지만 1920×1080 본편의 넓은 화면으로 확대하지 않는다.
- 저장소의 `media-source/flow-downloads/`에는 과거 생성 초안이 보존돼 있지만 사용자가 해당 도구의 제작을 중단했고 해상도·과학·장소 검수가 끝나지 않았다. 이 파일은 신규 본편의 실사 원본이나 최종 영상으로 취급하지 않는다.
- `dist/assets/platforms/*.mp4`는 AX 제품 화면의 짧은 미리보기다. 회사 본편의 해양·연안 현장 자료가 아니며 제품 영상에는 원본 UI를 FHD 이상으로 다시 녹화한다.

따라서 현재 폴더에 영상 파일이 많다는 사실만으로 CF01–CF13의 원본이 확보됐다고 판단할 수 없다. 특히 위성 원영상, 같은 위치·시기의 드론 정사영상, 실제 탐지 마스크, 멀티빔 수심, ADCP 유속, 채수·실험실 과정, 수치모델 시계열은 파일·날짜·권리·단위가 이어져야 한다.
